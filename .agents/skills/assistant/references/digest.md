# 한입 · 회고 (모양을 바꾸지 마라)

학생이 소화한 뒤에만 다음 단계로 간다.
설명을 길게 쓴 뒤 이 상자를 빼먹지 마라. **상자 한 장**이 그 단계의 끝이다.

웹 장터를 열라고 하지 마라. 찾기는 AI가 한다.

## 🧃 한입 — 작은 단계가 끝날 때마다

한 실습·한 구분이 끝나면 이 장을 보여 주고 **멈춘다.**
「다음」이라고 하기 전에 학생이 「맞아요」 또는 「다음」이라고 해야 한다.

```
🧃 한입 · (지금 단계 짧은 이름)
────────────────
방금 : (한 줄. 학생이 한 일)
기억 : (학생이 말한 한 줄. 없으면 핵심 한 줄)
다음 : (하나만)
────────────────
맞으면 「다음」이라고 해 주세요.
```

## 🪞 회고 — 한 덩어리가 끝날 때

숙제 한 바퀴, MCP 연결, 스킬·MCP 찾기처럼 **덩어리**가 끝나면
질문 **하나**씩. 답이 오면 다음. 말한 문장만 적는다.

질문 셋이 기본이다. 없는 것은 「없음」.

1. 방금 된 것 한 줄
2. 안 되거나 헷갈린 것 한 줄
3. 다음에 보고 싶은 것 한 줄

끝나면 이 장만 보여 준다.

```
🪞 회고 · (덩어리 이름)
────────────────
된 것     : (학생 말)
안 된 것  : (학생 말. 「없음」도 됨)
다음에    : (학생 말. 「없음」도 됨)
다음 단계 : (하나만)
────────────────
```

투자 습관 회고는 `내-투자-판단.md` 회고 칸에도 같은 세 줄을 쓴다.

## 누가 쓰나

| 때 | 장 |
|---|---|
| 환경 맞춤·설치가 끝남 | 🔄 / 📦 다음에 🧃 한입 한 장 |
| 직접 호출·MCP 실습이 한 칸 끝남 | 🧃 한입 |
| 스킬과 MCP 구분이 끝남 | 🧃 한입 → 찾기 |
| 찾기·한 번 쓰기가 끝남 | 🪞 회고 |
| 모의주문 한 바퀴 | 🪞 회고 (investment-habit-rules retro) |
| 초록이가 다음 단계로 넘길 때 | 먼저 🧃 한입. 「다음」 후에만 넘김 |
