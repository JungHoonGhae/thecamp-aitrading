# 내-투자-판단.md

ROOT 의 `내-투자-판단.md`. 4주 동안 같은 파일. **이번 주 투자 판단**이 여기 남는다. 2·3·4주와 차주 학습이 이 칸을 읽는다. 투자 습관 스킬이 이 칸만 채운다.

이 파일의 칸은 습관, 할 것, 하지 말 것, 이번 주 실행 규칙, 이번 주에 못 하는 것, 네 문장, 회차, 회고다.
목표 비중 표는 2주차 `내-투자-스펙.md` 다. 스펙은 이 문서를 읽고 채운다.

## 칸

| 칸 | 오는 곳 | 누가 읽나 |
|---|---|---|
| 습관 | 단계 3·4·5 의 사실 | 투자 습관 스킬, 초록이 |
| 원하는 방식 | 단계 7 의 할 것 | 투자 습관 스킬, 2·3·4주 |
| 하지 말 것 | 단계 5·6, 단계 7 의 하지 말 것 | 2주차 스펙 ④ 가드레일 |
| 이번 주 실행 규칙 | 원하는 방식 중 MCP로 되는 것 | 1주차 조회 |
| 이번 주에 못 하는 것 | 차트·PER·진입 타이밍 등 | 3·4주 자리 |
| 네 문장 | 살 때 / 팔 때 / 위험 / 관점 | lecture-prism `MY_STRATEGY.md` |
| 회차 | 한 회차가 끝날 때마다 한 줄 | 다음 회차 |
| 회고 | 주문 다음. 불편·붙일 소스·안 된 규칙 | 다음 회차, 2주차 |

하지 말 것 = 이 사람이 거부하는 것. 못 하는 것 = 이번 주 데이터로 안 되는 것.
회고 = 돌려 보고 난 학습. 규칙 인터뷰와 섞지 않는다.

팔 때가 비어 있으면 정상이다. 3·4주가 채운다.

## 채울 문장

문서화 때 학생 말로 이 빈칸을 채운다. 실적으로 고르든, 차트로 고르든, 말한 습관이 들어간다.

```
나는 ______ 하는 주식을 ______ 으로 투자하고,
______ 은 하지 않는다.
______ 하면 판다. (없어도 된다)
```

회고는 이 세 줄이다.

```
______ 가 없어서 불편했다.
나중에 ______ 를 붙이고 싶다.
하고 싶었는데 안 된 것은 ______.
```

뉴스 종목을 사라는 정답이 아니다. 칸의 문장은 학생 말만.

## 2주차

`내-투자-스펙.md` 를 채울 때 이 파일을 먼저 읽는다.
하지 말 것 → 스펙 ④. 원하는 방식에서 담을 종목이 보이면 ①.
하지 말 것이 「아직 모름」이면 스펙 인터뷰가 이어서 묻는다.

## 3·4주차

네 문장 칸을 `MY_STRATEGY.md` 초안으로 가져간다.
