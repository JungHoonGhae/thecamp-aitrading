# 회고

둘째 명령이다. 첫 명령(포착 · 규칙 · 적용)이 끝난 뒤다. 이번 회차를 돌아본다. 말한 문장만 `내-투자-판단.md` **회고** 칸에 쓴다.

학생이 혼자 적겠다고 하면 칸만 안내하고 완료다.

한 화면에 질문 **하나**. 답이 오면 다음.

## 질문

1. "데이터가 없거나 도구가 짧아서 불편했던 게 있어요? 없으면 없다고 해 주세요."
2. "나중에 붙이고 싶은 데이터 소스가 있어요? 공시, 차트처럼요. 없으면 없다고 해 주세요."
3. "이 규칙으로 하고 싶었는데 잘 안 된 게 있어요? 없으면 없다고 해 주세요."

「없어요」 → 「없음」.

**완료:** 회고 세 칸이 비어 있지 않다. 「없음」도 완료다.

이 파일을 가리키는 명령:

```
.agents/skills/investment-habit-rules/references/retro.md 대로 방금 모의투자를 회고해 줘. 말한 것만 내-투자-판단.md 회고 칸에 채워.
```
