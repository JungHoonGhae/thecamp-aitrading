# 회고

둘째 명령이다. 첫 명령(포착 · 규칙 · 적용)이 끝난 뒤다. 이번 회차를 돌아본다.
말한 문장만 `내-투자-판단.md` **회고** 칸에 쓴다.

학생이 혼자 적겠다고 하면 칸만 안내하고 완료다.

한 화면에 질문 **하나**. 답이 오면 다음.

상자 모양은 초록이 `../assistant/references/digest.md` 의 **🪞 회고** 와 같다.
질문을 끝낸 뒤 그 장을 보여 주고 멈춘다. 긴 설명으로 덮지 마라.

## 질문

1. "방금 된 것 한 줄이요. 데이터가 없거나 도구가 짧아서 불편했던 게 있으면 그것도요. 없으면 없다고 해 주세요."
2. "안 되거나 헷갈린 것 한 줄이요. 이 규칙으로 하고 싶었는데 잘 안 된 것도요. 없으면 없다고 해 주세요."
3. "다음에 보고 싶은 것 한 줄이요. 공시, 차트처럼 붙이고 싶은 데이터도요. 없으면 없다고 해 주세요."

「없어요」 → 「없음」.

**완료:** 회고 세 칸이 비어 있지 않다. 「없음」도 완료다. 아래에 🪞 장이 있다.

```
🪞 회고 · 모의투자
────────────────
된 것     : (학생 말)
안 된 것  : (학생 말)
다음에    : (학생 말)
다음 단계 : 2주차에 내-투자-판단.md
────────────────
```

이 파일을 가리키는 명령:

```
.agents/skills/investment-habit-rules/references/retro.md 대로 방금 모의투자를 회고해 줘. 말한 것만 내-투자-판단.md 회고 칸에 채워. 끝나면 🪞 회고 상자로 보여 줘.
```
