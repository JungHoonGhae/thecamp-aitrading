# 한눈에 — 한투 공식 MCP 는 둘이다

공식 저장소 `koreainvestment/open-trading-api` 의 `MCP/` 아래 **폴더가 둘**이다.
포털 탭도 같다: 코딩도우미 MCP · 트레이딩 MCP.
**한 손으로 보면 주문이 안 나간다.**

```
🔧 한투 공식 도구 · 둘
────────────────
👀 코딩도우미  = 문서 334개 검색 · 샘플 코드. 주문 없음
🔧 트레이딩    = 호출 166개. 시세·잔고·모의주문. Docker
────────────────
수업 토요일   : kis-lecture-lab (연습 5개). Docker 없음
평일 숙제     : 👀로 둘러보고, 트레이딩 MCP 로만 부른다
실전 계좌     : 숙제 아님
────────────────
```

| | 코딩도우미 MCP | 트레이딩 MCP | kis-lecture-lab |
|---|---|---|---|
| 공식 이름 | KIS Code Assistant MCP | Kis Trading MCP | 수업 서버 |
| 개수 | **334** (`data.csv`) | **166** (`configs/*.json`) | **5** |
| 하는 일 | 찾기 · 샘플 코드 | **실제로 부름** | 수업용 다섯 |
| 주문 | **안 나감** | 모의(`env_dv=demo`) | `order_cash` 만 |
| 설치 | `npx` · 키 없음 | **Docker** · 모의 키 | 없음 |
| 포트 | 8081 (HTTP일 때) | 3000 (SSE) | stdio |

334 − 166 = 문서에만 있는 것. 코딩도우미에서 고른 API가 트레이딩 166에 없으면 **호출·주문이 안 된다.**
숙제에서 쓸 목록은 **트레이딩 166 안에 있는 것**만 고른다.

조회(읽기) 예: 현재가 · 호가 · 잔고 · 뉴스 제목 · 순위.
액션(쓰기) 예: 현금 주문 · 정정 · 취소. 숙제는 **모의투자만**. `env_dv` 는 `demo`. `real` 이면 멈춘다.

등록 이름 (그대로):
- `kis-code-assistant-mcp` — 👀
- `kis-trade-mcp` — 🔧
- `kis-lecture-lab` — 토요일 수업. 지우지 않는다.
