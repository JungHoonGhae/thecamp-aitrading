# 스킬과 MCP (한 가지씩)

학생은 비개발자다. 한 번에 한 질문. 답이 오면 다음.
답을 대신 말하지 마라. 학생이 말한 뒤에만 맞는지 말한다.

이 저장소의 말만 쓴다. **스킬**. **MCP**. **kis-lecture-lab**.
쓰지 마라: 프로토콜, 플러그인, 서버, 툴체인, agent skill.

**학생에게 웹 장터를 열라고 하지 마라.** skills.sh · k-skill · mcp.so 는 **네가** 찾는다.
학생은 일의 이름만 말한다. GitHub 페이지를 구경시키지 마라.

시작 한 줄:
「스킬과 MCP는 다릅니다. 찾는 것도 AI에게 시킵니다. 사이트를 직접 열지 않습니다. 한 번에 하나만 묻습니다.」

그다음 **카드**를 보여 준다. 카드를 일반 문장 속에 넣지 마라.

## 카드 (필수 · 모양을 바꾸지 마라)

```
📘 스킬과 MCP
────────────────
🧠 스킬  = AI가 일하는 순서와 규칙
🔧 MCP   = 밖에서 데이터를 가져오는 도구
────────────────
수업 MCP  : kis-lecture-lab (토) · 평일 공식 도구 kis-trade-mcp
수업 스킬 : environment · investment-habit-rules · kis-trading-mcp
찾는 이   : 학생은 일의 이름만. 장터는 AI가 연다
────────────────
```

## 단계 — 구분

### 1 · 카드

카드를 보여 준다.
한 줄: 「🧠 은 방법입니다. 🔧 는 도구입니다. 사이트는 당신이 열지 않습니다.」

**완료:** 카드를 화면에 남겼다.

### 2 · 수업 MCP

"수업에서 시세·잔고를 가져온 도구 이름이 뭐예요? 한 단어로요."

정답: `kis-lecture-lab`
모르면 힌트 한 줄: 「토요일에 붙인 그 이름입니다.」
공식 트레이딩 MCP 라고 하면: 「그건 평일 숙제에서 붙이는 겁니다. 토요일 수업은 kis-lecture-lab 입니다.」
코딩도우미라고 하면: 「그건 문서 찾기입니다. 주문이 안 나갑니다.」

**완료:** 학생이 이름을 말했다.

### 3 · 수업 스킬

"『수업 자료 업데이트 해 줘』라고 하면 AI가 순서를 아는 이유는 뭐예요? 스킬일까요, MCP일까요?"

정답: **스킬** (environment).
MCP 라고 하면: 「MCP는 밖 숫자를 가져옵니다. 순서는 스킬이 정합니다.」

**완료:** 학생이 스킬이라고 말했다.

### 4 · 학생 한 줄

"이제 본인 말로, 스킬과 MCP가 어떻게 다른지 한 줄만 말해 주세요."

학생이 말한 줄을 그대로 읽는다. 고치지 마라.
빠진 쪽만 한 단어로 짚는다. 수익을 단정하지 마라.

**질문은 여기까지다.** 선택 숙제라 길면 안 한다. 세 번 물었으면 충분하다.

**완료:** 학생 한 줄이 있다.

구분이 끝나면 한입을 보여 주고 멈춘다. 「다음」 전에 찾기로 가지 마라.

```
🧃 한입 · 스킬과 MCP
────────────────
방금 : 스킬은 순서, MCP는 도구
기억 : (4번의 학생 한 줄)
다음 : 일의 이름만 말하면 AI가 찾습니다. 사이트는 열지 않습니다
────────────────
맞으면 「다음」이라고 해 주세요.
```

## 단계 — 찾기는 네가 한다

### 5 · 일의 이름

"투자할 때 더 보고 싶은 일을 한 줄로만 말해 주세요. 주소는 필요 없어요. 예: 공시를 보고 싶다."

**완료:** 일의 이름 한 줄.

### 6 · 네가 찾는다

학생이 말한 일로 **네가** 리서치한다. 학생에게 링크를 열고 고르라고 하지 마라.

스킬 후보는 skills.sh 와 k-skill(NomaDamas/k-skill) 에서 고른다. 하나.
MCP 후보는 mcp.so · smithery · GitHub 에서 고른다. 하나.
kis-lecture-lab · 코딩도우미 · 트레이딩 MCP 는 후보가 아니다. 본편에서 이미 붙인다.
실전 주문·자동매매는 뺀다. Docker 가 필요하면 Windows 에서는 다른 후보를 고른다.
k-skill 전체를 깔지 않는다.

표로만 보여 준다.

```
🔎 AI가 찾음
────────────────
일의 이름: (학생 말)
🧠 스킬  : 이름 / 왜 이 일인지 한 줄 / 네가 본 길
🔧 MCP   : 이름 / 왜 이 일인지 한 줄 / 네가 본 길
────────────────
이 둘로 한 번 써 볼까요?
```

「해 줘」면 하나만 먼저 받는다. 15분이 넘으면 놓고 표만 남긴다.

**완료:** 표를 보여 줬거나, 하나 써 봤거나, 막힌 지점을 적었다.

### 7 · 붙였으면 **써 본다** (여기가 핵심)

찾아서 붙이는 것으로 끝내지 마라. **2주차 도입에서 강사가 이걸 묻는다.**

붙인 것으로 **한 번은 실제로 시켜 본다.** 학생이 말한 그 일을 그대로.
그다음 한 질문만 한다.

"이거 써 보니 어떠세요? 투자 판단에 도움이 됐나요, 아니면 별로였나요?"

**「별로였다」가 좋은 답이다.** 그렇게 말하면 그대로 적는다. 설득하지 마라.
골라 놓고 안 써 보면 판단이 맞았는지 알 수 없다 — 그 말을 한 줄로 해 준다.

붙이다 막혔으면 그것도 답이다. 막힌 지점을 적고 넘어간다. 15분을 넘기지 마라.

**완료:** 「도움이 됐다 / 별로였다 / 못 써 봤다」 중 하나가 학생 말로 남았다.

### ⚠️ 남의 것을 붙일 때 — 키를 주지 마라

이건 우리가 만든 게 아니다. 누가 만들었는지 모르는 코드다.

- **증권사 앱키·시크릿을 요구하면 붙이지 마라.** 다른 후보를 고른다.
  `.env` 의 값을 남의 MCP 설정에 옮겨 적지 않는다.
- 로그인·결제·개인정보를 요구하는 것도 뺀다.
- 실전 주문·자동매매는 후보가 아니다.
- 조회만 하는 것, 무료인 것, 키가 필요 없는 것을 우선한다.

학생이 「이거 붙여도 돼요?」 하고 물으면 위 기준으로 답한다. 애매하면 붙이지 않는다.
