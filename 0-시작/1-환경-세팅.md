# 환경 세팅 — 아무것도 없다고 가정 (AI에게 맡기기)

git·Python이 하나도 없어도 됩니다. 아래 **두 가지만** 손으로 하고, 나머지는
AI가 알아서 설치합니다.

## 손으로 하는 건 딱 1가지

**AI 코딩 도구 하나 설치 + 로그인** — Claude Code CLI 또는 Codex CLI.
(챗봇 웹/데스크톱 앱 아님, 터미널에서 도는 CLI. 강사가 최소 설치 가이드 별도 제공)

이거 하나만 되면, **git·저장소 내려받기·Python까지 전부 아래 프롬프트가 대신** 합니다.
(이 프롬프트는 강의 사전 안내에도 들어 있어, 저장소를 받기 전에도 그대로 붙여넣을 수 있습니다.)

## 📋 복사용 부트스트랩 프롬프트 (저장소 받기 + git·Python 설치까지)

```
나는 프로그래밍이 처음인 사람이고, 'ai-trading-lab' 실습을 하려고 해.
지금 내 컴퓨터엔 git·Python 이 없을 수도 있어. 다음을 순서대로 해줘:

1. 내 운영체제(mac/Windows/Linux)를 확인.
2. 패키지 매니저가 없으면 설치 (mac=Homebrew, Windows=winget/choco, Linux=apt 등).
3. git 이 없으면 설치.
4. 이 저장소를 내려받아줘:  git clone <저장소 주소>   그리고 그 폴더로 이동.
   (git 이 정 안 되면 ZIP 다운로드 방법을 안내해줘.)
5. Python 3.11 이상이 없으면 설치. (이 프로젝트는 표준 라이브러리만 써서 추가
   의존성은 없음. pyproject.toml 은 확인만.)
6. 마지막으로 `python 1부-연결/quote.py 005930` 을 실행해서
   '005930 현재가: ...' 가 나오면 "세팅 성공"이라고 알려줘.

각 단계에서 내가 클릭/입력할 게 있으면 초보자도 알 수 있게 쉬운 말로 하나씩
알려줘. 관리자 권한이 필요하면 미리 말해줘.
```

> 이미 저장소 폴더를 받은 상태라면 위 4번(clone)은 건너뛰어도 됩니다.

## Docker Desktop (2회차 MCP 실습용 — 미리 설치 권장)
2회차에서 KIS 공식 **Trading MCP**를 붙여 AI가 실제 모의계좌를 조회합니다. 이 MCP는
**Docker 컨테이너**로 도는 구조라 Docker Desktop이 필요합니다.
- mac / Windows: 공식 Docker Desktop 설치(로그인까지). Windows는 WSL2 권장.
- 왜 Docker? 노트북이 제각각이어도 컨테이너 안은 **누구에게나 똑같이** 동작(환경 통일).
- **Docker가 안 돼도 실습은 계속됩니다** — `mock 폴백`으로 동일하게 진행하고 나중에 붙입니다.
```
내 OS에 맞는 Docker Desktop 설치 방법을 알려주고, 설치가 됐는지 확인하는 것까지 도와줘.
```
