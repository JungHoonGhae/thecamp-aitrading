# Part 1 · 02 — 표준 래퍼(MCP)로 연결하기

## 이 단계 목표
KIS 공식 MCP를 AI 코딩 도구에 붙여, "자연어로 시세를 물어보면 AI가 알아서
호출"하는 걸 체험한다. 직접 만들지 않고 붙여서 써본다.

## 📋 복사용 프롬프트
```
KIS 공식 MCP를 이 프로젝트에 붙이고 싶어. mcp.example.json 을 참고해서
내 AI 코딩 도구(Claude Code 또는 Codex)에 MCP를 등록하는 방법을 알려주고,
등록 후 "삼성전자 현재가 알려줘"를 자연어로 물어보는 예시까지 보여줘.
```

## 참고: MCP 등록 설정 예시
`mcp.example.json` 을 열어보세요. KIS 공식 MCP 서버를 등록하는 형태입니다.
(실제 등록은 위 프롬프트로 AI가 도와줍니다.)

## MCP vs 직접 호출 — 무엇이 다른가
- **직접 호출(01)**: 코드를 실행해서 가져온다.
- **MCP(02)**: AI가 "어떤 기능을 어떻게 부를지" 스스로 알고 자연어로 호출한다.
  대신 등록해 둔 도구 정의가 늘 컨텍스트를 차지한다(무거워질 수 있음).
