# 1부 · 연결 (1회차)

## 이 파트의 목표
**AI를 국내 주식시장(KIS 모의투자)에 연결한다.** — "어떤 데이터를 어떻게 주느냐"가 결과의 경쟁력이라는
관점에서, AI가 내 **KIS 모의계좌를 실제로 조회**하게 만든다.

## 끝나면 할 수 있는 것
- 어떤 데이터 소스든 **AI에 연결하는 원리**를 설명할 수 있다 (직접 호출 vs MCP vs CLI).
- KIS 공식 **Trading MCP를 내 AI 도구에 붙여** "모의투자로 삼성전자 현재가" 를 실제로 받는다.
- **왜/언제 MCP가 좋은지**(정보는 양이 아니라 구조) 판단 기준을 갖는다.

## 직접 하는 것 (실습)
받아서 실행 → **내가 종목·질문을 바꿔** 다시 조회 → 결과를 읽는다.
- 프롬프트로 환경 세팅(설치도 AI가) → 직접 호출로 시세 → **MCP 붙여 실제 모의 조회**
- Docker가 안 되면 **mock 폴백**으로 동일 경험 (실습은 멈추지 않는다)
