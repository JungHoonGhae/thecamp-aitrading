# Part 2 · 01 — 예제 에이전트 그대로 실행하기 (수정 없이)

## 이 단계 목표
강사가 준비한 예제 에이전트를 **손대지 않고** 먼저 돌려본다.
"완성되면 이렇게 작동한다"를 만들기 전에 눈으로 확인한다.
(이 예제는 정답이 아니라, 검증 중인 하나의 예시입니다.)

## 📋 복사용 프롬프트
```
2-에이전트/agent.py 를 실행해서, 2-에이전트/spec 폴더의 내 투자 원칙대로
지금 계좌가 얼마나 맞는지 점검한 결과를 보여줘.
```

## 직접 실행하고 싶다면
```
python 2-에이전트/agent.py
```
