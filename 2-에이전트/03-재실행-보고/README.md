# Part 2 · 03 — 내 스펙으로 다시 실행 & 결과 확인

## 이 단계 목표
내가 고친 스펙대로 에이전트가 점검·보고하는지 다시 돌려 확인한다.
(선택) 디스코드로 보고가 오게 연결한다.

## 📋 복사용 프롬프트
```
2-에이전트/agent.py 를 다시 실행해서, 내가 바꾼 원칙대로 점검 결과가
달라졌는지 이전과 비교해서 설명해줘.
```

## 직접 실행하고 싶다면
```
python 2-에이전트/agent.py
```

## (선택) 디스코드로 보고 받기
디스코드 채널의 웹훅 URL을 환경변수로 넣으면 화면 대신 디스코드로 갑니다.
```
DISCORD_WEBHOOK="https://discord.com/api/webhooks/..." python 2-에이전트/agent.py
```
웹훅 만드는 법(5분): [`docs/discord-웹훅-가이드.md`](../../docs/discord-웹훅-가이드.md)

## (선택) mock → 실제 모의투자(live)로 전환
지금까지는 mock(모의 데이터)로 돌렸습니다. 내 KIS 모의투자 키로 실제 서버 조회를
해보고 싶다면 아래 프롬프트를 붙여넣으세요. (키 발급: `docs/kis-신청-가이드.md`)
```
내 KIS 모의투자 키로 실제로 돌려보고 싶어. .env.example 을 복사해 .env 를 만들고
KIS_MODE=live 와 내 앱키·시크릿·모의계좌번호를 넣는 걸 도와줘. 그다음
`KIS_MODE=live python 2-에이전트/agent.py` 로 실제 계좌 기준 점검이 되는지 확인해줘.
.env 는 절대 공유하지 말라고 알려줘.
```
> 주의: 토요일 등 휴장일엔 실시간 조회가 제한됩니다. 그럴 땐 mock 으로 실습하세요.
> 이 저장소는 조회·점검까지만 — 실제 돈이 오가는 실전 매매 기능은 없습니다.

## 마무리
이 에이전트는 **점검·보고까지만** 합니다. 완전 자동매매로 가려면 읽기 전용 → 확인 →
모의 자동 → 실전으로 '신뢰의 게이트'를 한 단계씩 넘어야 합니다. 스펙 몇 줄로 안전이
완성되지는 않습니다(자세히는 최상위 [`README.md`](../../README.md) 마무리 참고).
