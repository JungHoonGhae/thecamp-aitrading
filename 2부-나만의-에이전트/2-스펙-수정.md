# 2부 · 2 — 내 원칙으로 스펙 수정

## 이 단계 목표
`2부-나만의-에이전트/spec/` 의 마크다운 몇 줄만 고쳐서 에이전트를 "내 것"으로 바꾼다.
코드는 건드리지 않는다. **규칙을 코딩하는 게 아니라 선언**한다.

## 무엇을 고치나 (`2부-나만의-에이전트/spec/` 안)
- `portfolio.md` — 담을 종목과 목표 비중 (합 100)
- `rules.md` — 리밸런싱 주기·허용 오차
- `guardrails.md` — 한 종목 최대 비중·현금 최소 보유 (기본 안전 한도)

## 📋 복사용 프롬프트 (원하는 대로 골라 쓰세요)
```
2부-나만의-에이전트/spec/portfolio.md 를 열어서, 삼성전자 비중을 40%로 올리고
나머지 네 종목을 각 15%로 바꿔줘. 비중 합이 100이 되게 맞춰줘.
```
또는
```
2부-나만의-에이전트/spec/portfolio.md 를 시가총액 상위 3종목만 균등(각 33.3%)으로 바꾸고,
guardrails.md 의 '한 종목 최대 비중'을 35%로 낮춰줘.
```

## 가드레일 '체험' — 일부러 한 번 걸려보기
안전 한도가 실제로 어떻게 작동하는지 눈으로 보려면, 일부러 한도를 넘겨보세요.
```
2부-나만의-에이전트/spec/portfolio.md 에서 삼성전자 비중을 45%로 올리고 SK하이닉스를 5%로 바꿔줘.
(나머지는 그대로) 그다음 2부-나만의-에이전트/agent.py 를 실행해서 어떤 경고가 뜨는지 보여줘.
```
→ 실행하면 "가드레일 경고: 삼성전자 목표비중 45% > 한도 40%" 가 뜹니다. 이렇게
스펙이 스스로 "이 선을 넘었다"고 알려주는 걸 확인한 뒤, 다시 안전한 값으로 되돌리세요.
```
방금 바꾼 걸 원래대로(각 20%) 되돌려줘.
```

> ⚠️ 스펙 몇 줄로 기본 제약을 선언할 수는 있지만, 이것만으로 온전히
> 안전해지는 건 아닙니다. 그 한계와 보완은 마무리에서 다룹니다.
