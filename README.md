## 1회차에 연결하고, 2회차에 완성합니다

![Part 1–2 학습 여정 — 1회차에 AI를 KIS Open API에 연결하고, 그 MCP 연결을 재사용해 2회차에 나만의 AI 투자 에이전트로 완성하는 구조](assets/journey-part1-2.png)

| 파트 | 목표 | 끝나면 |
|---|---|---|
| **1부 · 연결** (1회차) | AI를 국내 주식시장(KIS 모의투자)에 연결 | 내 모의계좌를 AI가 실제 조회 |
| **2부 · 에이전트** (2회차) | 내 원칙으로 스스로 점검·리밸런싱·보고 | 자는 동안 도는 나만의 에이전트 |

1회차에서 만든 **MCP 연결을 그대로 재사용**해, 2회차에 에이전트를 얹습니다.
직접 호출 · KIS MCP · CLI 래퍼 세 경로를 비교해보고, 그중 하나로 계속 갑니다.

## 2회차에 완성되는 것

![Part 2 아키텍처 — 정기 실행·투자 스펙·가드레일 스펙을 입력으로, AI 에이전트가 목표 비중과 실제 보유를 비교하고 가드레일을 검증한 뒤 디스코드로 보고하는 흐름](assets/architecture-part2.png)

내가 **마크다운으로 선언한 원칙**(투자 스펙 · 가드레일 스펙)을 AI가 매일 정해진 시각에 읽고,
계좌와 비교해 차이를 계산한 뒤 **디스코드로 보고**합니다.
코딩이 아니라 선언 — 원칙을 바꾸고 싶으면 마크다운만 고치면 됩니다.

> 점검·보고까지입니다. **실제 주문 실행은 없습니다.**

## 전체 지도 (여는 순서)
```
0-시작/            환경 세팅 + 핵심 개념
  └▶ 1부-연결/          [1회차] AI를 국내 주식시장(KIS 모의투자)에 연결
        └▶ 2부-나만의-에이전트/  [2회차] 점검·리밸런싱·자동 보고 에이전트
              └▶ 9-마무리/       신뢰 게이트 · 다음 회차
```

## 폴더 안내
- **학습 경로(순서대로)**: `0-시작` → `1부-연결` → `2부-나만의-에이전트` → `9-마무리`
- **참고/**: 필요할 때 펴보는 가이드 (KIS 신청·MCP 연동·디스코드 웹훅·아키텍처·프롬프트 모음)
- **common/**: 내부 코드(KIS 클라이언트·디스코드) — 직접 열 필요 없음
- **skill/assistant/**: 학습 튜터 (AI에게 "다음 단계 알려줘 / 막혔어"라고 하면 안내)

## 세팅 확인
```
python verify.py     # mock 모드로 3/3 통과하면 준비 완료
```

## 튜터에게 도움받기
막히면 어떤 AI 코딩 도구에서든:
```
skill/assistant/SKILL.md 대로 도와줘. 나는 지금 어느 단계인지 모르겠어.
```
