# AI 자동매매 실습실 (ai-trading-lab)

패스트캠퍼스 강의 실습 저장소입니다. **프롬프트를 복사해 붙여넣으며 단계별로** 따라오면
됩니다. 코딩 지식이 없어도 괜찮습니다.

## 폴더 지도 (여는 순서)
```
README.md      ← ① 지금 이 파일
SETUP.md       ← ② 환경 세팅
verify.py      ← 세팅 확인:  python verify.py

1-연결/         ← 1회차: AI를 시장에 연결 (01→02→03)
2-에이전트/      ← 2회차: 나만의 AI 투자 에이전트 (01→02→03)
3-자동화/        ← 3단계: 정해진 시각에 자동 실행 + 디스코드

docs/          참고자료 (아키텍처·디스코드 웹훅·KIS 신청)
common/        내부 코드 — 열어볼 필요 없음
skill/         AI 도우미용 (막힐 때 튜터)
```
> 숫자 폴더(1→2→3)만 순서대로 따라가면 됩니다. 나머지는 참고/내부용입니다.

## 시작하기
git·Python이 하나도 없어도 됩니다. **손으로 하는 건 딱 1가지**, 나머지는 AI가 합니다.

1. **AI 코딩 도구 하나 설치 + 로그인** — Claude Code CLI 또는 Codex CLI.
   (챗봇 웹/데스크톱 앱이 아니라 터미널에서 도는 CLI 입니다.)
2. [`SETUP.md`](SETUP.md) 의 프롬프트를 AI에 붙여넣기 → git·저장소 내려받기·Python까지 세팅 끝.
3. 확인: `python verify.py` (4/4 나오면 준비 완료)

> 기본은 **mock 모드**입니다. KIS 키가 없어도, 장이 닫힌 토요일에도 예제가 똑같이 돌아갑니다.

### 2회차 · [`2-에이전트/`](2-에이전트/) — 마크다운 몇 개로 나만의 AI 투자 에이전트
| 순서 | 모듈 | 내용 |
|---|---|---|
| 01 | [`01-예제-실행`](2-에이전트/01-예제-실행/) | 예제 그대로 먼저 돌려보기 |
| 02 | [`02-스펙-수정`](2-에이전트/02-스펙-수정/) | 내 원칙으로 스펙(마크다운) 수정 + 가드레일 체험 |

### 3회차 · [`3-자동화/`](3-자동화/) — 정해진 시각에 자동으로
"자는 동안 AI가 시장을 지켜본다." 점검을 정해진 시각에 자동 실행하고 디스코드로 받습니다.
방법은 **OS 스케줄러(누구나)** 또는 **내 hermes(무료·자연어)** 중 편한 걸 고르면 됩니다.

각 폴더 `README.md` 에 **📋 복사용 프롬프트**가 있습니다. 붙여넣고 다음 폴더로.

## 마무리 — 신뢰만큼 한 단계씩
이 실습의 에이전트는 **점검·보고까지만** 합니다(실제 주문 없음). 완전 자동매매로 가려면
읽기 전용 → 미리보기·확인 → 모의 자동 → 실전으로 권한을 **한 단계씩** 열어야 합니다.
스펙 몇 줄로 안전이 완성되지는 않으며, 핵심 안전장치는 코드로 단단히 고정하는 하이브리드가
현실적으로 필요합니다.
