# AI 자동매매 실습실 (ai-trading-lab)

패스트캠퍼스 강의 실습 저장소입니다. **프롬프트를 복사해 붙여넣으며 단계별로**
따라오면 됩니다. 코딩 지식이 없어도 괜찮습니다.

## 시작하기

컴퓨터에 git·Python이 하나도 없어도 됩니다. **손으로 하는 건 딱 2가지**뿐이고,
나머지(git·Python 설치까지)는 AI가 알아서 해줍니다.

1. **AI 코딩 도구 하나 설치 + 로그인** — Claude Code CLI 또는 Codex CLI.
   (챗봇 웹/데스크톱 앱이 아니라 터미널에서 도는 CLI 입니다.)
2. **이 저장소 파일 받기** — `git clone <주소>` 또는 GitHub의 **Download ZIP**.

그다음 [`SETUP.md`](SETUP.md) 의 프롬프트를 AI에 붙여넣으면 환경 세팅 끝.

> 기본은 **mock 모드**입니다. KIS 키가 없어도, 장이 닫힌 토요일에도 예제가 똑같이
> 돌아갑니다. 실제 모의투자로 돌리고 싶으면 [`.env.example`](.env.example) 참고.

다음 폴더로 넘어가면 됩니다.

## 막히면? — 튜터에게 물어보세요
어떤 AI 코딩 도구를 쓰든 이렇게 부탁하면 단계별로 도와줍니다.
```
skill/assistant/SKILL.md 를 읽고, 그 규칙대로 나를 지금 단계부터 도와줘.
```
(이 안내는 [`AGENTS.md`](AGENTS.md) 에도 들어 있어, 저장소를 연 AI가 자동으로 참고합니다.)

## 마무리 — 신뢰만큼 한 단계씩

이 실습의 에이전트는 **점검·보고까지만** 합니다(실제 주문 없음). 완전 자동매매로
가려면 읽기 전용 → 미리보기·확인 → 모의 자동 → 실전으로 권한을 **한 단계씩**
열어야 합니다. 스펙 몇 줄로 안전이 완성되지는 않으며, 핵심 안전장치는 코드로
단단히 고정하는 하이브리드가 현실적으로 필요합니다.
