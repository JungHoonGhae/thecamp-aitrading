# AI 자동매매 시스템 제작 — 실습 저장소 (ai-trading-lab)

패스트캠퍼스 오프라인 강의(정훈 · Part 1~2)의 실습 저장소입니다.
코딩을 몰라도, **프롬프트를 복사해 붙여넣으며** 따라오면 끝에는 동작하는 시스템이 남습니다.

## ▶ 여기서 시작
### 👉 [`0-시작/README.md`](0-시작/README.md) 를 열면, 다음다음으로 이어집니다.

각 파일 맨 아래 **`다음 ▶`** 을 따라가면 순서대로 진행됩니다.

## 전체 지도 (여는 순서)
```
0-시작/            환경 세팅 + 핵심 개념
  └▶ 1부-연결/          [1회차] AI를 국내 주식시장(KIS 모의투자)에 연결
        └▶ 2부-나만의-에이전트/  [2회차] 점검·리밸런싱·자동 보고 에이전트
              └▶ 9-마무리/       신뢰 게이트 · 다음 회차
```

| 파트 | 목표 | 끝나면 |
|---|---|---|
| **1부 · 연결** (1회차) | AI를 국내 주식시장(KIS 모의투자)에 연결 | 내 모의계좌를 AI가 실제 조회 |
| **2부 · 에이전트** (2회차) | 내 원칙으로 스스로 점검·리밸런싱·보고 | 자는 동안 도는 나만의 에이전트 |

## 폴더 안내
- **학습 경로(순서대로)**: `0-시작` → `1부-연결` → `2부-나만의-에이전트` → `9-마무리`
- **참고/**: 필요할 때 펴보는 가이드 (KIS 신청·MCP 연동·디스코드 웹훅·아키텍처·프롬프트 모음)
- **발표자료/**: 파트별 슬라이드(`1부-슬라이드`·`2부-슬라이드`)와 개념 인터랙티브(`1부-개념-시각화`)
- **common/**: 내부 코드(KIS 클라이언트·디스코드) — 직접 열 필요 없음
- **skill/assistant/**: 학습 튜터 (AI에게 "다음 단계 알려줘 / 막혔어"라고 하면 안내)

## 세팅 확인
```
python verify.py     # mock 모드로 3/3 통과하면 준비 완료
```

## 튜터에게 도움받기
막히면 어떤 AI 코딩 도구에서든:
```
skill/assistant/SKILL.md 대로 도와줘. 나는 지금 어느 단계인지 모르겠어.
```
