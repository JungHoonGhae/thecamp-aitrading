---

이 수업의 에이전트는 적어 둔 비율로 되돌리는 일만 합니다. 종목을 고르지 않습니다.

어떤 종목을 40%만 담기로 했는데 주가가 뛰면 어느새 60%가 됩니다. 그때 계좌는 한 곳에 더 실려 있습니다. **리밸런싱**은 불어난 쪽을 조금 팔고 줄어든 쪽을 사서, 적어 둔 비율로 되돌리는 일입니다. 수익을 올려 준다고 단정하지 않습니다.

40%는 삼성전자를 담으라는 숫자가 아닙니다. 비율이 어떻게 흐트러지는지 보여 주려고 든 예시입니다. ETF가 그 비율 맞추기를 상품으로 만든 것이고, 이 수업은 ETF를 사라는 이야기도 아닙니다.

종목을 하나씩 골라 지수를 이기는 일은 대부분의 사람에게 어렵습니다. AI에게 매매를 바로 맡기면, 표가 돈 건지 AI가 골라 넣은 건지 모릅니다.

**그래서 리밸런싱부터 합니다 — 답을 채점할 수 있어서입니다.** 목표 20%인데 지금 36.9%면 팔아야 한다, 이건 계산해 보면 맞는지 압니다. 「언제 사고 언제 팔까」는 몇 주 지나야 맞았는지 알고요. 채점할 수 없는 일부터 맡기면 믿을 근거가 안 쌓입니다. 1·2회차가 채점 가능한 쪽이고, 3·4회차가 그다음입니다.

원칙은 [`내-투자-스펙.md`](내-투자-스펙.md) 표에 적습니다. 한도를 넘으면 주문을 막습니다. 통과한 것만 실행합니다. 결과는 텔레그램으로 옵니다.

자는 동안은 hermes가 같은 점검을 돌립니다. 설치가 안 되면 crontab입니다. Windows는 작업 스케줄러입니다.

![1회차에 연결하고, 2회차에 에이전트를 만드는 흐름](assets/journey-part1-2.png)

### 1·2회차에서 AI가 하는 일

리밸런싱은 표대로 돕니다. AI가 종목을 고르지 않습니다. 코드를 안 짜도 표를 만들고, 돌리고, 결과를 읽게 하려고 AI를 씁니다.

- **표 채우기** — 말로 한 원칙을 숫자에 옮길 때 ([스펙 인터뷰](lessons/2부-나만의-에이전트/2-스펙-수정.md))
- **체결 후 리뷰** — 주문을 더 넣지 않고, 방금 일어난 일만 읽을 때 ([리뷰어](lessons/2부-나만의-에이전트/3-재실행-리밸런싱.md))

설치와 에러도 AI가 돕습니다. 그건 코딩 도움이지 매매가 아닙니다.

테슬라로 치면 여기는 차선과 속도를 미리 적어 둔 차에 가깝습니다. 장면을 보고 "지금은 끼어들어도 된다"고 판단하는 FSD는 3·4회차입니다.

## 시작

Claude Code 같은 도구에서 이 폴더를 연 다음, 아래를 그대로 붙이세요. 폴더를 아직 안 받았으면 [환경 세팅](lessons/0-시작/1-환경-세팅.md)부터.

```text
지금 열려 있는 폴더가 이 실습 저장소의 루트인지 확인해줘 (verify.py 와 lessons 폴더가 보여야 해).
Python 3.9 이상이 있는지 확인하고, 없으면 내 OS에 맞게 설치를 도와줘.
(맥은 기본 python3 로 대개 그냥 됩니다 — 새로 깔 필요 없는지 먼저 확인해줘.)
`python` 이 없으면 `python3` 로 실행해도 돼.
준비되면 python verify.py 를 실행해줘 — API 키 없이 mock 모드로 도는 게 정상이야.
실패하면 내가 명령어를 직접 치지 않도록, 네가 원인을 설명하고 고쳐줘.
5/5 통과가 나오면 다음으로 열 파일이 lessons/0-시작/README.md 라고 알려줘.
```

화면에 `결과: 5/5 통과`가 나오면 [0-시작](lessons/0-시작/README.md)을 엽니다.
에러가 나면 `.agents/skills/troubleshooting/SKILL.md 대로 고쳐줘`
길을 잃으면 `.agents/skills/assistant/SKILL.md 대로, 다음 행동 하나만 알려줘`

`python`이 없으면 `python3`로 같은 명령을 치면 됩니다.

## 어떻게 돌아가나

표와 한도를 읽습니다. 지금 들고 있는 것과 비교합니다. 한도를 넘으면 주문을 막습니다. 통과한 것만 연습 계좌에서 사고팝니다. 보고는 텔레그램입니다.

1회차 MCP는 AI가 시세를 읽게 붙여 보는 시간입니다. 2회차 에이전트는 `kis.py`로 같은 종류의 데이터를 읽습니다.

![표와 한도 → agent.py → 텔레그램](assets/architecture-part2.png)

고치는 파일은 [`내-투자-스펙.md`](내-투자-스펙.md) 하나면 됩니다. 고치고 `python sync_spec.py`를 실행하세요. 이 줄을 안 치면 에이전트는 예전 표를 그대로 씁니다.

| | 어떻게 | 예 |
|---|---|---|
| 숫자만 | 표만 고치고 `python sync_spec.py` | ③ 오차를 5 → 3 |
| 말로 | AI에게 뜻을 말하기 (2회차에서 합니다) | "배당 위주 3종목으로 표를 채우고 sync·verify까지 해줘" |
| 파일 | `agent/spec/`을 직접 고치기 | `guardrails.md`에 금지 한 줄 |

수업에서 쓰는 건 연습 계좌와 모의투자입니다.

| | 여는 법 | 실제로 움직이는 것 | 필요한 것 |
|---|---|---|---|
| 연습 계좌 | 그냥 이 상태 | 수업용 시세·잔고·체결 | 없음 |
| 모의투자 | `.env`에 `KIS_MODE=live` | 증권사 모의투자. 돈은 가짜 | KIS 모의투자 App Key |
| 실전 | `KIS_ENV=real` + `KIS_REAL_ACK=REAL-MONEY-OK` | 실제 돈 | 실전 키 + 위 두 줄. [9-마무리](lessons/9-마무리/README.md) |

실전은 수업이 끝난 뒤 본인이 두 줄을 직접 켜야 열립니다.

## 수업이 끝나면

연습 계좌에서 리밸런싱하는 에이전트, 내가 채운 표, 텔레그램 보고, hermes 예약(안 되면 crontab)이 남습니다.
3·4회차 가기 전에 적어 둘 메모 네 줄도 남습니다. 언제 담을까, 무엇을 볼까, 언제 줄일까, 한도는 얼마인가.

3·4회차는 [lecture-prism](https://github.com/dragon1086/lecture-prism)입니다. 그쪽은 [`START_HERE.md`](https://github.com/dragon1086/lecture-prism/blob/main/START_HERE.md)부터입니다.
표 전체를 가져가는 숙제는 아닙니다. 메모 네 줄이 [`MY_STRATEGY.md`](https://github.com/dragon1086/lecture-prism/blob/main/MY_STRATEGY.md) 초안입니다.

직접 여는 건 이 README, `lessons/`, `내-투자-스펙.md`입니다. 나머지 폴더는 AI가 찾습니다.

```
README.md          ← 지금 이 파일
내-투자-스펙.md     ← 원칙을 적는 표
lessons/           ← 학습 문서
agent/             ← 에이전트와 실행용 스펙
hermes/            ← 자동화 패키지
examples/          ← 단계별 실행 스크립트
src/               ← 내부 코드
verify.py          ← 확인용
```

안녕하세요. 계정훈입니다. 앱 안에 갇힌 데이터를 AI가 쓰게 여는 일을 합니다.
[tossinvest-cli](https://github.com/JungHoonGhae/tossinvest-cli)가 그중 하나입니다. 토스증권 공식 API만으로는 쓰기 어려웠던 계좌·시세·주문을 AI가 읽게 연결했습니다.

자동매매는 연결만으로 끝나지 않습니다. 내 돈이 움직이는 일입니다. 어디까지 맡길지, 언제 멈출지, 어떻게 확인할지가 같이 있어야 합니다.

수업에서는 KIS 모의투자로 그 흐름을 만듭니다. 코딩을 몰라도 됩니다. 글을 따라가면 됩니다. 끝나면 자는 동안에도 계좌를 보는 에이전트가 남도록 안내하겠습니다.

## 자주 묻는 질문

**패시브면 그냥 룰 아니냐. AI는 왜 쓰나.**
맞습니다. 1·2회차 매매는 표대로입니다. AI가 살지 말지를 정하지 않습니다. AI는 말로 한 원칙을 표로 옮기고, 설치와 에러를 돕고, 체결이 난 뒤 결과를 같이 읽습니다. 코딩을 대신하는 쪽에 가깝습니다.

**AI 자동매매 강의인데 왜 종목을 안 고르나.**
처음부터 종목까지 고르면 표가 돈 건지 AI가 골라 넣은 건지 모릅니다. 적어 둔 비율이 연습 계좌에서 맞는지 본 다음, 3·4회차에서 언제 담고 언제 줄일지를 정합니다.

**삼성전자 40%가 추천이냐.**
아닙니다. 비율이 어떻게 흐트러지는지 보여 주려고 든 숫자입니다.

**연습 계좌면 의미가 있나.**
수업이 토요일입니다. 증권사 서버가 쉬는 날이 많습니다. 연습 계좌에서 비율이 바뀌는 걸 보는 게 당일 실습입니다. 평일에 모의투자 키를 넣으면 같은 코드가 증권사 모의로 붙습니다.

---

수업은 모의투자까지입니다. 실전은 졸업 스위치(이중 확인)로만 열리고, 수업 범위가 아닙니다.
예제는 배우려고 만든 것이고 수익을 약속하지 않습니다. 투자 판단과 실계좌는 본인 책임입니다.
