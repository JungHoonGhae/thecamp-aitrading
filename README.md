## 무엇을 만드나

정해진 시각에 내 계좌를 열어 보고, 내가 적어 둔 비율과 다르면 사고팔고, 결과를 텔레그램으로 보내 주는 작은 프로그램입니다. 이걸 **에이전트**라고 부르겠습니다.

만드는 방법이 이 수업의 절반입니다. **코드를 직접 치지 않고 AI에게 말로 시켜서 만듭니다.** 설치도, 연결도, 에러 고치는 것도 그렇게 합니다. 랜딩에 적힌 「바이브코딩」이 이것입니다.

세 가지를 알아 두시면 나머지가 쉽습니다.

- **코딩은 안 해도 됩니다.** 문서에 있는 글을 복사해 AI에 붙이면 됩니다.
- **증권사 키는 1주차엔 없어도 됩니다.** 수업이 토요일이라 증권사 서버가 쉽니다. 키는 1주차 수업 중에 다 같이 신청하고, 평일 숙제부터 씁니다.
- **실제 돈은 안 움직입니다.** 수업은 모의투자까지입니다.

## 어떻게 돌아가나

1주차에 AI를 시세에 붙여 보고, 2주차 에이전트는 같은 종류의 데이터를 코드로 읽습니다.

여기서 「표」는 [`내-투자-스펙.md`](내-투자-스펙.md) 에 적는 표 하나를 말합니다.

그 표와 한도를 읽습니다. 지금 들고 있는 것과 비교합니다. 한도를 넘으면 주문을 막습니다. 통과한 것만 연습 계좌에서 사고팝니다. 보고는 텔레그램으로 옵니다.

자는 동안은 hermes 가 같은 점검을 돌립니다. 설치가 안 되면 crontab 이고, Windows 는 작업 스케줄러입니다.

![표와 한도 → agent.py → 텔레그램](assets/architecture-part2.png)

고치는 파일은 [`내-투자-스펙.md`](내-투자-스펙.md) 하나면 됩니다. 고친 뒤 `python sync_spec.py` 를 실행하세요. **이 줄을 안 치면 에이전트는 예전 표를 그대로 씁니다.**

| | 어떻게 | 예 |
|---|---|---|
| 숫자만 | 표만 고치고 `python sync_spec.py` | ③ 오차를 5 → 3 |
| 말로 | AI에게 뜻을 말하기 (2주차에서 합니다) | "배당 위주 3종목으로 표를 채우고 sync·verify까지 해줘" |
| 파일 | `agent/spec/` 을 직접 고치기 | `guardrails.md` 에 금지 한 줄 |

직접 여는 건 이 README, `lessons/`, `내-투자-스펙.md` 입니다. 나머지 폴더는 AI가 찾습니다.

```
README.md          ← 지금 이 파일
내-투자-스펙.md     ← 원칙을 적는 표
lessons/           ← 학습 문서
agent/             ← 에이전트와 실행용 스펙
hermes/            ← 자동화 패키지
examples/          ← 단계별 실행 스크립트
src/               ← 내부 코드
verify.py          ← 확인용
```

## 왜 리밸런싱부터 하나

이 수업의 에이전트는 적어 둔 비율로 되돌리는 일만 합니다. 종목을 고르지 않습니다.

어떤 종목을 40%만 담기로 했는데 주가가 뛰면 어느새 60%가 됩니다. 그때 계좌는 한 곳에 더 실려 있습니다. 그 40%는 삼성전자를 담으라는 숫자가 아니라, 비율이 어떻게 흐트러지는지 보여 주려고 든 예시입니다.

종목을 하나씩 골라 지수를 이기는 일은 대부분의 사람에게 어렵습니다. AI에게 매매를 바로 맡기면 내가 적은 대로 된 건지 AI가 알아서 고른 건지 구분이 안 갑니다.

**그래서 리밸런싱부터 합니다 — 답을 채점할 수 있어서입니다.** 목표 20%인데 지금 36.9%면 팔아야 한다, 이건 계산해 보면 맞는지 압니다. 「언제 사고 언제 팔까」는 몇 주 지나야 맞았는지 알고요. 채점할 수 없는 일부터 맡기면 믿을 근거가 안 쌓입니다. 1·2주차가 채점 가능한 쪽이고, 3·4주차가 그다음입니다.

![1주차에 연결하고, 2주차에 에이전트를 만드는 흐름](assets/journey-part1-2.png)

### 그럼 AI는 어디에 쓰나

리밸런싱은 내가 적어 둔 비율대로만 돕니다. AI가 종목을 고르지 않습니다. 코드를 안 짜도 표를 만들고, 돌리고, 결과를 읽게 하려고 AI를 씁니다. 자리는 네 군데입니다.

- **약점 읽기** — 고정 결과를 AI가 한 번 검토할 때 ([예제 실행](lessons/2부-나만의-에이전트/1-예제-실행.md))
- **가드레일 확인** — 한 종목 최대 비중을 낮춰 주문이 막히는지 ([스펙 수정](lessons/2부-나만의-에이전트/2-스펙-수정.md))
- **넣기 전 검토** — 주문 계획이 한도를 넘지 않는지, 실행 직전에 ([실행 전 검토](lessons/2부-나만의-에이전트/3-재실행-리밸런싱.md))
- **체결 후 리뷰** — 주문을 더 넣지 않고, 방금 일어난 일만 읽을 때 ([리뷰어](lessons/2부-나만의-에이전트/3-재실행-리밸런싱.md))

계산은 코드가, 차단은 가드레일이 합니다. 「내가 이걸 정말 의도했나」는 둘 다 못 봅니다. 그 자리가 AI의 자리입니다.

설치와 에러도 AI가 돕습니다. 그건 코딩 도움이지 매매가 아닙니다.

테슬라로 치면 여기는 차선과 속도를 미리 적어 둔 차에 가깝습니다. 장면을 보고 "지금은 끼어들어도 된다"고 판단하는 FSD는 3·4주차입니다.

## 자주 묻는 질문

**AI 자동매매 강의인데 왜 종목을 안 고르나.**
처음부터 종목까지 고르면 내가 적은 대로 된 건지 AI가 알아서 고른 건지 구분이 안 갑니다. 적어 둔 비율이 연습 계좌에서 맞는지 본 다음, 3·4주차에서 언제 담고 언제 줄일지를 정합니다.

**패시브면 그냥 룰 아니냐. AI는 왜 쓰나.**
위 「그럼 AI는 어디에 쓰나」의 네 자리입니다. 사고파는 것 자체는 내가 적어 둔 비율대로이고, AI가 살지 말지를 정하지 않습니다.

**5종목 균등이면 그냥 ETF 사면 되지 않나.**
그 말이 맞습니다. ETF는 이 비율 맞추기를 상품으로 만든 것이고, 수수료 내고 남에게 맡기는 게 편합니다. 여기서 직접 해 보는 이유는 수익률 때문이 아닙니다. 남이 대신 해 주던 일이 안에서 어떻게 도는지 한 번은 봐야 그다음을 맡길지 말지 판단됩니다. 그리고 ETF는 「내가 아는 회사 한 종목」을 못 넣습니다.

**증권사 앱에도 자동 매수가 있는데 왜 만드나.**
앱은 앱이 정해 둔 것만 합니다. 여기서 만드는 건 **내 규칙을 내가 글로 적고, 그게 실행을 바꾸는 것**입니다. 「바이오는 안 담는다」를 한 줄 적으면 그 종목 주문이 막힙니다. 앱에 그런 칸은 없습니다. 이 골격은 리밸런싱에만 쓰는 게 아닙니다 — 3·4주차에서 판단이 들어가도 선언하고, 미리 보고, 막고, 보고받는 순서는 그대로입니다.

**연습 계좌면 의미가 있나.**
수업이 토요일이라 증권사 서버가 쉬는 날이 많습니다. 연습 계좌에서 비율이 바뀌는 걸 보는 게 당일 실습입니다. 평일에 모의투자 키를 넣으면 같은 코드가 증권사 모의로 붙습니다.

**KIS가 API를 바꾸면 제 건 죽나요.**
언젠가는 바뀝니다. 그때 고치는 게 이 수업에서 배우는 것 중 하나입니다 — 에러 원문을 그대로 AI에게 주고 고치게 하는 것. `python verify.py` 가 어디가 깨졌는지 짚어 주고, 저장소의 트러블슈팅 가이드가 증상→원인→수정 순서를 잡아 줍니다. 실제로 이 저장소도 그렇게 고쳐 왔습니다. 토큰 발급 제한, 초당 호출 제한, 응답 지연 같은 것들이 이미 기록돼 있습니다. 저장소는 계속 갱신합니다.

**AI 구독료를 왜 제가 내야 하나요.**
실습이 AI 코딩 도구(Claude Code / Codex) 위에서 돌아가는데 그 계정은 개인 것이라 강사가 대신 넣어 드릴 수 없습니다. 이 저장소 자체는 무료이고 설치할 것이 없습니다 — 파이썬만 있으면 됩니다. 유료인 건 "코드를 대신 쳐 주는 AI" 쪽이고, 수업이 끝난 뒤 구독을 끊어도 만든 에이전트는 그대로 돕니다. 자동화(hermes·crontab)도 무료입니다.

**4주에 자동매매 시스템이 정말 만들어지나요.**
1·2주차가 끝나면 적어 둔 비율대로 점검하고, 가드레일 안에서 리밸런싱하고, 정해진 시각에 텔레그램으로 알려 주는 것이 실제로 돕니다. 그건 약속드립니다. 다만 "알아서 돈 벌어 주는 것"은 아닙니다. 종목을 고르는 판단은 3·4주차이고, 그것도 판단을 **맡기는 법**을 배우는 것이지 정답을 받는 게 아닙니다. 수익은 누구도 약속할 수 없습니다.

**3·4주차를 안 들으면 반쪽인가요.**
아닙니다. 1·2주차만으로 점검하고, 리밸런싱하고, 알려 주는 것이 손에 남습니다. 그대로 계속 쓰셔도 됩니다. 3·4주차는 여기에 판단(언제 담고 언제 줄일지)을 얹는 확장이지, 없으면 안 도는 나머지 절반이 아닙니다.
