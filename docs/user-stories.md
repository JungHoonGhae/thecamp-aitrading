# 사용자 스토리 — 1·2회차 (정훈)

레슨이나 코드를 고칠 때 "이게 누구의 무엇을 위한 건가"를 여기서 확인한다.
스토리마다 **판정 문장**이 있다 — 충족/미충족을 말로 다투지 않기 위해서다.

추적: [🗺 1·2회차 단독 학습가치 맵](https://linear.app/remodule/issue/REMOD-922) ·
[사용자 스토리 티켓](https://linear.app/remodule/issue/REMOD-923)

## 페르소나

| | 누구 | 온 이유 | 가장 큰 두려움 |
|---|---|---|---|
| **P1** | 비개발자 직장인 (주 대상) | 투자는 하는데 감으로 한다. 자동화하고 싶지만 코딩은 못 한다 | 따라가지 못해 혼자 뒤처지는 것 |
| **P2** | 코딩 조금 아는 수강생 | AI 에이전트 구조를 보고 싶다 | 너무 쉬워 시간 낭비하는 것 |
| **P3** | 강사·조교 | 2시간 안에 전원을 완주시켜야 함 | 설치 지옥으로 절반을 잃는 것 |
| **P4** | 3·4회차로 가는 수강생 | 실전 자동매매까지 | 1·2회차가 겉핥기여서 안 이어지는 것 |

## 세팅 (`lessons/0-시작/`)

**US-01** · P1 — 컴퓨터에 뭐가 깔렸는지 몰라도 **AI에 한 번 붙여넣으면 준비가 끝나기를** 원한다. 터미널이 무섭기 때문이다.
→ 판정: `verify.py` 5/5. 손으로 친 명령은 붙여넣기 프롬프트 외 0개. — **충족**

**US-02** · P1 — 세팅이 실패하면 **문제와 다음 행동을 한 문장으로** 알기를 원한다. traceback 을 읽을 줄 모르기 때문이다.
→ 판정: 실패 시 원인 1줄 + 다음 행동 1줄. 두 개 이상 제안하지 않는다. — **충족**

**US-03** · P3 — 막힌 학생을 **같은 이름으로 분류**하기를 원한다. 20명이 제각각 다른 화면을 보여주면 대응이 불가능하기 때문이다.
→ 판정: 학생이 화면을 그대로 읽어 주면 조교가 어느 단계인지 안다. — **충족**

**US-04** · P1 — **이미 되는 걸 또 깔지 않기를** 원한다. 수업이 2시간뿐이기 때문이다.
→ 판정: 맥 기본 `python3` 로 그냥 된다. — **충족** (요구 3.9)

**US-05** · P1 — **윈도우 한국어 환경에서도 첫 실행이 되기를** 원한다.
→ 판정: 한국어 콘솔에서 `python agent/agent.py` 가 정상 출력. — **충족** (cp949 수정)

## 1부 · 연결 (`lessons/1부-연결/`)

**US-06** · P1 — "AI에 데이터를 연결한다"를 **몸으로** 느끼기를 원한다. 개념만 읽으면 다음 주에 잊기 때문이다.
→ 판정: 내가 종목·질문을 바꿔 다시 조회하고, 왜 답이 달라졌는지 말할 수 있다. — **충족** (1부-2에 「내 걸로 바꿔 보기」 + 「도구 순서를 설명해줘」 스텝)

**US-07** · P1 — **MCP 붙이기가 실습을 멈추게 하지 않기를** 원한다. Docker 는 내가 통제할 수 없기 때문이다.
→ 판정: Docker 없이 1부가 끝까지 간다. — **충족** (`agent/mcp_server.py`)

**US-08** · P2 — **왜 MCP 인가**를 판단 기준으로 갖기를 원한다. 남한테 설명할 수 있어야 배운 것이기 때문이다.
→ 판정: "정보는 양이 아니라 구조로"를 내 말로 한 문장. — **충족** (도구 3개가 검색·상세보기·호출로 개념 문서와 일치)

## 2부 · 나만의 에이전트 (`lessons/2부-나만의-에이전트/`)

**US-09** · P1 — **코드를 안 고치고 말로 내 원칙을 넣기를** 원한다. 코드는 못 읽기 때문이다.
→ 판정: 인터뷰로 표가 내 것이 되고 `sync_spec.py` 로 반영된다. — **충족**

**US-10** · P1 — **내가 적은 게 실제로 실행을 바꾸는 걸** 보기를 원한다. 안 그러면 마크다운 몇 줄 쓴 흉내이기 때문이다.
→ 판정: `내-투자-스펙.md` ①~④ 중 내가 고친 칸이 결과를 바꾼다. — **충족** (①③④는 실행을, ②는 보고를 바꾼다. ④는 종목명 매칭으로 주문 차단)

**US-18** · P1 — **AI가 틀릴 수 있다는 걸 안전할 때 한 번 보기를** 원한다. 돈이 걸린 뒤에 처음 겪고 싶지 않기 때문이다.
→ 판정: AI가 채운 표에서 내가 말하지 않은 값을 찾아내 반박했고, 「기계가 잡는 실수 / 사람만 잡는 실수」를 한 줄로 말할 수 있다. — **충족** (2부-2 「AI가 채운 표를 그대로 믿지 않기」)

**US-19** · P1 — **AI가 준 숫자를 다른 방법으로 확인**할 수 있기를 원한다. 믿을 근거가 필요하기 때문이다.
→ 판정: MCP로 받은 잔고와 `agent.py` 결과를 대조해 같음을 확인했다. — **충족** (1부-2 「AI가 준 값이 맞나」)

**US-11** · P1 — **안전장치가 진짜 막는 걸** 보기를 원한다. 실제 돈으로 가기 전 믿을 근거가 필요하기 때문이다.
→ 판정: 일부러 한도를 넘기면 레슨이 예고한 그 차단 문구가 뜬다. — **충족**

**US-12** · P1 — **주문이 체결돼 비중이 움직이는 걸** 보기를 원한다. 토요일이라 시장이 닫혀 있어도.
→ 판정: `--execute` 후 재실행하면 비중이 목표에 가까워져 있다. — **충족**

**US-13** · P1 — **결과가 무슨 뜻인지 AI가 설명해 주기를** 원한다. 숫자만 봐서는 모르기 때문이다.
→ 판정: 리뷰어 프롬프트가 3가지를 답하고 추가 주문은 넣지 않는다. — **충족**

**US-14** · P1 — **자는 동안 알아서 돌기를** 원한다. 그게 이 수업에 온 이유이기 때문이다.
→ 판정: 예약이 등록되고 텔레그램으로 보고가 온다. — **부분 충족** (hermes 경로 미검증)

## 마무리 · 이후 (`lessons/9-마무리/`)

**US-15** · P1 — **집에 가서 혼자 돌려도 안 깨지기를** 원한다.
→ 판정: 평일에 `.env` 한 줄만 바꿔 증권사 모의투자로 붙는다. — **미검증**

**US-16** · P4 — **1·2회차 산출물이 3·4회차 입력이 되기를** 원한다.
→ 판정: 판단 메모 4줄이 `MY_STRATEGY.md` 초안이 된다. — **미충족**

**US-17** · P1 — **수익을 약속받지 않기를** 원한다. 과장에 속아 손해 보는 게 가장 두렵기 때문이다.
→ 판정: 문서 어디에도 수익 단정이 없다. 실전은 졸업 스위치로만. — **충족**
