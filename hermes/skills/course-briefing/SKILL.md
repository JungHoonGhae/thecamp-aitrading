# 아침 브리핑 자동화

이 스킬은 읽기 전용 아침 브리핑 하나만 다룬다. 주문 계획을 만들거나 승인·실행하지 않는다.
학생은 Telegram에서 요청하고, 결과도 같은 Telegram 대화에서 확인한다.

## 지금 한 번 실행

사용자가 지금 실행해 달라고 하면 `terminal`로 아래 스크립트를 한 번 실행한다.

```text
python "${HERMES_SKILL_DIR}/../../scripts/morning-brief.py"
```

출력에서 시장·현재 계좌·보유 종목·오늘 점검 여부를 짧게 보여 준다. 마지막에
`주문: 없음`을 붙인다. 실패하면 원인과 다시 확인할 항목을 보여 주고 성공처럼 말하지 않는다.

## 평일 오전 8시 예약

1. 먼저 `cronjob(action="list")`로 기존 예약을 확인한다.
2. 이름이 `수업 아침 브리핑`인 예약이 있으면 새로 만들지 않는다. 시각과 상태를 보여 준다.
3. 없으면 `cronjob`으로 아래 값의 예약을 만든다.
   - action: `create`
   - name: `수업 아침 브리핑`
   - schedule: `0 8 * * 1-5`
   - prompt: `아침 브리핑 결과를 그대로 전달한다. 주문은 만들거나 실행하지 않는다.`
   - script: `morning-brief.py`
   - no_agent: `true`
   - deliver: `origin`
4. 생성 뒤 이름·시각·활성 상태를 보여 준다.

사용자가 수동 시험도 원하면 방금 만든 정확한 job id로 `cronjob(action="run")`을 한 번만
호출한다. job id를 추측하지 않는다. 실행은 백그라운드에서 끝나므로 기다리거나 반복 호출하지
않는다.

`agent.py --execute`는 만들거나 예약하지 않는다. 실전 계좌 설정도 바꾸지 않는다.
