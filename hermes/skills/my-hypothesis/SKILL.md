# 수업 가설 검토

이 명령은 매 주문이 아니라 시스템을 처음 만들거나 규칙을 다시 검토할 때만 쓴다.

1. 아래를 실행한다.

```text
python "${HERMES_SKILL_DIR}/../../../agent/hermes_invest.py" hypothesis-review
```

2. KIS 시가총액 상위 30 → 현재가·20일선·60일선 → 공식 수급·실적 확인 → 검토 후보 최대
   3개라는 고정 예제와 한계를 그대로 보여 준다.
3. AI는 장점·약점·다음 질문만 보탠다. 종목·비중·수량·가격을 바꾸지 않는다. AI를 호출하지
   못하면 그 상태를 숨기지 않고 고정 설명을 보여 준다.
4. 이 예제는 이미 수업 설명용으로 고정되어 있으므로 채택 버튼을 다시 띄우지 않는다. 현재
   목표 포트폴리오와 주문 계획도 바뀌지 않는다. 평소에는
   `/ts_status → /ts_order_plan → 승인`으로 진행한다고 말한다.
