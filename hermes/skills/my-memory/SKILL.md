# 자동 기억

이 기능은 매번 일지를 쓰게 하지 않는다. 새 로그 파일도 만들지 않는다. Hermes가 이미 가진
세 가지 기억을 역할에 맞게 사용한다.

- **세션 기록**: Telegram 대화와 분석·계획·승인·보류 결과. 자동 저장되며 과거 내용은
  `session_search`로 찾는다.
- **Hermes Memory**: 여러 세션에서 다시 쓸 안정된 선호·가드레일만 짧게 선별한다.
- **규칙 장부**: 계좌 상태와 주문 계획·체결 결과는 수업 규칙 코드가 관리한다.

## 인자가 없을 때

1. 현재 대화에서 확인되는 최근 분석·설정·계획·승인·보류를 먼저 읽는다.
2. 이전 대화가 필요할 때만 `session_search`를 한 번 사용한다. 검색어는
   `ts_analyze ts_config ts_order_plan 승인 보류`처럼 수업 활동으로 한정한다.
3. 현재 수업 저장소에서 아래 두 명령을 각각 한 번 실행한다.

```text
python "${HERMES_SKILL_DIR}/../../../agent/hermes_invest.py" status
python "${HERMES_SKILL_DIR}/../../../agent/hermes_invest.py" rule
```

4. `최근 활동`, `현재 규칙과 계좌`, `오래 기억하는 선호` 세 덩어리로 짧게 보여 준다.
   확인되지 않은 활동은 지어내지 말고 `아직 기록 없음`이라고 쓴다.

## 사용자가 뒤에 말을 붙였을 때

- 앞으로도 반복할 안정된 선호·금지선·가드레일이면 Hermes의 `memory` 도구로 한 번만
  추가하거나 기존 항목을 고친다.
- 오늘 한 번의 감상·분석 결과·주문 사유라면 별도 Memory에 복제하지 않는다. 현재 Hermes
  세션에 이미 자동 저장됐다고 알린다.
- 무엇을 저장할지 애매하면 강제로 저장하지 않고, 대화 기록에는 남았다고만 말한다.

사용자가 명령어 대신 “이건 기억해 줘”·“다음에도 기억해 줘”라고 자연어로
말해도 수업 플러그인이 이 스킬로 연결한다. 매번 일지를 쓸 필요는 없으며 명시적으로
기억을 요청할 때만 오래 쓸 원칙인지 판단한다.

어느 경우에도 종목·수량·가격을 만들거나 주문을 승인·실행하지 않는다. `MEMORY.md`나
`USER.md`를 쉘·파일 도구로 직접 편집하지 않고 반드시 Hermes 기본 `memory` 도구만 쓴다.
