# 환경 세팅 — 아무것도 없다고 가정 (AI에게 맡기기)

git·Python이 하나도 없어도 됩니다. 손으로 하는 것은 AI 코딩 도구 설치·로그인뿐입니다.
받·맞춤·점검은 「실습 환경 설치해 줘」「수업 자료 업데이트 해 줘」면 됩니다.

## 손으로 하는 건 딱 1가지

**AI 코딩 도구 하나 설치 + 로그인** — Claude Code CLI 또는 Codex CLI.
(챗봇 웹/데스크톱 앱 아님, 터미널에서 도는 CLI. 강사가 최소 설치 가이드 별도 제공)

이거 하나만 되면, **git·저장소 내려받기·Python까지 전부 아래 프롬프트가 대신** 합니다.
(이 프롬프트는 강의 사전 안내에도 들어 있어, 저장소를 받기 전에도 그대로 붙여넣을 수 있습니다.)

## 📋 이미 실습 폴더를 열었다면

```
실습 환경 설치해 줘
```

끝나면 **📦 실습 환경 · 설치** 상자에 「실습 환경이 준비되었습니다」가 나와야 합니다.

강사가 자료를 고쳤다고 하면:

```
수업 자료 업데이트 해 줘
```

**🔄 실습 환경 · 업데이트** 상자가 뜨면 된 겁니다. `git` 명령을 칠 필요는 없습니다.

## 📋 폴더가 아직 없을 때 (처음 한 번)

```
나는 프로그래밍이 처음인 사람이고, 'ai-trading-lab' 실습을 하려고 해.
내 컴퓨터엔 git·Python 이 없을 수도 있어.

1. 내 운영체제에 맞게 git 과 Python 3.9 이상을 준비해줘. Windows 는 python 이다.
2. 이 주소를 노트북에 받아 그 폴더로 이동해줘:
   https://github.com/JungHoonGhae/thecamp-aitrading.git
   ZIP 으로는 받지 마. 나중에 맞출 수 없다.
3. python verify.py 를 실행해줘.
   - 「실습 환경이 준비되었습니다」면 성공이라고 알려줘.
   - 실패하면 화면의 「다음」 하나만 해결하고 다시 실행해줘.

내가 클릭/입력할 게 있으면 하나씩 알려줘.
```
