# 환경 세팅 — 아무것도 없다고 가정 (AI에게 맡기기)

git·Python이 하나도 없어도 됩니다. 아래 **두 가지만** 손으로 하고, 나머지는
AI가 알아서 설치합니다.

## 손으로 하는 건 딱 1가지

**AI 코딩 도구 하나 설치 + 로그인** — Claude Code CLI 또는 Codex CLI.
(챗봇 웹/데스크톱 앱 아님, 터미널에서 도는 CLI. 강사가 최소 설치 가이드 별도 제공)

이거 하나만 되면, **git·저장소 내려받기·Python까지 전부 아래 프롬프트가 대신** 합니다.
(이 프롬프트는 강의 사전 안내에도 들어 있어, 저장소를 받기 전에도 그대로 붙여넣을 수 있습니다.)

## 📋 복사용 부트스트랩 프롬프트 (저장소 받기 + git·Python 설치까지)

```
나는 프로그래밍이 처음인 사람이고, 'ai-trading-lab' 실습을 하려고 해.
내 컴퓨터엔 git·Python 이 없을 수도 있어.

1. 내 운영체제에 맞게 git 과 Python 3.9 이상을 준비해줘.
   (맥은 기본 python3 로 대개 그냥 되니, 새로 깔기 전에 먼저 확인해줘.)
2. 이 저장소를 내려받고 그 폴더로 이동해줘:
   git clone https://github.com/JungHoonGhae/thecamp-aitrading.git
   git 설치가 오래 걸리거나 막히면 ZIP 으로 받아도 똑같아 — 이 실습에 git 은 필요 없어:
   https://github.com/JungHoonGhae/thecamp-aitrading/archive/refs/heads/main.zip
   (받아서 압축을 풀고 그 폴더로 이동)
3. python verify.py (또는 python3 verify.py) 를 실행해줘.
   - 「결과: 5/5 통과」면 세팅 성공이라고 알려줘.
   - 실패하면 화면에 「원인」과 「다음」이 한 줄씩 나와. 그 「다음」 하나만 해결하고
     다시 실행해줘. 네가 원인을 새로 추측하지 말고 화면에 나온 걸 그대로 따라줘.

내가 클릭/입력할 게 있으면 초보자도 알 수 있게 하나씩 알려줘.
관리자 권한이 필요하면 미리 말해줘.
```

> 이미 저장소 폴더를 받은 상태라면 위 4번(clone)은 건너뛰어도 됩니다.
