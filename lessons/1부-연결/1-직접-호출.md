# 1부 · 1 — 직접 호출로 시세 가져오기

## 이 단계 목표
AI에게 시장 데이터를 "직접 호출"로 가져오게 해본다. 가장 단순한 형태.

## 📋 복사용 프롬프트
아래를 그대로 복사해 Claude Code / Codex 에 붙여넣으세요.

```
examples/quote.py 를 실행해서 삼성전자(005930) 현재가를 보여줘.
그리고 이 코드가 하는 일을 한 줄로 설명해줘.
```

## 직접 실행하고 싶다면
```
python examples/quote.py 005930
```

## 기대 결과
```
005930 현재가: 307,500원
```
> 기본은 mock 모드라 KIS 키가 없어도, 토요일(휴장)에도 똑같이 나옵니다.
