# 1부 · 2 — MCP로 AI를 국내 주식시장에 연결 (핵심)

## 이 단계 목표
AI가 **무엇을 부를지 스스로 골라** 시세·잔고를 가져오게 만든다.
내가 "이 함수를 이렇게 불러"라고 알려주지 않는다. 목적지와 도구만 준다.

바로 앞에서 읽은 [`0-시작/2-개념`](../0-시작/2-개념-정보전달과-MCP.md)의 그 구조를
직접 씁니다 — 도구 **3개**(검색 · 상세보기 · 호출)로 낯선 API에 도달하는 것.

## 📋 복사용 프롬프트 — 붙이기 (한 줄)

```
이 저장소의 agent/mcp_server.py 를 MCP 서버로 등록해줘.
Claude Code면  claude mcp add kis-lab -- python3 <이 저장소 절대경로>/agent/mcp_server.py
Codex면        codex  mcp add kis-lab -- python3 <이 저장소 절대경로>/agent/mcp_server.py
등록되면 어떤 도구가 연결됐는지 목록으로 보여줘.
```

> 설치할 것도, 켜 둘 것도 없습니다. Docker도 포트도 필요 없습니다.
> 이 서버는 2부에서 쓸 것과 **같은 데이터**를 봅니다 — 지금 붙이는 게 다음 주에도 그대로 돕니다.

> ⚠️ **등록한 뒤 AI 도구를 한 번 껐다 켜세요.** 실행 중인 대화에는 새 MCP 가 안 붙습니다.
> (Claude Code 는 `/mcp` 에서 재연결해도 됩니다.) 껐다 켠 뒤 아래를 물어보면 도구가 보입니다.

연결되면 도구가 3개 보입니다.

| 도구 | 하는 일 | 개념 문서의 그것 |
|---|---|---|
| `search_api` | 뭘 할 수 있는지 찾는다 | 키오스크에서 "A 레스토랑" 검색 |
| `describe_api` | 그 하나가 뭘 요구하는지 본다 | 몇 층 몇 호인지 확인 |
| `call_api` | 실제로 부른다 | 그 층으로 가서 도착 |

## 📋 복사용 프롬프트 — 물어보기

```
삼성전자 현재가를 알려줘.
```

이게 전부입니다. 종목코드도, API 이름도 안 알려줬는데 AI가 알아서 갑니다.

**끝나고 이걸 물어보세요** — 이 단계의 진짜 목표입니다.
```
방금 어떤 순서로 도구를 썼는지, 왜 그 순서였는지 설명해줘.
```
→ 검색으로 `inquire_price` 를 찾고 → 상세보기로 `code` 가 필요한 걸 알고 →
   호출한 흐름이 나옵니다. **330개 문서를 안 줘도 도달한** 그 방식입니다.

## 📋 내 걸로 바꿔 보기 (여기서 손이 움직여야 합니다)

하나만 바꿔서 다시 물어보세요.

```
내 계좌에 지금 뭐가 얼마나 있는지 알려줘.
그리고 그중 제일 큰 비중이 뭔지도.
```
→ 이번엔 `inquire_balance` 를 고릅니다. **같은 도구 3개로 다른 목적지**에 갔습니다.

종목도 바꿔 보세요 — `SK하이닉스`, `현대차`, 아니면 직접 고른 아무 종목.

## 📋 AI가 준 값이 맞나 — 내가 확인하기

붙였으니 이제 **믿어도 되는지** 봅니다. 같은 것을 다른 길로 한 번 더 확인하세요.

```
방금 MCP로 받은 잔고랑, 터미널에서 python agent/agent.py 를 실행한 결과의
총 자산·보유 종목이 같은지 비교해줘. 다르면 어디가 다른지 짚어줘.
```

같아야 정상입니다 — **둘 다 같은 데이터를 봅니다.** MCP로 물어보든 스크립트를 돌리든
결국 같은 곳에서 옵니다. 그래서 2회차의 에이전트가 1회차에 붙인 것과 같은 값을 씁니다.

> 이 확인이 습관이 돼야 합니다. AI가 준 숫자를 **다른 방법으로 한 번 더 보는 것** —
> 뒤에서 주문이 나가기 시작하면 이게 유일한 안전장치입니다.

## ☑️ 넘어가도 되는 신호
- 자연어로 물었을 때 AI가 도구를 **스스로 골라** 값을 답했다.
- 시세 말고 **잔고**도 같은 방식으로 물어봤다.
- AI가 쓴 도구 순서(검색 → 상세보기 → 호출)를 내 말로 설명할 수 있다.
- MCP로 받은 값과 `agent.py` 결과가 같다는 걸 **내가 대조해서** 확인했다.

## 왜 mock 인가 (그리고 언제 진짜가 되나)
수업은 **토요일**이라 증권사 서버가 시세·주문을 받지 않습니다.
그래서 기본은 mock 연습 계좌이고, **이게 정상 경로**입니다 — 구조를 보는 데는
진짜 값이든 연습 값이든 똑같습니다.

평일에 KIS 키를 넣고 `.env` 의 `KIS_MODE` 를 `live` 로 바꾸면, **같은 프롬프트가
그대로 진짜 서버에 붙습니다.** 코드도 등록도 안 바꿉니다. 키 발급은
[`lessons/참고/kis-신청-가이드.md`](../참고/kis-신청-가이드.md).

## MCP vs 직접 호출(01) — 무엇이 달랐나
- **직접 호출(01)**: 내가 `quote.py` 에 종목코드를 넘겨 실행했다. 뭘 부를지 **내가** 정했다.
- **MCP(02)**: 목적지만 말했고 뭘 부를지는 **AI가** 정했다.

미리 뭘 부를지 아는 일은 CLI가 빠르고, 모르는 일은 MCP가 낫습니다.
