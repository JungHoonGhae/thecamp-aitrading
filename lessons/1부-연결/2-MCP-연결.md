# 1부 · 2 — MCP로 AI를 국내 주식시장에 연결 (핵심)

## 이 단계 목표
AI가 **무엇을 부를지 스스로 골라** 시세·잔고를 가져오게 만든다.
내가 "이 함수를 이렇게 불러"라고 알려주지 않는다. 목적지와 도구만 준다.
오늘은 그 소스가 KIS 하나입니다. 남는 것은 못 보는 데이터를 찾아 붙이는 법입니다.

바로 앞에서 읽은 [`0-시작/2-개념`](../0-시작/2-개념-정보전달과-MCP.md)의 그 구조를
직접 씁니다 — 도구 **3개**(검색 · 상세보기 · 호출)로 낯선 API에 도달하는 것.

## 📋 복사용 프롬프트 — 붙이기 (한 줄)

```
이 저장소의 agent/mcp_server.py 를 MCP 서버로 등록해줘.
Claude Code면  claude mcp add kis-lecture-lab -- python3 <이 저장소 절대경로>/agent/mcp_server.py
Codex면        codex  mcp add kis-lecture-lab -- python3 <이 저장소 절대경로>/agent/mcp_server.py
Windows면 python3 자리에 python 을 넣어줘 (Windows 에는 python3 명령이 없습니다).
등록되면 어떤 도구가 연결됐는지 목록으로 보여줘.
```

> 설치할 것도, 켜 둘 것도 없습니다. Docker도 포트도 필요 없습니다.
> 이 서버는 2부에서 쓸 것과 **같은 데이터**를 봅니다 — 지금 붙이는 게 다음 주에도 그대로 돕니다.

개발자 포털의 AI 도구 탭은 셋입니다. 오늘 붙이는 것은 넷 번째, 이 저장소의 **kis-lecture-lab** 입니다.

| 탭 | 하는 일 | 오늘(토) | 평일 숙제 |
|---|---|---|---|
| MCP 소개 | 개념 페이지. 설치할 서버가 아니다 | 안 붙인다 | — |
| 코딩도우미 MCP | 문서 **334** 검색·샘플. **주문 안 함** | 안 붙인다 | 둘러보기만 |
| 트레이딩 MCP | 호출 **166**. 시세·잔고·모의주문. **Docker** | 안 붙인다 | **호출·주문** |
| **kis-lecture-lab** (수업) | 같은 방식. API 다섯. Docker 없음 | **이것만** | 지우지 않음 |

오늘(토)은 kis-lecture-lab이면 됩니다. 평일 숙제는 공식 도구 둘입니다. 코딩도우미로 사면 주문이 안 나갑니다.
트레이딩 MCP는 Docker가 필요합니다. 숙제 프롬프트가 설치부터 합니다. 세부는 [`lessons/참고/kis-mcp-연동-가이드.md`](../참고/kis-mcp-연동-가이드.md).

> ⚠️ **등록한 뒤 AI 도구를 한 번 껐다 켜세요.** 실행 중인 대화에는 새 MCP 가 안 붙습니다.
> (Claude Code 는 `/mcp` 에서 재연결해도 됩니다.) 껐다 켠 뒤 아래를 물어보면 도구가 보입니다.

연결되면 도구가 3개 보입니다.

| 도구 | 하는 일 | 개념 문서의 그것 |
|---|---|---|
| `search_api` | 뭘 할 수 있는지 찾는다 | 키오스크에서 "A 레스토랑" 검색 |
| `describe_api` | 그 하나가 뭘 요구하는지 본다 | 몇 층 몇 호인지 확인 |
| `call_api` | 실제로 부른다 | 그 층으로 가서 도착 |

지금 `search_api` 로 찾을 수 있는 건 **다섯 가지**입니다 — 현재가 · 잔고 · 뉴스 제목 · 시총 순위 · **주문**.
도구는 언제나 세 개입니다. MCP를 바꾸지 않습니다.

> 오늘은 **토요일**이라 증권사 서버가 시세·주문을 받지 않습니다.
> 연습 데이터(mock)로 같은 조회·주문을 합니다. 평일에 `.env` 의 `KIS_MODE` 만 `live` 로
> 바꾸면, **같은 MCP** 가 모의투자 서버를 봅니다.

## 📋 복사용 프롬프트 — 조회 (한 문장씩)

종목코드·API 이름은 주지 않습니다. 한 줄 보내고 답을 본 다음, 다음 줄.

```
내 계좌 잔고 알려줘.
```
```
삼성전자 현재가 알려줘.
```
```
SK하이닉스 시세 얼마야?
```
```
시가총액 상위 10종목 뽑아줘.
```
```
내 보유 종목 뉴스 제목만 보여줘.
```
```
현대차 최근 소식 제목만.
```

앞의 둘은 공식 트레이딩 MCP 소개에 있던 문장입니다. 호가창은 오늘 카탈로그에 없습니다.
문장을 바꿔도 도구는 세 개입니다. 숫자는 연습 값입니다.

한 번에 묶어서 물어도 됩니다.

```
kis-lecture-lab 으로 아래를 전부 알려줘. 종목코드나 API 이름은 주지 마.

1) 내 계좌 잔고
2) 삼성전자 현재가
3) 시가총액 상위 10종목
4) 내 보유 종목의 최근 뉴스 제목

어떤 도구로 뭘 가져왔는지도 한 줄씩 적어줘.
```

종목코드도, API 이름도 안 줬는데 AI가 알아서 갑니다. 숫자는 연습 값입니다.
종목 이름만 바꿔 한 번 더 물어보세요 — 같은 도구 3개로 다른 목적지에 갑니다.

뉴스 제목으로 사고팔지 정하지 마세요. 맛보기입니다. 판단은 3·4주차입니다.

## 📋 복사용 프롬프트 — 주문 (연습 계좌)

```
kis-lecture-lab으로 삼성전자 1주를 시장가로 사는 주문을 미리보기만 해줘. 아직 사지 마.

내가 「주문해」라고 하면 그때 연습 계좌에 넣어줘.
들어가면 접수됐는지, 잔고가 어떻게 바뀌었는지 다시 알려줘.
```

미리 보고, 「주문해」라고 한 뒤에만 넣습니다. 연습 계좌라 토요일에도 접수됩니다. 내 돈이 아닙니다.
이 주문 도구가 숙제의 「주문해」와 같습니다. 공식 트레이딩 MCP를 따로 붙이지 않습니다.
잔고가 바뀌면 정상입니다. 처음 상태로 되돌리려면:

```
python agent/agent.py --reset-mock
```

**끝나고 이걸 물어보세요** — 이 단계의 진짜 목표입니다.
```
방금 어떤 순서로 도구를 썼는지, 왜 그 순서였는지 설명해줘.
```
→ 검색으로 찾고 → 상세보기로 확인하고 → 호출한 흐름이 나옵니다.
**334개 문서를 안 줘도 도달한** 그 방식입니다.

## 📋 내 걸로 바꿔 보기 (여기서 손이 움직여야 합니다)

종목 이름만 바꿔 한 번 더 물어보세요 — `SK하이닉스`, `현대차`, 아니면 직접 고른 아무 종목.
**같은 도구 3개로 다른 목적지**에 가면 됩니다.

## 📋 AI가 준 값이 맞나 — 내가 확인하기

붙였으니 이제 **믿어도 되는지** 봅니다. 같은 것을 다른 길로 한 번 더 확인하세요.

```
방금 MCP로 받은 잔고랑, 터미널에서 python agent/agent.py 를 실행한 결과의
총 자산·보유 종목이 같은지 비교해줘. 다르면 어디가 다른지 짚어줘.
```

같아야 정상입니다 — **둘 다 같은 데이터를 봅니다.** MCP로 물어보든 스크립트를 돌리든
결국 같은 곳에서 옵니다. 그래서 2주차의 에이전트가 1주차에 붙인 것과 같은 값을 씁니다.

> 이 확인이 습관이 돼야 합니다. AI가 준 숫자를 **다른 방법으로 한 번 더 보는 것** —
> 뒤에서 주문이 나가기 시작하면 이게 유일한 안전장치입니다.

## ☑️ 넘어가도 되는 신호
- 자연어로 물었을 때 AI가 도구를 **스스로 골라** 잔고·현재가·시총·뉴스 제목을 답했다.
- 연습 주문을 미리 본 뒤 「주문해」로 넣었고, 잔고가 바뀐 것을 봤다.
- AI가 쓴 도구 순서(검색 → 상세보기 → 호출)를 내 말로 설명할 수 있다.
- MCP로 받은 값과 `agent.py` 결과가 같다는 걸 **내가 대조해서** 확인했다.
- 뉴스 제목이 **판단이 아니라 맛보기**라는 걸 안다.

## 왜 mock 인가 (그리고 언제 진짜가 되나)
수업은 **토요일**이라 증권사 서버가 시세·주문을 받지 않습니다.
그래서 기본은 mock 연습 계좌이고, **이게 정상 경로**입니다 — 구조를 보는 데는
진짜 값이든 연습 값이든 똑같습니다. MCP를 바꾸지 않습니다.

평일에 KIS 키를 넣고 `.env` 의 `KIS_MODE` 를 `live` 로 바꾸면, **같은 프롬프트가
그대로 모의투자 서버에 붙습니다.** 코드도 등록도 안 바꿉니다. 키 발급은
[`lessons/참고/kis-신청-가이드.md`](../참고/kis-신청-가이드.md).

## MCP vs 직접 호출(01) — 무엇이 달랐나
- **직접 호출(01)**: 내가 `quote.py` 에 종목코드를 넘겨 실행했다. 뭘 부를지 **내가** 정했다.
- **MCP(02)**: 목적지만 말했고 뭘 부를지는 **AI가** 정했다.

미리 뭘 부를지 아는 일은 CLI가 빠르고, 모르는 일은 MCP가 낫습니다.

## 더 가고 싶다면 (선택 · 수업 시간엔 안 합니다)

AI가 기본으로 못 보는 데이터는, 내 필요에 맞게 찾아 붙이면 됩니다. 주소를 외울 필요는 없습니다.
붙이고 싶으면 AI에게 **일의 이름만** 말하세요.

```
시장 수급(외국인·기관 순매수)을 보는 데이터 소스를 찾아 리서치하고,
지금 쓰는 코딩 앱에 MCP로 붙여 줘.
수업 본편 서버(kis-lecture-lab)는 그대로 두고, 새 소스만 추가해 줘.
```

일이 바뀌면 소스만 바뀝니다. 공시면 「전자공시(DART)」, 금리면 「한국은행 ECOS」, 해외 시세면 「유료 시세 API」.
스킬은 [skills.sh](https://skills.sh) 와 [k-skill](https://github.com/NomaDamas/k-skill) 에서 찾아도 됩니다.
수업 시간엔 붙이지 않습니다. 본편은 오늘 소스 하나입니다. 숙제 더하기는 [3-1주차-숙제-찾기](3-1주차-숙제-찾기.md).

한투 공식은 손이 둘입니다. 코딩도우미는 문서 **334**개(주문 없음). 트레이딩 MCP는 호출 **166**개(모의주문, Docker).
평일 숙제에서 붙입니다: [`3-1주차-숙제`](3-1주차-숙제.md) · [`kis-mcp-연동-가이드`](../참고/kis-mcp-연동-가이드.md).
