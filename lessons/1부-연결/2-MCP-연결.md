# 1부 · 2 — MCP로 AI를 국내 주식시장에 연결 (핵심)

## 이 단계 목표
KIS 공식 **Trading MCP**를 내 AI 코딩 도구에 붙여, **AI가 실제로 내 모의계좌를 조회**하게
만든다. "모의투자로 삼성전자 현재가 알려줘" 한마디로 진짜 KIS 서버 응답을 받는다.

> 왜 MCP인가? 무엇이 필요할지 미리 몰라도, AI가 도구 3개(검색·상세보기·호출)로
> 스스로 길을 찾는다. (개념: `0-시작/2-개념-정보전달과-MCP.md`)
> 왜 Docker인가? 노트북이 제각각이어도 컨테이너 안은 누구에게나 똑같다(환경 통일).

## 📋 복사용 프롬프트 — MCP 붙이고 등록
```
강사가 준 KIS Trading MCP 컨테이너 이미지를 내 컴퓨터에서 실행하고,
지금 쓰는 이 AI 도구(Claude Code / Codex)에 그 MCP 서버를 등록하는 걸 도와줘.
등록이 끝나면 어떤 도구들이 연결됐는지 목록으로 보여줘.
```

## 📋 복사용 프롬프트 — 실제 모의 조회
```
모의투자로 삼성전자(005930) 현재가를 조회해줘.
이 숫자가 mock이 아니라 진짜 KIS 서버 응답인지도 한 줄로 설명해줘.
```

## 연동 상세 · 실전 가이드
- 등록 설정 예시: `mcp.example.json`
- **검증된 연동법 + 원본을 직접 고쳐 붙이는 실전 가이드**: `lessons/참고/kis-mcp-연동-가이드.md`
  (공식 MCP가 최신 라이브러리와 어긋나는 3곳과 그 수정까지 — 검증 완료)

## 안 될 때 (Docker/등록 실패) → mock 폴백
실습을 멈추지 말 것. mock으로 동일하게 "현재가"를 경험하고 나중에 다시 붙인다.
```
Docker/MCP 연결이 지금 안 돼. 대신 이 저장소의 mock 모드로 삼성전자 현재가를
확인하고, 뭐가 막혔는지도 같이 알려줘.
```

## MCP vs 직접 호출(01) — 무엇이 다른가
- **직접 호출(01)**: 우리가 코드를 실행해서 가져온다(개념 이해용, mock).
- **MCP(02)**: AI가 "무엇을 어떻게 부를지" 스스로 판단해 자연어로 호출한다. 같은 MCP를
  Claude Code에도 hermes에도 붙여 **재사용**한다(N×M→N+M).

## ☑️ 넘어가도 되는 신호
- 자연어로 물었을 때, AI가 MCP 도구를 **스스로 골라** 시세·잔고를 답했다. (명령어를 안 쳤는데도)
