# 1주차 숙제 · 더 찾기 — 스킬 하나, MCP 하나

본편 숙제([공식 도구 + 판단 문서 + 모의주문](3-1주차-숙제.md))에 **더하는** 일입니다.
본편에서 붙인 손(kis-lecture-lab · 코딩도우미 · 트레이딩 MCP)은 그대로 둡니다.
더 찾기는 **다른** 손입니다. 공식 한투 MCP를 여기서 다시 고르지 않습니다.

## 왜 하나

1주차에 본 것은 「AI가 못 보는 데이터는 찾아 붙인다」입니다.
숙제는 사이트를 돌아다니는 일이 아닙니다. **일의 이름을 AI에게 말하면, AI가 찾습니다.**
예시는 AI가 고를 때 참고할 출발점입니다. 학생이 예시를 외울 필요는 없습니다.

## 먼저 — 수업 자료 맞추기

실습 폴더(`verify.py` 가 보이는 곳)를 연 다음:

```
수업 자료 업데이트 해 줘
```

🔄 상자가 뜨면 된 겁니다.

## 본문 — AI에게 세 줄 (브라우저를 열지 마세요)

장터 주소는 AI가 압니다. 학생은 아래만 순서대로 붙입니다.

**1. 구분**

```
스킬과 MCP 가 뭐가 다른지 가르쳐 줘
```

📘 상자. 한 질문씩. 본인 한 줄이 나오면 다음.

**2. 찾기 (일의 이름만. 주소 없음)**

필요를 자기 말로 바꿔도 됩니다.

```
스킬과 MCP 가 뭐가 다른지 가르쳐 줘. 끝나면 내가 말한 일에 맞는 스킬 하나와 MCP 하나를 AI가 찾아 줘. 나는 웹페이지를 직접 열지 않을게. 수업 스킬과 kis-lecture-lab 은 그대로 둬. 공식 KIS 코딩도우미·트레이딩 MCP와 실전 주문은 빼. 고른 이유와 네가 본 길을 한 줄로 말해 줘.
```

일이 정해져 있으면 앞에 한 줄만 덧붙입니다. 예: 「공시를 보고 싶어.」

**3. 한 번 쓰기**

AI가 표를 주면:

```
방금 고른 스킬이랑 MCP로 한 번만 써 보자. 15분 넘게 막히면 놓고 막힌 지점만 남겨.
```

## 할 일 둘 (AI가 찾고, 학생이 확인)

1. **스킬 하나** — AI가 고른 것을 한 번 써 본다.
2. **MCP 하나** — 본편에서 붙인 한투 공식 도구·kis-lecture-lab 이 아닌 것. 조회·리서치. 실전 주문은 빼다.

「AI가 찾다 막힘」도 결과입니다.

## AI가 보는 길 (학생은 열지 않아도 됨)

AI에게 이 길을 쓰라고 이미 적혀 있습니다. 학생이 북마크할 숙제가 아닙니다.

- 스킬: skills.sh · k-skill(NomaDamas/k-skill)
- MCP: mcp.so · smithery · GitHub 검색

k-skill 예는 AI가 고를 수 있는 출발점입니다. `korean-stock-search` · `k-dart` · `daishin-report-search`. 전부 깔지 않습니다.
MCP 일의 예: 전자공시(DART) · 한국은행 금리·환율 · 수급.

## 2주차에 가져올 것 — 네 줄

0. **한 줄** — 스킬과 MCP가 어떻게 다른지, 본인 말
1. **스킬** — AI가 고른 이름 · AI가 본 길 · 한번 써 봤는지
2. **MCP** — AI가 고른 이름 · AI가 본 길 · 붙였는지 / 막힌 점
3. **왜 나인가** — 내 판단(`내-투자-판단.md`)과 어떻게 닿는지 한 줄

안 된 것이 더 좋은 이야깃거리입니다.

한 칸이 끝날 때마다 화면에 **🧃 한입** 상자가 나와야 합니다. 「다음」이라고 한 뒤에만 넘어갑니다.
찾기·쓰기가 끝나면 **🪞 회고** 상자. 이 네 줄이 그 안에 있으면 된 겁니다.

## 하지 말 것

- skills.sh · GitHub · mcp.so 를 **직접** 열고 고르기 (숙제의 목표가 아님)
- kis-lecture-lab · 코딩도우미 · 트레이딩 MCP 를 지우고 다른 것으로 갈아타기
- 실계좌·실전 주문 스킬/MCP
- k-skill **전체** 설치. 고른 하나만
- 15분 넘게 붙잡기
