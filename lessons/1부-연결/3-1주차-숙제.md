# 1주차 숙제 — 평일에 혼자 돌려보기

1주차와 2주차 사이 한 주 동안 하는 것입니다. **장이 열린 평일**에 한 번이면 됩니다.
수업에서 붙인 **kis-lecture-lab** 그대로입니다. 공식 트레이딩 MCP·Docker는 필요 없습니다.

## 왜 하나

수업은 토요일이라 증권사 서버가 쉽니다. 그날은 연습 데이터(mock)로 돌았습니다.
숙제는 **모의투자 신청 → 키 발급 → 내 판단을 글로 남기고 → 그 규칙으로 모의주문 한 번**입니다.
연습 계좌와 뭐가 다른지는 해봐야 압니다. 잘된 것보다 **안 된 것이 2주차에 더 좋은 이야깃거리**입니다.

## 스위치 (이것만 바꿉니다)

같은 MCP, 같은 도구입니다. 바꾸는 것은 `.env` 한 줄입니다.

| 언제 | `.env` | 무엇을 보나 |
|---|---|---|
| 1·2주차 수업 (토) | `KIS_MODE=mock` | 연습 데이터. 키 없어도 됨 |
| **숙제 (평일 9시~15시 반)** | `KIS_MODE=live` + 키 세 개 | 증권사 **모의투자** 서버. 돈은 가짜 |
| 2주차 오기 전 | 다시 `KIS_MODE=mock` | 수업이 다시 연습 데이터로 돌아옴 |

실계좌(`KIS_ENV=real`)는 숙제가 아닙니다. 켜지 마세요.

## 준비 — 신청과 키

아직 없으면 [KIS 신청 가이드](../참고/kis-신청-가이드.md) 순서입니다. 모의투자 참가 → Open API 키 → 모의계좌 앞 여덟 자리.

키는 숙제 명령이 `.env` 에만 넣습니다. 숫자는 화면에 다시 그리지 않게 되어 있습니다.
`.env` 는 남에게 보여주지 마세요.

## 숙제 본체 — 판단 문서 + 모의주문

평일 장중에, 실습 폴더(`verify.py` 가 보이는 곳)를 연 다음 이 두 줄을 **순서대로** 붙입니다.

```
.agents/skills/investment-habit-rules/SKILL.md 대로 내 투자 습관을 하나씩 물어봐 줘. 말한 것만 규칙으로 적고, 그 규칙으로 첫 모의투자까지 가자.
```

끝나면

```
.agents/skills/investment-habit-rules/references/retro.md 대로 방금 모의투자를 회고해 줘. 말한 것만 내-투자-판단.md 회고 칸에 채워. 끝나면 🪞 회고 상자로 보여 줘.
```

남는 파일은 `내-투자-판단.md` 입니다. 2주차가 이 칸을 읽습니다.

키가 있으면 연습 데이터가 아니라 **지금 모의계좌**로 조회·주문이 갑니다.
없으면 연습 계좌로 끝내도 됩니다. 막힌 지점을 2주차에 가져오면 됩니다.

## 2주차 수업 전에

```
.env 의 KIS_MODE 를 mock 으로 되돌려줘.
```

키는 지울 필요 없습니다. 모드만 되돌리면 수업은 다시 연습 데이터입니다.

## 다른 확인 (필수는 아님)

시세만 따로 보고 싶으면 장중에:

```
python examples/quote.py 005930 을 실행해줘.
```

연습 때와 숫자가 다르면 증권사 서버에 붙은 겁니다. Windows 는 `python` 입니다 (`python3` 없음).

`agent/agent.py` 점검·`--execute` 는 **2주차** 본편입니다. 이번 숙제의 주문은 위 스킬 + kis-lecture-lab 입니다.

## 안 될 때

```
.agents/skills/troubleshooting/SKILL.md 대로 고쳐줘
```

| 증상 | 무슨 일인가 |
|---|---|
| 응답이 10초 넘게 안 옴 | 모의투자 서버가 원래 느립니다. 기다리면 옵니다 |
| "초당 거래건수를 초과" | 너무 빨리 여러 번 불렀습니다. 몇 초 뒤 다시 |
| "모의투자 장종료" | 장 시간이 아닙니다. 평일 9시~15시 반에 다시 |
| 토요일인데 live 값이 안 나옴 | 정상입니다. `KIS_MODE=mock` 으로 되돌리세요 |

**15분 넘게 막히면 붙잡지 마세요.** `KIS_MODE=mock` 으로 되돌리면 연습 계좌입니다. 거기까지가 숙제입니다.
