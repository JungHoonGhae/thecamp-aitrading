# 1주차 숙제 — 평일에 혼자 돌려보기

1주차와 2주차 사이 한 주 동안 하는 것입니다. **장이 열린 평일 아무 날이나** 한 번이면 됩니다.

## 왜 하나

수업은 토요일이라 증권사 서버가 쉽니다. 그래서 1주차는 연습 계좌로 돌았습니다.
숙제는 **진짜 증권사 서버에 붙는 첫 경험**입니다. 연습 계좌와 뭐가 다른지는 해봐야 압니다.

여기서 겪은 것을 2주차에 가져와 나눕니다. 잘된 것보다 **안 된 것이 더 좋은 이야깃거리**입니다.

## 준비 — 키 넣기

1주차에 신청한 앱키·시크릿·모의계좌번호를 넣습니다. 아직 없으면 [KIS 신청 가이드](../참고/kis-신청-가이드.md)를 먼저 보세요.

```
.env 파일을 열어서 KIS_MODE 를 live 로 바꾸고,
KIS_APP_KEY / KIS_APP_SECRET / KIS_ACCOUNT 에 내가 받은 값을 넣어줘.
.env 가 없으면 .env.example 을 복사해서 만들어줘.
```

> `.env` 는 남에게 보여주지 마세요. 키는 비밀번호와 같습니다. (git에는 이미 안 올라가게 돼 있습니다)

## 1단계 — 조회가 되는지

장이 열린 평일 **오전 9시~오후 3시 반** 사이에 합니다.

```
python examples/quote.py 005930 을 실행해줘.
```

연습 계좌 때와 값이 다르면 성공입니다. 진짜 지금 가격을 받아온 겁니다.

## 2단계 — 내 계좌 점검 (미리보기)

```
python agent/agent.py 를 실행해서, 지금 내 모의투자 계좌가
스펙에 적힌 비율과 얼마나 어긋나는지 보여줘.
```

새로 만든 모의계좌라면 현금 1천만원에 보유 종목이 없을 겁니다. 그래서 "다 사야 한다"고 나옵니다. 정상입니다.

## 3단계 — 체결까지

미리보기를 읽고 납득이 되면 주문을 넣습니다.

```
python agent/agent.py --execute 를 실행해줘.
```

가드레일에 걸리는 주문은 **여기서 막힙니다.** 막히는 것도 결과입니다 — 무엇이 왜 막혔는지 적어 두세요.

주문이 들어갔으면 잠시 뒤 다시 점검해 봅니다.

```
python agent/agent.py 를 다시 실행해서, 아까와 뭐가 달라졌는지 알려줘.
```

## 4단계 — 텔레그램으로 받아보기 (여력 되면)

[텔레그램 봇 가이드](../참고/telegram-봇-가이드.md)대로 봇을 만들면 결과가 폰으로 옵니다.
2주차에 이 대화창을 그대로 보여주시면 됩니다. 안 해도 숙제는 됩니다.

## 2주차에 가져올 것 — 세 줄

어디에 적어도 됩니다. 폰 메모도 좋습니다.

1. **놀란 것** — 예상과 달랐던 것 하나
2. **막힌 것** — 안 되거나 이해가 안 갔던 것 하나
3. **바꾸고 싶은 것** — 내 스펙에서 손보고 싶어진 것 하나

3번이 2주차 실습의 출발점입니다.

## 안 될 때

**먼저 이걸 치세요.**

```
.agents/skills/troubleshooting/SKILL.md 대로 고쳐줘
```

자주 나오는 것 셋을 미리 알려드립니다.

| 증상 | 무슨 일인가 |
|---|---|
| 응답이 10초 넘게 안 옴 | 증권사 모의투자 서버가 원래 느립니다. 설정 문제가 아닙니다. 기다리면 옵니다 |
| "초당 거래건수를 초과" | 너무 빨리 여러 번 불렀습니다. 몇 초 뒤 다시 하세요 |
| "모의투자 장종료" | 장 시간이 아닙니다. 평일 9시~15시 반에 다시 하세요 |

**15분 넘게 막히면 붙잡지 마세요.** `.env` 에서 `KIS_MODE` 를 지우면 연습 계좌로 돌아옵니다. 거기까지가 숙제고, 막힌 지점을 2주차에 가져오시면 됩니다. 그게 오히려 좋은 재료입니다.
