# 1주차 숙제 — 평일에 혼자 돌려보기

1주차와 2주차 사이 한 주 동안 하는 것입니다. **장이 열린 평일**에 한 번이면 됩니다.

수업(토)은 연습 다섯 개(`kis-lecture-lab`)입니다. 숙제는 **공식 손**을 붙입니다.
한투 공식 MCP는 **둘**입니다. 섞으면 주문이 안 나갑니다.

| 손 | 하는 일 | 개수 | 숙제 |
|---|---|---|---|
| 코딩도우미 MCP | 문서·샘플 검색. **주문 없음** | 334 | 둘러보기만 |
| **트레이딩 MCP** | 시세·잔고·**모의주문** | 166 | **호출·주문은 여기만** |
| kis-lecture-lab | 수업 다섯 | 5 | 토요일·공식 손을 못 붙였을 때 |

트레이딩 MCP는 **Docker** 가 필요합니다. Windows 는 Docker Desktop + WSL 2 입니다.
**설치·실행·연결은 전부 아래 프롬프트가 합니다.** 직접 치실 명령은 없습니다.
설치 창을 한 번 누르고, 앱을 한 번 켜 주시는 것까지가 하실 일입니다.

> **Docker 가 안 되면 숙제를 못 하는 게 아닙니다.** 회사 노트북이라 막히는 분도 있습니다.
> 그때는 수업에서 쓴 `kis-lecture-lab` 으로 **모의주문·잔고·수익률까지 그대로 됩니다.**
> 10분 넘게 막히면 멈추고 「공식 손 못 붙임」 한 줄만 남기세요. 그것도 숙제입니다.

## 왜 하나

수업은 토요일이라 증권사 서버가 쉽니다. 그날은 연습 데이터로 돌았습니다.
숙제는 **모의 키 → 공식 카탈로그를 조회/액션으로 한번 둘러보고 → 나한테 쓸 호출을 고르고 → 그 규칙으로 모의주문 한 번**입니다.
잘된 것보다 **안 된 것이 2주차에 더 좋은 이야깃거리**입니다.

## 스위치

| 언제 | 손 | `.env` |
|---|---|---|
| 1·2주차 수업 (토) | kis-lecture-lab | `KIS_MODE=mock` |
| **숙제 (평일 9시~15시 반)** | 코딩도우미로 둘러보기 + **트레이딩 MCP로 호출** | `KIS_MODE=live` + 키 세 개 |
| 2주차 오기 전 | 다시 kis-lecture-lab | `KIS_MODE=mock` |

실계좌(`KIS_ENV=real`, 트레이딩의 `env_dv=real`)는 숙제가 아닙니다. 켜지 마세요.

## 준비 — 신청과 키

아직 없으면 [KIS 신청 가이드](../참고/kis-신청-가이드.md) 순서입니다. 모의투자 참가 → Open API 키 → 모의계좌 앞 여덟 자리.

키는 숙제 명령이 `.env` 에만 넣습니다. 숫자는 화면에 다시 그리지 않게 되어 있습니다.
`.env` 는 남에게 보여주지 마세요.

## 숙제 본체 — 세 줄 (순서대로)

평일 장중에, 실습 폴더(`verify.py` 가 보이는 곳)를 연 다음 **한 줄씩** 붙입니다.

**1. 공식 손 + 둘러보기 + 고르기** (Docker 포함)

```
.agents/skills/kis-trading-mcp/SKILL.md 대로 공식 손을 붙여 줘. 코딩도우미로 조회와 액션을 한번 둘러보고, 트레이딩 MCP로만 호출해. 나한테 쓸 조회 셋과 액션 하나를 고르자. 코딩도우미로는 주문하지 마.
```

Docker Desktop 설치 창이 뜨면 학생이 클릭합니다. 설치 중 **Use WSL 2** 를 켭니다.
세부는 [`kis-mcp-연동-가이드`](../참고/kis-mcp-연동-가이드.md). 막히면 그 문서를 AI에게 주면 됩니다.

**2. 판단 문서 + 모의주문** (✋ 트레이딩 MCP 만)

```
.agents/skills/investment-habit-rules/SKILL.md 대로 내 투자 습관을 하나씩 물어봐 줘. 말한 것만 규칙으로 적고, 방금 고른 조회·액션과 그 규칙으로 첫 모의투자까지 가자. 주문은 kis-trade-mcp 만. 코딩도우미로는 주문하지 마.
```

**3. 회고**

```
.agents/skills/investment-habit-rules/references/retro.md 대로 방금 모의투자를 회고해 줘. 말한 것만 내-투자-판단.md 회고 칸에 채워. 끝나면 🪞 회고 상자로 보여 줘.
```

남는 파일은 `내-투자-판단.md` 입니다. 2주차가 이 칸을 읽습니다.

키가 없으면 둘러보기·문서만 하고 끝냅니다. Docker가 막히면 「공식 손 못 붙임」을 남깁니다. 그것도 숙제입니다.

## 2주차 수업 전에

```
.env 의 KIS_MODE 를 mock 으로 되돌려줘.
```

키는 지울 필요 없습니다. 모드만 되돌리면 수업은 다시 연습 데이터입니다.
트레이딩 MCP 컨테이너는 꺼 두어도 됩니다. `kis-lecture-lab` 은 지우지 마세요.

## 다른 확인 (필수는 아님)

시세만 수업 랩으로 보고 싶으면 장중에:

```
python examples/quote.py 005930 을 실행해줘.
```

연습 때와 숫자가 다르면 증권사 서버에 붙은 겁니다. Windows 는 `python` 입니다 (`python3` 없음).

`agent/agent.py` 점검·`--execute` 는 **2주차** 본편입니다. 이번 숙제의 공식 주문은 트레이딩 MCP 입니다.

## 안 될 때

```
.agents/skills/troubleshooting/SKILL.md 대로 고쳐줘
```

| 증상 | 무슨 일인가 |
|---|---|
| 코딩도우미로 샀는데 잔고가 그대로 | 그 손은 주문을 안 넣습니다. 트레이딩 MCP 로 |
| Docker / WSL 이 안 됨 | 회사 노트북이면 강사 칸. 15분 넘게 붙잡지 마세요 |
| 응답이 10초 넘게 안 옴 | 모의투자 서버가 원래 느립니다. 기다리면 옵니다 |
| "초당 거래건수를 초과" | 너무 빨리 여러 번 불렀습니다. 몇 초 뒤 다시 |
| `KeyError: 'my_acct'` | `KIS_PROD_TYPE=01` 이 빠졌습니다 |
| "모의투자 장종료" | 장 시간이 아닙니다. 평일 9시~15시 반에 다시 |
| 토요일인데 live 값이 안 나옴 | 정상입니다. `KIS_MODE=mock` 으로 되돌리세요 |

**15분 넘게 막히면 붙잡지 마세요.** 막힌 지점만 남기면 숙제입니다.

## 더하는 숙제 — 스킬 하나, MCP 하나

본편을 한 뒤에 합니다. 나한테 필요한 스킬·MCP를 **어디서 찾는지**가 숙제입니다.
공식 한투 MCP 둘은 이미 본편에서 붙입니다. 더 찾기는 **다른** 손입니다.
[3-1주차-숙제-찾기](3-1주차-숙제-찾기.md) · 찾는 길: skills.sh, **k-skill**, mcp.so.

## ☑️ 넘어가도 되는 신호

아래면 본편 숙제가 된 겁니다. 막힌 한 줄도 신호입니다.

- 코딩도우미와 트레이딩 MCP를 **다르게** 말했다 (주문은 트레이딩만)
- 조회 다섯 · 액션 셋 · **나한테 쓸 조회 셋과 액션 하나**가 화면에 있다
- `내-투자-판단.md` 에 할 것 / 하지 말 것이 있다
- 모의주문을 했거나, 「공식 손 못 붙임」·「주문 안 함」이 회차에 있다
- 🪞 회고 상자가 있다
