# 1부 · 연결 (1주차)

> **1주차 주제 — 자동매매를 위한 바이브코딩 기초 세팅** (AI에 데이터를 연동하는 법)

## 이 파트의 목표
**AI에게 내 데이터를 보여주고, 그 답이 맞는지 내가 확인한다.**
연결은 절반입니다. 붙여 놓고 답을 그대로 믿으면 아무것도 맡길 수 없습니다 —
**확인할 수 있는 것부터** 맡기는 게 이 강의 전체의 순서입니다.

## 끝나면 할 수 있는 것
- 어떤 데이터 소스든 **AI에 연결하는 원리**를 설명할 수 있다 (직접 호출 vs MCP vs CLI).
- **MCP를 내 AI 도구에 붙여** 자연어로 시세·잔고를 받는다. AI가 도구를 스스로 고른다.
- **왜/언제 MCP가 좋은지**(정보는 양이 아니라 구조) 판단 기준을 갖는다.
- AI가 준 값이 맞는지 **내가 다른 방법으로 확인**할 수 있다.

## 직접 하는 것 (실습)
**전부 AI에게 말로 시켜서 합니다.** 설치도, 연결도, 에러 고치는 것도 그렇습니다 —
코드를 직접 치는 자리는 없습니다. 이게 「바이브코딩」이고, 1주차에 몸에 붙일 것입니다.

받아서 실행 → **내가 종목·질문을 바꿔** 다시 조회 → 결과를 읽는다.
- 프롬프트로 환경 세팅(설치도 AI가) → 직접 호출로 시세 → **MCP 붙여 자연어 조회**
- 붙이는 건 저장소 안의 서버라 설치가 없다. Docker는 선택 심화로 내렸다.
