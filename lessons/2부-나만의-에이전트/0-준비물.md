# 0 · 수업 시작과 텔레그램 준비

## 먼저 볼 완성 화면

오늘은 설정 화면부터 시작하지 않습니다. 강사 화면에서 아래 순서를 먼저 봅니다.

```text
처음 한 번  후보 선정 가설의 근거·약점 확인 → 고정 예제
재료 찾기  /ts_tools [순위·가격·수급·실적·계좌·주문]
필요할 때  /ts_analyze → 기술적·펀더멘탈·둘 다 중 선택
핵심 흐름   /ts_status → /ts_analyze [대상] → /ts_order_plan → 「이 주문안 승인」 또는 「보류」
자동 실행   아침·마감 브리핑과 주간 점검은 예약한 시각에 시작
규칙 재검토 전제가 달라졌을 때만 /ts_rule
계좌 변경   /ts_config
```

텔레그램 제품 안에서는 기술적으로 `bot`이라고 부릅니다. 수업에서는 학생이 직접 호출하고
결과를 받는 인터페이스를 **내 투자 에이전트**라고 부르겠습니다.

## 준비 경로 · 두 갈래

### A · 이미 쓰던 실습 폴더

실습 폴더를 코딩 앱에서 연 뒤 아래 한 줄을 보냅니다.

```text
수업 자료를 최신으로 맞추고 python verify.py 까지 실행해 줘.
내-투자-스펙.md, 내-투자-판단.md, .env 는 유지해 줘.
```

`결과: 5/5 통과`면 끝입니다. 1주차 숙제를 못 했어도 오늘은 기본값으로 진행합니다.

### B · 처음 여는 PC 또는 새 폴더

먼저 Claude Code나 Codex에서 수업 폴더를 열고 아래 한 줄을 보냅니다. 저장소 받기와 Python
확인까지 AI가 이어서 합니다. ZIP 파일은 다음 주 업데이트를 이어 받기 어려워 사용하지 않습니다.

```text
지금 연 폴더의 AGENTS.md 와 lessons/0-시작/1-환경-세팅.md 를 읽어 줘.
오늘 실습에 필요한 최소 환경만 준비해 줘.
파이썬 확인과 python verify.py 5/5 까지 네가 진행하고,
내가 눌러야 하는 설치·로그인 창만 한 단계씩 알려 줘.
```

짝·조교와 이 칸을 진행합니다. 수업 본 흐름은 계속되며, 10분 안에 안 되면 강사 화면으로
먼저 따라갑니다.

## 1주차와 숙제는 이렇게 잇습니다

1주차에는 AI가 기본으로 못 보는 시세·잔고를 연결했습니다. 숙제에서는 본인의 투자 습관과
하지 않을 일을 [`내-투자-판단.md`](../../내-투자-판단.md)에 남겼습니다.

숙제를 했든 비어 있든 아래 프롬프트를 보냅니다. **아직 파일은 고치지 않습니다.**

```text
내-투자-판단.md 를 읽고 1주차 숙제를 세 칸으로만 정리해 줘.

1) 오늘 규칙으로 바로 반영 가능한 가드레일
2) Claude Code나 Codex가 검토할 때 참고할 관점
3) 내가 본 산업·종목처럼 수업 후보와 비교할 재료

빈칸은 빈칸이라고 말해 줘. 내용을 지어내지 말고 파일도 아직 고치지 마.
각 칸에서 오늘 반영할 수 있는 예시는 하나만 보여 줘.
```

숙제가 비어 있으면 기본값으로 갑니다. 채운 내용이 모두 오늘 예제와 맞지 않아도 정상입니다.

## 수업 시작 20분 · AI가 Hermes와 Telegram을 연결

Claude Code 또는 Codex에 아래 한 문장을 먼저 보냅니다. AI가 기본 환경을 확인하고 설치와
연결을 이어서 진행합니다. 학생은 Nous 로그인과 Telegram의 **Create Bot**처럼 사람만 할 수
있는 소유 확인에서만 직접 누릅니다. 토큰과 방 번호는 AI가 안전하게 받아 저장하며 화면에
다시 출력하지 않습니다.

```text
2주차 실습 환경 설치해 줘.
내 1주차 파일과 설정은 유지하고,
Hermes 공식 설치 → Nous 무료 로그인 → Docker Desktop → KIS Trading MCP 166 →
Claude ACP → Telegram → TS 연결 → /ts_doctor까지 네가 진행해 줘.
내가 눌러야 할 때만 한 단계씩 알려 줘.
Docker는 평소 8초 안에 확인하고, 설치 직후 첫 시작만 최대 2분 기다려 줘.
그래도 준비되지 않으면 이유를 한 줄로 남기고 수업용 계좌로 계속해 줘.
```

아래 1~3번은 AI가 진행하는 내용을 확인하거나, 다른 PC에서 다시 연결할 때 보는 보조 절차입니다.

### 1. Hermes 무료 라우터 준비

Hermes는 특정 AI 하나에 묶이지 않게 요청을 가능한 작업자에게 넘기는
**오케스트레이션·라우팅 레이어**입니다. Claude/Codex가 없어도 Nous Portal 무료 모델을
사용할 수 있습니다.

한 문장 설치가 이 단계에서 멈췄을 때만 아래를 지금 쓰는 코딩 앱에 보냅니다.

```text
Hermes가 설치돼 있는지 확인하고, 없으면 공식 설치 방법으로 설치해 줘.
hermes setup --portal 로 Nous Portal 무료 로그인을 한 단계씩 도와줘.

로그인 뒤 hermes status 와 hermes fallback list 를 실행해서
1) 지금 기본 작업자
2) 연결된 Claude/Codex 같은 추가 작업자
3) 실패하면 넘어갈 다음 경로
를 쉬운 말로 보여 줘.

내 계정 비밀값을 복사하거나 새 파일에 옮기지 마.
추가 작업자가 연결돼 있지 않아도 무료 모델로 진행 가능하다고 알려 줘.
```

`hermes portal info`에 `logged in`이 보이면 무료 경로는 준비됐습니다. Nous 모델은 별도
프로그램을 설치하는 것이 아니라 로그인 후 Hermes가 고르는 무료 작업자입니다. 복잡한
분석은 Claude ACP → Claude CLI → Codex CLI → Nous 무료 모델 순서로 시도합니다. 공식
CLI의 로그인 저장소를 사용하며 OAuth 토큰을 복사하지 않습니다.

### 2. 텔레그램 인터페이스 만들기

폰 또는 PC에 [Telegram 공식 앱](https://telegram.org/apps/download)을 설치하고 로그인합니다.
그다음 코딩 앱에 아래 한 문장을 보냅니다.

```text
python hermes/setup_course.py --managed-telegram 를 실행해 줘.
Telegram이 열리면 내가 눌러야 하는 Create Bot 버튼만 알려 주고,
토큰·방 번호 저장과 Hermes 연결은 네가 끝내 줘. 비밀값은 다시 보여 주지 마.
```

Telegram에서 **Create Bot**을 한 번 누르면 사용자 소유의 새 투자 에이전트가 만들어집니다.
표시 이름·사용자명·토큰·내 대화 ID를 따로 입력하거나 브라우저 주소에서 찾지 않습니다.
이 공식 Managed Bot 화면이 열리지 않는 PC에서만
[@BotFather 수동 절차](../참고/telegram-봇-가이드.md#수동-대체-경로)를 사용합니다.

### 3. 기존 BotFather 봇을 다시 연결할 때

이미 BotFather로 만든 개인 봇이 있는 사람만 아래 문장을 사용합니다.

```text
lessons/참고/telegram-봇-가이드.md 대로 내 투자 에이전트를 연결해 줘.
토큰은 이거야: (BotFather가 준 토큰)

.env 가 없으면 만들고, 내 방 번호를 찾아 넣은 뒤
python hermes/setup_course.py --from-project-env 를 실행하고
Hermes gateway를 다시 시작해 줘.
토큰은 화면에 다시 출력하지 마.
```

내 투자 에이전트가 켜진 동안 폰에서 `/ts_help`를 보냅니다. `/ts_update`, `/ts_doctor`,
`/ts_auth`, `/ts_status`, `/ts_tools`, `/ts_config`, `/ts_analyze`, `/ts_rule`, `/ts_order_plan`, `/ts_memory`가
보이고 답이 오면 연결 완료입니다. 이어서 `/ts_doctor`에서 모두 ✅인지 확인합니다.
Hermes 기본 명령도 그 아래 함께 보입니다. 노트북을 닫으면 응답도 멈춥니다. 고장이 아닙니다.
승인 버튼을 기다리는 화면은 2분 뒤 자동으로 끝납니다. 분석이나 설치가 2분에 강제로 끊긴다는
뜻은 아닙니다. 다른 명령이 막힌 것처럼 보이면 `/stop`을
보낸 뒤 원래 명령을 다시 보냅니다.

## ☑️ 넘어가도 되는 신호

- `python verify.py`가 5/5입니다.
- 1주차 숙제를 세 칸으로 나눠 봤습니다. 비어 있어도 됩니다.
- `hermes status`에서 Nous Portal 무료 경로를 확인했습니다.
- `/ts_doctor`에서 Docker·KIS 166·Claude ACP 상태를 확인했습니다. Docker가 불가하면 이유가
  보이고 mock 경로가 유지됩니다.
- 폰에서 `/ts_help`에 답이 옵니다. 연결이 늦으면 강사 화면으로 진행해도 됩니다.
