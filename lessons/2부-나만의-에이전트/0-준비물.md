# 오늘 손으로 깔 것 — 시작 전 10분

1주차와 같습니다. 손으로 하는 것은 **앱 설치와 로그인**뿐입니다.
나머지(파일 고치기·키 넣기·확인)는 「~해 줘」 한 줄로 AI가 합니다.

## 손으로 하는 건 딱 2가지

| | 무엇 | 왜 오늘 필요한가 | 시간 | 없으면 |
|---|---|---|---|---|
| 1 | **텔레그램** 앱 + 내 봇 | 폰으로 보고를 받고 **승인**을 되돌려 보낸다 | 5분 | 화면으로만 실습 |
| 2 | **hermes** 로그인 (무료) | 자는 동안 혼자 돌린다 | 5분 | crontab 으로 대체 |

둘 다 **없어도 수업은 진행됩니다.** 설치가 **20분**을 넘기면 여기서 멈추고
[1-예제-실행](1-예제-실행.md)으로 갑니다. 강사 화면과 노트북 명령이 오늘 본편입니다.

---

## 1. 텔레그램 — 폰으로 받고, 폰에서 승인한다

### 1-1. 앱 설치

**폰은 필수입니다.** 주문 승인 버튼을 폰에서 누릅니다.
노트북 앱은 선택이지만, 토큰을 복사해 붙이기가 훨씬 편합니다.

| 어디 | 링크 |
|---|---|
| iPhone · iPad | [App Store](https://apps.apple.com/app/telegram-messenger/id686449807) |
| Android | [Google Play](https://play.google.com/store/apps/details?id=org.telegram.messenger) |
| macOS | [telegram.org/dl/macos](https://telegram.org/dl/macos) |
| Windows | [telegram.org/dl/desktop/win64](https://telegram.org/dl/desktop/win64) |
| 설치 없이 | [web.telegram.org](https://web.telegram.org) — 폰 인증이 한 번 필요합니다 |

전체 목록은 [telegram.org/apps](https://telegram.org/apps) 입니다.
가입에는 **휴대폰 번호**가 필요합니다. 인증 문자가 오니 폰을 옆에 둡니다.

### 1-2. 내 봇 만들기 — 3분

강사 봇을 같이 쓰지 않습니다. **각자 자기 봇**을 만듭니다. 무료입니다.

1. 텔레그램에서 [**@BotFather**](https://t.me/BotFather) 를 열고 `/newbot` 을 보냅니다.
2. 표시 이름 → `@…bot` 으로 끝나는 사용자명 순으로 정합니다.
3. BotFather 가 준 **토큰**(긴 문자열)을 복사합니다. **공유·업로드 금지** — 이건 열쇠입니다.
4. 방금 만든 봇을 검색해 열고 **`/start`** 를 한 번 보냅니다. (이걸 안 하면 다음 단계에서 숫자가 안 보입니다)

자세한 순서와 화면은 [`telegram-봇-가이드`](../참고/telegram-봇-가이드.md) 에 있습니다.

### 1-3. 저장소에 붙이기 — 여기서부터 AI

```
lessons/참고/telegram-봇-가이드.md 대로 텔레그램 보고를 붙여 줘.
토큰은 이거야: (BotFather 가 준 토큰)

1) .env 가 없으면 .env.example 을 복사해서 만들어 줘.
2) getUpdates 로 내 chat id 를 찾아 TELEGRAM_CHANNEL_ID 에 넣어 줘.
3) python agent/agent.py 로 도착하는지 확인해 줘.
4) 토큰은 화면에 다시 그리지 마.
```

### 1-4. 봇 켜 두기

```
python agent/telegram_bot.py
```

폰에서 `/config` 를 보내 **표가 오면** 된 겁니다. 기본값이 이미 있습니다.
칸을 고치려면 `/update_config` 뒤에 바꿀 말을 적습니다. `/help` 는 가져가는 것 다음에 목록이 옵니다.
자료가 바뀌면 `/update` 로 맞춥니다. 내 스펙·판단·`.env` 는 그대로입니다.

- **노트북이 켜져 있어야 답합니다.** 닫으면 멈춥니다. 고장이 아닙니다.
- 봇은 **내 방에서 온 말만** 듣습니다. 이름은 누구나 검색할 수 있습니다.

## 2. hermes — 자는 동안 (무료)

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash   # mac / Linux / WSL2
hermes setup --portal    # Nous Portal 무료 로그인 (카드 등록 없음)
hermes --tui             # 채팅이 되면 성공
```

- **Windows 는 WSL2 안에서** 돌립니다. WSL2 가 없으면 이 단계는 건너뛰고 작업 스케줄러를 씁니다.
- 이미 쓰는 Claude Code / Codex 를 hermes 에 다시 붙일 필요 없습니다.
  (Claude Pro 구독으로는 hermes 의 Anthropic 로그인이 되지 않습니다.)
- **막혀도 됩니다.** 예약이 목적이지 hermes 가 목적이 아닙니다.
  폴백은 crontab 한 줄이고 [`4-자동화-hermes-예약`](4-자동화-hermes-예약.md) 의 A 항목입니다.
