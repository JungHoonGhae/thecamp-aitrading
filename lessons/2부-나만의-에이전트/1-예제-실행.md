# 2부 · 1 — 후보를 지수와 견주기

## 장면

완성된 예제를 고치기 전에 **왜 이 후보인가**를 먼저 봅니다. 가설을 빈칸으로 쓰지 않습니다. 이름이 붙은 후보를 견주고 하나만 남깁니다.

가져가는 한 줄: **지수를 이겼는지 본 뒤에야 본편으로 씁니다.** 안 이긴 후보는 버립니다.

긴장 한 박: 한국에 같은 규칙을 쓰면 숫자가 약합니다. 그걸 본편으로 쓰지 않습니다.

숨 한 박: 이 화면은 아직 주문이 아닙니다. 채택·승인은 다음 장입니다.

## 후보 세 개

| | 후보 | 수업에서 |
|---|---|---|
| 1 | 시총 상위 다섯 종목, 같은 금액 | 이미 있는 기본 스펙. 고르는 메뉴가 아닙니다. 여기서 시작합니다. |
| 2 | 미국 대형주, 직전 한 달 빼고 1년 성적 상위 | **본편.** 나중 구간에서 지수보다 나았습니다. |
| 3 | 한국 대형주, 같은 규칙 | **버립니다.** 같은 규칙이어도 수업 본편으로 쓰지 않습니다. |

산다 · 판다 · 보유는 [`내-투자-스펙.md`](../../내-투자-스펙.md) 와 같은 말입니다.

- **산다**: 직전 한 달을 빼고 1년 성적이 상위인 종목을 다음 한 달 같은 금액으로
- **판다**: 다음 달 점검에서 순위 밖이면 바꿈
- **보유·점검**: 안 움직여도 `/journal` 에 한 줄
- **한도**: 고점 대비 -10%는 재검토 알림. 자동으로 팔지 않음

강사가 출처와 구현을 확인했다는 뜻이지, 이 규칙이 앞으로 수익을 낸다는 뜻이 아닙니다.

## 📋 복사용 프롬프트

```text
python agent/committee.py 를 실행해 줘.
약점, 반대 근거, 다음 질문과 제안 번호까지만 확인하고,
스펙 채택이나 주문은 하지 마.
```

직접 실행하려면:

```bash
python3 agent/committee.py
```

설치된 AI로 설명을 다시 만들려면 `--with-ai`를 붙입니다. AI를 찾지 못하면 수업용
고정 설명으로 끝납니다. 종목과 비중 숫자는 AI 문장에서 가져오지 않습니다.

한국 바스켓을 보려면 `--market KR` 을 붙입니다. 수업에서 채택할 기본 시장은 미국입니다.
한국이 약하면 그게 학습입니다. 본편으로 가져가지 않습니다.

## 화면에서 볼 것

- 이전 구간(2016–2020)과 나중 구간(2021–2025)의 비용 후 결과
- 벤치마크보다 나았는지(차이). 한국이 약하면 그게 기대하는 학습입니다
- AI 검토: 약점 · 반대 근거 · 다음 질문
- 스펙 변경안: 최근 월 상위 종목 동일 비중, 현금 10%
- 매도: 1개월마다 다시 순위, 고점 -10%는 재검토
- 제안 번호: 다음 단계에서 사람이 채택할 정확한 제안
- “아직 주문이 아닙니다”

고정 바스켓·비공식 조정주가입니다. 실시간 추천이나 수익률 예측이 아닙니다.

## ☑️ 넘어가도 되는 신호

- 미국 후보는 본편, 한국 후보는 버린다는 것을 한 줄로 말할 수 있습니다.
- “아직 주문이 아닙니다”를 확인했습니다.
- 약점(생존편향)과 반대 근거를 한 줄로 말할 수 있습니다.
- 종목과 비중이 좋아 보인다는 이유만으로 주문하지 않았습니다.
