# 2부 · 1 — 예제 에이전트 그대로 실행 (수정 없이)

## 이 단계 목표
강사가 준비한 예제 에이전트를 **손대지 않고** 먼저 돌려본다.
"완성되면 이렇게 작동한다"를 만들기 전에 눈으로 확인한다.
(이 예제는 정답이 아니라, 검증 중인 하나의 예시입니다.)

## 📋 복사용 프롬프트
```
agent/agent.py 를 실행해서, agent/spec 폴더의 내 투자 원칙대로
지금 계좌가 얼마나 맞는지 점검한 결과를 보여줘.
```

## 직접 실행하고 싶다면
```
python agent/agent.py
```

## 기대 결과 (예)
```
[모의데이터] 포트폴리오 점검 결과
총 자산: 10,000,000원 (현금 1,960,500원)

- 삼성전자(005930): 목표 20% / 현재 36.9% → 매도 약 5주  ⚠️조정필요
- SK하이닉스(000660): 목표 20% / 현재 23.2% → 매도 약 0주
- LG에너지솔루션(373220): 목표 20% / 현재 10.5% → 매수 약 2주  ⚠️조정필요
- 삼성바이오로직스(207940): 목표 20% / 현재 0.0% → 매수 약 1주  ⚠️조정필요
- 현대차(005380): 목표 20% / 현재 9.8% → 매수 약 2주  ⚠️조정필요

리밸런싱 미리보기:
- 삼성전자: 매도 5주 (약 1,537,500원)
- ...
※ 미리보기입니다. 실제 주문하려면 --execute 를 붙이세요.
※ 신뢰는 한 단계씩. 실전(실계좌) 매매는 이 실습 범위 밖입니다.
```
> 기본 실행은 **미리보기**라 주문이 나가지 않습니다. 실제 모의주문은 3-재실행-리밸런싱에서 `--execute` 로.
> 이미 몇 종목을 보유해 목표와 어긋난 상태라, **매도·매수 신호가 섞여** 나옵니다.
> 이게 리밸런싱의 핵심입니다. 아직 아무것도 안 고쳤어요 — 다음 단계에서 이 원칙을
> 내 것으로 바꿉니다.

## ☑️ 넘어가도 되는 신호
- 점검 보고 **미리보기**가 출력됐고, `※ 미리보기입니다` 안내가 보였다. (주문은 나가지 않음)
- 출력 끝의 **차트 링크**를 열면 목표 vs 현재 비중이 그림으로 보인다. (디스코드로 보내면 이미지로 펼쳐짐)
