# 2부 · 1 — 후보를 지수와 견주기

## 이 단계 목표
완성된 예제를 고치기 전에 **왜 이 후보인가**를 숫자로 봅니다.
지수를 이겼는지 본 뒤에야 본편으로 씁니다. 안 이긴 후보는 버립니다.
이 화면은 아직 주문이 아닙니다.

## 화면을 읽기 전에

숫자를 보기 전에 네 말만 씁니다.

| 말 | 뜻 |
|---|---|
| **고정 바스켓** | 지금 구성 종목을 과거에도 고정해 계산한 수업용 묶음 |
| **생존편향** | 살아남은 종목만 과거로 가져가 성적이 실제보다 좋아 보이는 치우침 |
| **벤치마크** | 비교 기준 지수(미국 SPY · 한국 069500). 「이겼다」는 항상 이 기준 대비 |
| **비용 후** | 매수·매도 수수료를 뺀 뒤. 수업 숫자는 전부 비용 후 |

## 후보 세 개

| | 후보 | 수업에서 |
|---|---|---|
| 1 | 시총 상위 다섯 종목, 같은 금액 | 이미 있는 기본 스펙. 고르는 메뉴가 아닙니다. 여기서 시작합니다. |
| 2 | 미국 대형주, 직전 한 달 빼고 1년 성적 상위 | **본편.** 나중 구간에서 지수보다 나았습니다. |
| 3 | 한국 대형주, 같은 규칙 | **버립니다.** 같은 규칙이어도 수업 본편으로 쓰지 않습니다. |

산다 · 판다 · 보유는 [`내-투자-스펙.md`](../../내-투자-스펙.md) 와 같은 말입니다.

- **산다**: 직전 한 달을 빼고 1년 성적이 상위인 종목을 다음 한 달 같은 금액으로
- **판다**: 다음 달 점검에서 순위 밖이면 바꿈
- **보유·점검**: 안 움직여도 `/journal` 에 한 줄
- **한도**: 고점 대비 -10%는 재검토 알림. 자동으로 팔지 않음

강사가 출처와 구현을 확인했다는 뜻이지, 이 규칙이 앞으로 수익을 낸다는 뜻이 아닙니다.

## 📋 복사용 프롬프트

```text
python agent/committee.py 를 실행해 줘.
약점, 반대 근거, 다음 질문과 제안 번호까지만 확인하고,
스펙 채택이나 주문은 하지 마.
```

직접 실행하려면:

```bash
python agent/committee.py
```

설치된 AI로 설명을 다시 만들려면 `--with-ai`를 붙입니다. AI를 찾지 못하면 수업용
고정 설명으로 끝납니다. `--with-ai` 를 붙이면 약점 문장과 **제안 번호**가 달라질 수 있습니다.
종목과 비중 숫자는 AI 문장에서 가져오지 않습니다.

## 기대 결과

고정 설명( `--with-ai` 없음 )이면 아래와 같습니다. 숫자가 같고, 맨 아래에 `제안 번호:` 가 있으면 통과입니다.

```
참조 실험 · 미국 주식 판단 제안
──────────────────────────────────────────────────────────
고정 바스켓·비공식 조정주가를 사용한 학습용 결과입니다. 수익 보장이나 투자 추천이 아닙니다.
자료 기준일: 2025-12
이전 구간 비용 후 +439.9% · 벤치마크 차이 +337.9%p
나중 구간 비용 후 +232.7% · 벤치마크 차이 +137.3%p

[AI 검토 · 주문 권한 없음]
약점: 고정 바스켓에는 생존편향이 있어 시장 전체 결과로 일반화할 수 없습니다.
반대 근거: 시장과 기간에 따라 모멘텀 결과가 약하거나 반대로 나타날 수 있습니다.
다음 질문: 한 종목 최대 비중을 낮추면 오늘 주문이 막히는가?

스펙 변경안
  GOOGL  30%
  NVDA   30%
  JPM    30%
  현금   10%

매도·손절 제안
  1개월마다 다시 순위를 매겨 목표 밖 종목은 매도
  고점 대비 -10%이면 자동 매도하지 않고 원문과 가설을 다시 검토

제안 번호: 8549bca55c349bf78c92ee9fad98f70b1e6f685ec8f01085a19a524b904ae2be
아직 주문이 아닙니다. 이 제안을 채택할지는 사람이 정합니다.
```

`+137.3%p` 옆의 약점이 생존편향입니다. 숫자가 커 보여도 시장 전체 성과로 읽지 않습니다.

**제안 번호**는 64자리 영숫자입니다. 다음 단계에서 `--adopt` 뒤에 붙입니다.
이 번호는 **생각 한 장의 이름표**입니다. 아직 주문이 아닙니다.

## 한국은 같은 규칙이어도 버립니다

지수를 이겼는지 숫자로 확인하는 명령이 이 두 줄입니다.

```bash
python agent/committee.py
python agent/committee.py --market KR
```

한국 나중 구간은 이렇게 나옵니다.

```
이전 구간 비용 후 +102.3% · 벤치마크 차이 +8.6%p
나중 구간 비용 후 +171.3% · 벤치마크 차이 +62.2%p
```

미국 +137.3%p, 한국 +62.2%p. 한국이 약하면 그게 학습입니다. 본편으로 가져가지 않습니다.

## ☑️ 넘어가도 되는 신호

- 미국 후보는 본편, 한국 후보는 버린다는 것을 한 줄로 말할 수 있습니다.
- “아직 주문이 아닙니다”와 제안 번호 한 줄을 확인했습니다.
- 약점(생존편향)과 반대 근거를 한 줄로 말할 수 있습니다.
- 종목과 비중이 좋아 보인다는 이유만으로 주문하지 않았습니다.
