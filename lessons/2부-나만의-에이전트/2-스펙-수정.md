# 2부 · 2 — 판단 제안을 스펙으로 채택

## 이 단계 목표

AI가 낸 문장을 바로 쓰지 않습니다. 약점과 반대 근거를 읽은 뒤, 사람이 제안 번호를
확인해 스펙으로 채택합니다. 이것이 첫 번째 사람 개입입니다.

수업에서 고치는 값은 **한 종목 최대 비중** 하나입니다. 진입·청산 문장과 종목 목록은
바꾸지 않습니다.

## 📋 복사용 프롬프트

`(제안 번호)`에는 앞 화면의 번호를 붙입니다.

```text
방금 참조 실험의 약점과 반대 근거를 다시 짧게 보여 줘.
내가 채택한다고 답한 뒤에만 아래 미리보기를 실행해 줘.

python agent/us_agent.py --adopt (제안 번호)

주문 계획은 보여 주되 실행하지 마.
```

직접 실행하려면:

```bash
python3 agent/us_agent.py --adopt (제안 번호)
```

제안 번호가 다르면 멈춥니다. AI에게 비슷한 번호를 추측하게 하지 말고
`python3 agent/committee.py`부터 다시 확인합니다.

## 코드 가드레일 보기

예제의 한 종목 목표는 약 30%입니다(상위 3종목 동일 비중). 최대 비중을 15%로 낮추면
전부 차단됩니다. **오늘 학생이 만져 보는 값은 이 숫자 하나**입니다.

```bash
python3 agent/us_agent.py --adopt (제안 번호) --max-weight 15
```

사람이 제안을 채택해도 가드레일을 넘을 수 없습니다. AI가 “이번만 괜찮다”고 말해도 같습니다.

1주차 `내-투자-스펙.md` 표 ①은 이미 채워져 있습니다. 여기서 전략을 고르거나 종목을
새로 설계하지 않습니다. 칸을 고치려면 `/update_config` 입니다.

## ☑️ 넘어가도 되는 신호

- 제안의 약점과 반대 근거를 읽고 채택했습니다.
- 주문 미리보기와 **주문 계획 번호**가 나왔지만 주문은 실행되지 않았습니다.
- 최대 비중 15%에서 주문이 차단되는 것을 확인했습니다.
- 제안 번호와 주문 계획 번호가 다른 이유를 말할 수 있습니다.
