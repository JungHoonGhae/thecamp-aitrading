# 2부 · 2 — 내 원칙으로 스펙 수정

## 이 단계 목표
기본값(시총 상위 균등)을 **한 번 본 다음**, AI에게 내 말을 걸어 표를 채우게 한다.
코드는 건드리지 않는다. 기계가 리밸런싱하고, **무엇을 담을지는 내가 AI와 정한다.**

> 왜 기계식만 두면 안 되나: 그 상태로는 AI가 계산기일 뿐이다.
> 왜 진입·청산까지 안 하나: 그건 3~4회차다. 여기서 AI는 **스펙을 인터뷰**한다.

## 무엇을 고치나
입력은 한 곳: [`내-투자-스펙.md`](../../내-투자-스펙.md) 표. 네 칸이 각각 다른 데로 갑니다 —
①은 목표 비중, ③은 조정 필요 판정 기준, ④는 주문 차단, **②는 보고에 「오늘이 점검일인지」**.
반영은 한 줄:
```
python sync_spec.py
```
(`python` 이 없으면 `python3`)

## 📋 필수 — 스펙 인터뷰 (이 단계의 본편)

아래를 그대로 붙여넣되, **두 번째 줄만 내 말로** 바꾸세요.
```
내-투자-스펙.md 표를 내 상황에 맞게 채워줘.
나는 (예: 월급 일부로 장기 적립, 반도체 쏠림이 걱정, 종목은 3개면 충분) 이야.

규칙:
- 국내 종목만, 비중 합 100.
- 한 종목 40% 넘지 말 것. 몰빵·레버리지는 넣지 말 것.
- **내가 이름을 아는 회사를 최소 한 곳은 넣어줘.** 내가 쓰는 물건이나 서비스를
  만드는 회사면 좋겠어. 그게 뭔지는 내가 말해줄게.
- 왜 이 종목·비중인지 각 한 줄로 설명해줘. 수익을 단정하지 마.
- 다 채우면 python sync_spec.py 하고 python verify.py 로 5/5 확인해줘.
- 에이전트 주문은 아직 넣지 마.
```

### 한 종목은 꼭 내가 고르세요

나머지는 몰라도 됩니다. 다만 **하나는 내가 아는 회사**로 바꾸세요.
평소 쓰는 앱, 자주 가는 곳, 다니는 회사의 경쟁사 — 뭐든 좋습니다.

이유는 두 가지입니다.

1. 다음 화면부터 **내가 고른 회사 이름이 뜹니다.** 남의 표를 돌리는 것과 완전히 다릅니다.
2. 「내가 아는 것에 투자한다」는 오래된 원칙이기도 합니다. 정답이라서가 아니라,
   **내가 왜 담았는지 설명할 수 있는 종목**이라야 나중에 팔지 말지도 판단됩니다.

> 나머지 칸은 확신이 없으면 기본값 그대로 둬도 됩니다. **한 종목만** 내 것으로.

## AI가 채운 표를 그대로 믿지 않기 (이 단계의 진짜 배움)

방금 AI가 표를 채웠습니다. **맞는지 확인해 보세요.**

두루뭉술하게 말할수록 AI는 빈칸을 자기 판단으로 메웁니다. 그게 나쁜 게 아니라,
**그래서 확인이 필요한 것**입니다. 일부러 애매하게 한 번 더 시켜 보세요.

```
내-투자-스펙.md 표를 다시 채워줘. 나는 "요즘 잘 나가는 걸로 안전하게" 하고 싶어.
```

나온 표를 **세 가지로 검토**하세요. 답은 정해져 있지 않습니다 — 따지는 게 목적입니다.

1. **왜 이 종목인가?** — "잘 나간다"는 내 말이지 근거가 아닙니다. AI가 든 이유가
   납득되나요? 안 되면 그렇게 말하세요.
2. **"안전하게"를 AI가 뭐라고 해석했나?** — 종목 수? 업종 분산? 현금 비중?
   내가 생각한 안전과 같은가요?
3. **내가 말 안 한 걸 AI가 정했나?** — 점검 주기, 허용 오차는 내가 언급도 안 했습니다.
   무슨 값이 들어갔나요?

이제 반박해 보세요.
```
2번이 내 생각과 달라. 나한테 안전은 ______ 야. 그 기준으로 표를 다시 짜줘.
```

### 여기서 무엇이 갈리는가

돌려 보면 **기계가 잡는 실수**와 **사람만 잡을 수 있는 실수**가 나뉩니다.

```
python sync_spec.py
python agent/agent.py
```

| 기계가 잡는다 | 사람만 잡는다 |
|---|---|
| 비중 합이 100이 아님 | 왜 하필 이 종목인지 근거가 없음 |
| 모르는 종목 이름 | 내가 생각한 "안전"과 다른 해석 |
| 한 종목이 한도 초과 | 내가 말 안 한 값을 AI가 임의로 정함 |
| ④에 적은 금지어에 걸림 | 내 상황에 안 맞는 주기·오차 |

**오른쪽 칸은 코드가 영원히 못 잡습니다.** 그래서 미리보기가 기본이고, 실행에 `--execute`가
따로 필요하고, 가드레일이 최후에 한 번 더 막는 겁니다. 「신뢰 게이트」가 왜 있는지가
여기서 나옵니다 — AI가 멍청해서가 아니라, **내가 말 안 한 걸 누군가는 정해야 하기 때문**입니다.

> 확인이 끝나면 내 원칙대로 되돌리세요.
> ```
> 아까 인터뷰로 채운 내 표(또는 기본값)로 되돌려 sync 해줘.
> ```

## 한 단어로 종목 막아 보기 — ④ 「절대 안 하는 것」

한도(숫자)만 안전장치가 아닙니다. **말로 적은 금지**도 주문을 막습니다.
`내-투자-스펙.md` ④에 단어를 하나 더해 보세요.

```
내-투자-스펙.md 의 ④ 「절대 안 하는 것」 끝에 · 바이오 를 추가하고
python sync_spec.py 로 반영한 다음, python agent/agent.py 를 실행해줘.
```
→ 이렇게 뜹니다.
```
⛔ 가드레일 위반 (주문 차단):
- 삼성바이오로직스 — 스펙 ④에 적은 「바이오」 에 걸립니다 (이 종목 주문 차단)
```

**④에 적은 말이 종목 이름에 들어 있으면 그 종목을 막습니다.** 「한 종목 몰빵」처럼
이름으로 판정할 수 없는 건 위의 한도(한 종목 최대 비중)가 대신 막고요.

확인했으면 되돌리세요.
```
④에서 방금 추가한 · 바이오 를 빼고 다시 sync 해줘.
```

> 여기가 이 수업의 핵심입니다. 코드를 한 줄도 안 고쳤는데,
> **내가 표에 적은 말이 실제로 주문을 막았습니다.**

## ☑️ 넘어가도 되는 신호
- 인터뷰(또는 기본값)가 `sync_spec.py` 로 반영됐고, `verify.py` 가 5/5 이다.
- AI가 채운 표에서 **내가 말하지 않은 값**을 하나 찾아냈고, 반박해서 고쳤다.
- 「기계가 잡는 실수 / 사람만 잡는 실수」를 한 줄로 말할 수 있다.
- ④에 단어를 하나 더했더니 그 종목이 막혔고, 되돌렸다.
