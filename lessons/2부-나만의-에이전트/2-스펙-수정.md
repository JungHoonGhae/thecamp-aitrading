# 2부 · 2 — 내 원칙으로 스펙 수정

## 이 단계 목표
`agent/spec/` 의 마크다운 몇 줄만 고쳐서 에이전트를 "내 것"으로 바꾼다.
코드는 건드리지 않는다. **규칙을 코딩하는 게 아니라 선언**한다.

## 무엇을 고치나 (`agent/spec/` 안)
- `portfolio.md` — 담을 종목과 목표 비중 (합 100)
- `rules.md` — 리밸런싱 주기·허용 오차
- `guardrails.md` — 한 종목 최대 비중·현금 최소 보유 (기본 안전 한도)

## 0. 내 스펙을 반영하기 — 기계식 한 줄

0-시작에서 고친 [`내-투자-스펙.md`](../../내-투자-스펙.md) 의 표(①~④)가
에이전트의 스펙이 됩니다. 반영은 **AI 없이도 되는** 한 줄:

```
python sync_spec.py
```

표 ①은 `portfolio.md` 로, ②③은 `rules.md` 로, ④는 `guardrails.md` 의
"하지 마"로 갑니다. 이 순간부터 에이전트는 **여러분의 표**로 점검합니다.
값이 바뀌면 표를 고치고 이 한 줄을 다시 — 코딩이 아니라 선언.

> 왜 이렇게 기계식부터? 판단 없는 규칙(패시브)을 먼저 완주해야
> 판단이 들어가는 액티브(3~4회차)에 얹을 기반이 생깁니다.
> 근거와 순서는 [`내-투자-스펙.md`](../../내-투자-스펙.md) 3절 참조.

## 📋 응용 — AI에게 의도로 말하기 (골라 쓰세요)
```
내-투자-스펙.md 의 표를 배당 위주의 안정적인 3종목으로 채워줘.
다 고치면 python sync_spec.py 로 반영하고 python verify.py 로 확인해줘.
```
또는
```
내-투자-스펙.md 의 ①을 지수 ETF 로 바꿔줘 — KODEX 200 60 · TIGER 미국S&P500 40.
반영(sync_spec)과 확인(verify)까지 해줘.
```
또는 (고급 — 실행 스펙 직접)
```
agent/spec/guardrails.md 의 '하지 마'에 "내가 모르는 업종(바이오)" 금지를 추가하고,
'한 종목 최대 비중'을 35%로 낮춰줘.
```

## 가드레일 '체험' — 일부러 한 번 걸려보기
안전 한도가 실제로 어떻게 작동하는지 눈으로 보려면, 일부러 한도를 넘겨보세요.
```
agent/spec/portfolio.md 에서 삼성전자 비중을 45%로 올리고 SK하이닉스를 5%로 바꿔줘.
(나머지는 그대로) 그다음 agent/agent.py 를 실행해서 어떤 경고가 뜨는지 보여줘.
```
→ 실행하면 "가드레일 경고: 삼성전자 목표비중 45% > 한도 40%" 가 뜹니다. 이렇게
스펙이 스스로 "이 선을 넘었다"고 알려주는 걸 확인한 뒤, 다시 안전한 값으로 되돌리세요.
```
방금 바꾼 걸 원래대로(각 20%) 되돌려줘.
```

> ⚠️ 스펙 몇 줄로 기본 제약을 선언할 수는 있지만, 이것만으로 온전히
> 안전해지는 건 아닙니다. 그 한계와 보완은 마무리에서 다룹니다.

## ☑️ 넘어가도 되는 신호
- `python sync_spec.py` 가 내 표를 3개 파일에 반영했고, `python verify.py` 가 여전히 4/4 통과다.
- 일부러 한도를 넘겨봤을 때 `가드레일 경고: … > 한도 40%` 가 떴고, 다시 되돌렸다.

> 🧭 **초록이(진행 도우미)에게** — 막혔으면 이 한 줄을 복붙하세요:
> `.agents/skills/assistant/SKILL.md 대로, 내가 지금 어느 단계에서 막혔는지 진단하고 다음 행동을 하나만 알려줘.`
