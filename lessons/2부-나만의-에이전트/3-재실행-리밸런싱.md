# 2부 · 3 — 재실행 · 리밸런싱

## 이 단계 목표
내 스펙대로 다시 점검하고, **미리보기 → 가드레일 → 모의 주문**의 신뢰 게이트로
실제 리밸런싱까지 해본다. (선택) 디스코드로 보고가 오게 연결한다.

## 📋 복사용 프롬프트 — 재실행 비교
```
agent/agent.py 를 다시 실행해서, 내가 바꾼 원칙대로 결과가
달라졌는지 이전과 비교해서 설명해줘.
```

## 리밸런싱 — 신뢰 게이트 (미리보기 → 실행)
기본 실행은 **미리보기**입니다. 무엇을 얼마나 사고팔지만 보여주고, 주문은 넣지 않습니다.
```
python agent/agent.py
```
확인했으면 **--execute** 로 실제 모의 주문을 전송합니다. (mock은 시뮬레이션)
```
python agent/agent.py --execute
```
- 가드레일(한 종목 한도·비중 합)을 **위반하면 --execute 여도 주문을 차단**합니다.
- 📋 프롬프트로:
```
지금 스펙 기준 리밸런싱을 먼저 미리보기로 보여주고, 가드레일을 통과한 주문만
실제 모의투자로 실행하는 걸 도와줘. 실행 전에 한 번 더 확인해줘.
```

## (선택) 디스코드로 보고 받기
디스코드 채널의 웹훅 URL을 환경변수로 넣으면 화면 대신 디스코드로 갑니다.
```
DISCORD_WEBHOOK="https://discord.com/api/webhooks/..." python agent/agent.py
```
웹훅 만드는 법(5분): [`lessons/참고/discord-웹훅-가이드.md`](../참고/discord-웹훅-가이드.md)

## (선택) mock → 실제 모의투자(live)로 전환
지금까지는 mock(모의 데이터)로 돌렸습니다. 내 KIS 모의투자 키로 실제 서버 조회를
해보고 싶다면 아래 프롬프트를 붙여넣으세요. (키 발급: `lessons/참고/kis-신청-가이드.md`)
```
내 KIS 모의투자 키로 실제로 돌려보고 싶어. .env.example 을 복사해 .env 를 만들고
KIS_MODE=live 와 내 앱키·시크릿·모의계좌번호를 넣는 걸 도와줘. 그다음
`KIS_MODE=live python agent/agent.py` 로 실제 계좌 기준 점검이 되는지 확인해줘.
.env 는 절대 공유하지 말라고 알려줘.
```
> 주의: 토요일 등 휴장일엔 실시간 조회·모의주문이 제한됩니다. 그럴 땐 mock(시뮬레이션)으로
> 흐름을 익히고, 평일에 같은 프롬프트로 실행해보세요.
> 이 저장소는 **모의투자**까지만 — 실제 돈이 오가는 실전(실계좌) 매매 기능은 없습니다.

## 마무리
이 에이전트는 **모의투자 리밸런싱까지** 합니다(실계좌 아님). 완전 자동매매로 가려면
읽기 전용 → 확인(미리보기) → 모의 자동 → 실전으로 '신뢰의 게이트'를 한 단계씩 넘어야
합니다. 스펙 몇 줄로 안전이 완성되지는 않습니다(자세히는 [`9-마무리`](../9-마무리/README.md) 참고).
