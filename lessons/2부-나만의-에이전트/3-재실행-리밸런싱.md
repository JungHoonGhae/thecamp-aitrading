# 2부 · 3 — 재실행 · 리밸런싱

## 이 단계 목표
내 스펙으로 **미리보기 → 가드레일 → 연습 계좌 체결**까지 간다.
체결 뒤에는 AI에게 **해석만** 시킨다. 주문을 더 넣게 하지 않는다.
(선택) 텔레그램으로 같은 보고를 받는다.

## 리밸런싱 — 신뢰 게이트 (미리보기 → 실행)
기본은 **미리보기**입니다. 무엇을 얼마나 사고팔지만 보여주고, 주문은 넣지 않습니다.
```
python agent/agent.py
```
### 📋 필수 — 넣기 전에 AI에게 한 번 물어보기

미리보기가 나왔으면, **실행 전에** AI에게 검토를 시킵니다. 여기가 이 수업에서
AI가 실행 경로에 서는 자리입니다 — **주문을 내지는 않고, 내가 놓친 걸 짚습니다.**

```
방금 python agent/agent.py 미리보기 결과를 봐줘. 주문은 절대 넣지 마.
내-투자-스펙.md 의 내 원칙과 대조해서 세 가지만 답해줘.

1. 이 주문 계획이 내가 적은 ①비중·③오차·④하지마 와 어긋나는 데가 있나?
2. 내가 표에 안 적었지만 실행에 영향을 준 게 있나? (현금 최소선 같은 것)
3. 지금 실행하면 내가 예상 못 할 결과가 있나? 있으면 딱 하나만 짚어줘.

없으면 "없다"고 해줘. 억지로 찾지 마.
```

AI가 뭘 짚으면 **스펙을 고치고 다시 미리보기**하세요. 없다고 하면 넘어갑니다.

> 왜 이 단계가 있나: 계산은 코드가 하고, 차단은 가드레일이 합니다. 그런데
> **「내가 이걸 정말 의도했나」는 둘 다 못 봅니다.** 그 자리를 AI가 메웁니다.
> 사람이 확인 버튼을 누르던 걸, 확인할 거리를 AI가 먼저 정리해 주는 셈입니다.

확인했으면 **--execute** 로 연습 계좌에 넣습니다. 토요일이어도 잔고가 바뀝니다.
```
python agent/agent.py --execute
python agent/agent.py
```
두 번째 실행에서 비중이 목표에 가까워져 있어야 합니다.
처음 상태로: `python agent/agent.py --reset-mock`

- 가드레일을 **위반하면 --execute 여도 주문을 차단**합니다.

### 출력 맨 아래 한 줄 — 내가 정한 점검 주기

```
※ 점검 주기는 「매주 월요일, 장 시작 전」 — 오늘은 그날이 아닙니다.
```

스펙 ②에 적은 값입니다. `내-투자-스펙.md` 의 ②를 `매일` 로 바꿔 sync 하면
"오늘이 그날입니다"로 바뀝니다. 이걸로 **표 네 칸이 전부 실행에 닿는 걸** 봤습니다 —
①은 목표 비중, ②는 이 줄, ③은 조정 필요 판정, ④는 주문 차단.
(실제 자동 실행은 다음 단계에서 hermes/crontab이 맡습니다.)

## 📋 필수 — 체결 후 리뷰어 (3~4회차 맛보기)

주문이 반영된 뒤, 아래를 붙여넣으세요. **추가 주문은 금지**입니다.
```
방금 agent/agent.py 결과를 보고 세 가지만 답해줘. 주문은 넣지 마.
1. 무엇이 줄고 늘었는지, 초등학생도 알게.
2. 내-투자-스펙.md 의 ④(하지 마)와 가드레일을 지켰는지.
3. 이 리밸런싱의 리스크를 한 줄. 수익은 단정하지 마.

마지막으로, 3~4회차에서 쓸 "판단 메모"를 아래 빈칸 형식 그대로 채워서 제안해줘.
내 스펙(종목·비중·오차·가드레일)과 방금 결과에서 근거를 끌어와.

  나는 ______ 한 종목을 사고,
  ______ 하면 팔고,
  ______ 만큼만 위험을 지고 싶다.
  (선택) 그리고 AI가 종목을 볼 때 ______ 관점으로 판단했으면 좋겠다.

정답을 단정하지 말고 "지금 내 스펙에서 유추하면 이렇다" 로 써줘. 저장은 내가 할게.
```

이게 이 수업에서 AI 판단의 자리입니다. 비중 계산은 코드, **의미는 대화**입니다.
