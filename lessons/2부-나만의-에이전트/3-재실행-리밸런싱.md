# 2부 · 3 — 정확한 주문 승인과 로컬 모의체결

## 이 단계 목표

확정 스펙에서 코드가 계산한 종목·방향·수량·지정가를 읽습니다. 화면에서 본 정확한
**주문 계획 번호**를 다시 승인한 뒤에만 미국 연습 계좌가 움직입니다.

## 먼저 미리보기

```bash
python agent/us_agent.py --adopt (제안 번호)
```

화면에 나온 주문의 종목, 수량, 지정가를 읽고 맨 아래 주문 계획 번호를 확인합니다.
목록이 세 줄이어도 정상입니다. 1년 성적(직전 한 달 제외) 상위 20%가 세 종목이기 때문입니다.

## 📋 복사용 프롬프트

```text
방금 주문 미리보기의 종목·방향·수량·지정가를 다시 보여 줘.
내가 정확한 주문 계획 번호를 승인한 뒤에만 미국 연습 계좌에서 실행해 줘.

python agent/us_agent.py --adopt (제안 번호) \
  --approve (주문 계획 번호) --execute

주문 계획이 바뀌었거나 가드레일에 걸리면 실행하지 말고 다시 보여 줘.
```

직접 실행하려면:

```bash
python agent/us_agent.py --adopt (제안 번호) \
  --approve (주문 계획 번호) --execute
```

승인 번호가 다르면 주문은 0건입니다. 가드레일 위반도 승인으로 통과하지 못합니다.

처음 상태로 되돌리기:

```bash
python agent/us_agent.py --reset-mock
```

## 체결 뒤 회고

AI에게 해석만 맡깁니다. 추가 주문은 시키지 않습니다. 산 이유·판 이유·안 움직인 이유는
`/journal` 또는 `내-투자-판단.md` 에 한 줄로 남깁니다.

```text
방금 미국 연습 계좌 체결 결과를 보고 세 가지만 답해 줘. 추가 주문은 하지 마.
1. 어떤 종목을 몇 주 샀고 현금이 얼마나 남았나?
2. 한 종목 최대 비중과 현금 최소 10%를 지켰나?
3. 다음 검증에서 가장 먼저 확인할 위험은 무엇인가?
```

## ☑️ 넘어가도 되는 신호

- 정확한 주문 계획 번호를 승인하기 전에는 주문이 나가지 않았습니다.
- 승인 뒤 미국 연습 계좌 체결 결과와 남은 현금을 확인했습니다.
- 가드레일을 승인으로 우회할 수 없다는 것을 설명할 수 있습니다.
- 실제 돈이 움직이지 않았습니다.
