# 2부 · 5 — 숙제: 기본 스펙으로 직접 실행

## 이 단계 목표
수업의 기본 분석 규칙을 다시 설계하지 않습니다. **이미 저장한 시스템 규칙**으로 직접
돌리고, 산 이유·판 이유·안 움직인 이유를 남깁니다. 취향이 있으면 가드레일 한 칸만
`내-투자-스펙.md`에서 고칩니다. 안 고쳐도 숙제입니다.

## 1 · 무엇을 하나

| | 수업 | 숙제 |
|---|---|---|
| 시스템 규칙 | 처음 한 번 저장 | `/ts_rule`의 현재 규칙으로 확인. 주문마다 다시 채택하지 않음 |
| 가드레일 | 기본값이 이미 있음 | 고칠 때만 스펙 한 칸 수정·동기화 |
| 사이클 | 진입 · 청산 · 기록 | 산 이유 · 판 이유 · 안 움직인 이유 |
| 루틴 | 아침·가격도달·마감 | 수업에서 못 끝낸 예약만 이음 |

주간·월간·연간 브리핑을 더 만들지 않습니다. 리밸런싱 주기를 3개월로 새로 설계하지 않습니다.

## 2 · 돌려 보기

텔레그램이 있으면:

```text
/ts_analyze AAPL
/ts_rule
/ts_order_plan
```

`/ts_analyze`에서 기술적 분석·펀더멘탈 분석·둘 다 분석 가운데 하나를 고릅니다.
분석은 주문과 분리해 읽습니다. 그 뒤 `/ts_rule`에서 현재 규칙을 확인하고 주문 계획의
종목·수량·가격을 읽어 승인 버튼을 누릅니다. 안 움직였어도 `/ts_memory`에서 오늘 대화와
본인 판단을 돌아봅니다.

노트북만 있으면:

```bash
python agent/agent.py
```

미리보기만 나옵니다. 주문을 내려면 수업 때와 같이 승인 뒤에 `--execute` 입니다.

칸 하나를 바꿔 보려면 코딩 앱에 말합니다. `/ts_config`는 계좌 종류만 바꾸는 명령이며
가드레일을 고치지 않습니다.

```text
내-투자-스펙.md에서 허용 오차만 7%p로 바꾸고 내 스펙을 반영해 줘.
다른 규칙은 유지하고 python sync_spec.py 와 python verify.py 까지 실행해 줘.
```

말한 칸만 바뀝니다. 종목 메뉴를 새로 만들지 않습니다.

## 3 · 한 줄 회고

빈칸은 학생이 채웁니다.

```text
기본 스펙으로 직접 실행하며 본 것은 ______.
칸을 바꿨으면 그 칸은 ______ 이고, 이유는 ______.
다음에 유지하거나 버릴 것은 ______.
```

AI는 초안을 제안할 수 있지만, 마지막 문장은 내가 확정합니다.

## 4 · 평일 모의주문은 선택

공식 도구가 준비되어 있으면
[6-평일-KIS-해외주식](6-평일-kis-해외주식.md)으로 갑니다.
10분 안에 연결되지 않으면 수업용 계좌로 같은 주문을 보고 회고합니다.

실계좌 주문은 숙제가 아닙니다.

## 텔레그램과 예약이 남았다면

수업에서 못 끝낸 사람만 [4-Hermes 예약](4-자동화-hermes-예약.md)을 이어서 합니다.
Telegram에서 아침 브리핑을 수동 실행한 뒤 평일 오전 8시로 예약합니다. 브리핑은 조회와
보고만 하며 주문안을 만들거나 주문을 실행하지 않습니다.

## ☑️ 넘어가도 되는 신호

- 저장된 규칙으로 주문 계획을 한 번 봤습니다.
- 기술적 분석과 펀더멘탈 분석 가운데 하나를 텔레그램에서 다시 읽었습니다.
- 산 이유·판 이유·안 움직인 이유 가운데 한 줄을 내가 적었습니다.
- 칸을 고쳤다면 `내-투자-스펙.md` 한 칸뿐이고 동기화·5/5 확인까지 마쳤습니다.
- 주간·월간·연간 브리핑을 만들지 않았습니다.
