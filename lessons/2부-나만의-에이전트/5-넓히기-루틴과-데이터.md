# 2부 · 5 — 넓히기: 데이터를 붙이고, 루틴으로 돌린다

## 이 단계 목표
리밸런싱 하나로 끝내지 않는다. **KIS 밖 데이터를 붙이고, 정해진 시각에 혼자 돌게 만든다.**
여기서부터는 강사가 만든 것을 그대로 쓰다가, 고치다가, 없는 것을 붙이는 순서로 넓힌다.

> 앞 네 단계가 끝나지 않았어도 됩니다. 이 문서는 따로 읽어도 됩니다.

## 왜 넓히나 — KIS 는 「지금 값 한 점」만 줍니다

수업에서 쓰는 한국투자증권 모의투자는 **현재가·잔고·뉴스 제목·시총**을 줍니다.
과거 시세가 없습니다. 그래서 이런 질문을 아예 물을 수가 없습니다.

- 지금 이 가격이 1년 안에서 어디쯤인가
- 요즘 얼마나 흔들리나
- **내 포트폴리오가 코스피보다 잘했나**

밖에서 붙이면 이 질문이 성립합니다. 1주차에 배운 「AI가 못 보는 데이터는 찾아 붙인다」가
여기서 그대로 쓰입니다.

## 무엇이 붙어 있나

| 어디서 | 무엇 | 공식인가 | 키 |
|---|---|---|---|
| `common.kis` | 현재가 · 잔고 · 뉴스 제목 · 시총 · **주문** | **공식** (한국투자증권) | 필요 |
| `common.crypto` | 코인 시세 · 일봉 | **공식** (업비트) | 없음 |
| `common.market` | 과거 시세 · 코스피 · 환율 · 공포지수 · 섹터 | 비공식 (야후) | 없음 |
| `common.judge` | AI 판단 한 마디 | 내 코딩 앱 | 구독 |

각 모듈은 혼자 점검됩니다. 붙어 있는지 보려면 이렇게 합니다.

```
python src/common/market.py
python src/common/crypto.py
python src/common/judge.py
```

> **공식과 비공식은 무게가 다릅니다.** 야후는 문서 없는 주소라 예고 없이 막힐 수 있습니다.
> 공부에는 씁니다. 돈이 걸린 판단의 근거로는 쓰지 않습니다.
> **주문은 언제나 공식(KIS)으로만 나갑니다.**

## 📋 분석 네 갈래 — 하나씩 돌려 봅니다

```
python examples/analysis/1-정량-후보고르기.py
python examples/analysis/2-정성-뉴스브리프.py
python examples/analysis/3-시장맥락-벤치마크.py
python examples/analysis/4-섹터-쏠림점검.py
```

| 갈래 | 무엇을 보나 | 여기서 배우는 것 |
|---|---|---|
| **정량** | 시총 상위에서 스펙 ④ 로 거른 후보 | 숫자는 「무엇을 볼지」만 정합니다 |
| **정성** | 내 종목 뉴스 제목을 모아 AI에게 넘길 브리프 | 코드는 모으고, 읽는 것은 사람과 AI 입니다 |
| **시장 맥락** | 내 포트폴리오 vs 코스피 · 환율 · 공포지수 · 코인 | 내 숫자는 시장 안에서만 뜻이 있습니다 |
| **섹터** | 내 종목이 어느 업종에 몰려 있나 | 다섯 종목이 전부 반도체면 분산이 아닙니다 |

각 파일 위쪽에 **「여기를 고쳐 보세요」** 칸이 있습니다. 기간·기준·볼 종목이 몇 줄로 놓여 있습니다.
그 몇 줄만 바꿔도 답이 달라집니다.

### ☑️ 넘어가도 되는 신호
- 네 갈래 중 하나라도 돌아갔고, 나온 숫자를 한 줄로 설명할 수 있다.
- **섹터 쏠림**이나 **코스피 대비**에서 내가 몰랐던 것을 하나 찾았다.

## 루틴 — 정해진 시각에 혼자 돌게

**루틴**은 정해진 주기에 혼자 도는 작은 일입니다. 결과는 **루틴 알림**으로 옵니다.
목록과 알림 예시는 [`routines/README.md`](../../routines/README.md) 에 있습니다.

```
python routines/아침브리핑.py
python routines/내전략-백테스팅.py
python routines/저점고점-판독.py
```

카테고리로 위험이 이름에 보이게 해 두었습니다. **주문이 나가는 것은 리밸런싱 하나뿐입니다.**

| 카테고리 | 주문 |
|---|---|
| 정보수집 · 스크리닝 · 매매제안 | 안 나감 |
| 리밸런싱 | **나감 · 승인 필요** |

### 내 전략 백테스팅 — 내 규칙이 과거에 통했나

가장 먼저 돌려 볼 만합니다. 스펙 ①②를 **과거 시세에 그대로 돌려** 「가만히 두기」·코스피와 견줍니다.

```
python routines/내전략-백테스팅.py
```

> **기간을 바꿔서 다시 돌려 보세요. 답이 바뀌면 그건 규칙이 아니라 운이었다는 뜻입니다.**
> 수수료와 세금은 계산에 들어 있지 않습니다. 과거에 통했다고 앞으로 통하지도 않습니다.

## 📋 필수 — 텔레그램으로 받기

결과를 화면에서만 보면 자동화가 아닙니다. 폰으로 받아야 내가 없을 때도 옵니다.
봇 만드는 법은 [`telegram-봇-가이드`](../참고/telegram-봇-가이드.md) 입니다. 5분이면 됩니다.

```
lessons/참고/telegram-봇-가이드.md 대로 텔레그램 보고를 붙여 줘.
토큰은 이거야: (BotFather 가 준 토큰)

1) .env 가 없으면 .env.example 을 복사해서 만들어 줘.
2) getUpdates 로 내 chat id 를 찾아 TELEGRAM_CHANNEL_ID 에 넣어 줘.
3) python agent/agent.py 로 도착하는지 확인해 줘.
4) 토큰은 화면에 다시 그리지 마.
```

### 폰에서 시키기 — 봇을 켜 두면 명령이 됩니다

```
python agent/telegram_bot.py
```

켜 두면 폰에서 `/help` `/check` `/balance` `/candidates` `/news` `/spec` `/routines` 가 됩니다.
`/rebalance` 는 **승인**을 한 번 더 받고서야 주문을 냅니다.

- 봇은 **내 방에서 온 말만** 듣습니다. 봇 이름은 누구나 검색할 수 있습니다.
- **노트북이 켜져 있어야 답합니다.** 닫으면 멈춥니다. 이건 고장이 아닙니다.

## 예약 — 내가 없을 때

두 가지가 다릅니다. 하나는 **시각**, 하나는 **사건**입니다.

| 무엇 | 언제 | 어떻게 |
|---|---|---|
| 아침 브리핑 | 매일 정해진 시각 | `hermes cron --no-agent` (또는 crontab) |
| 가격 도달 | **언제 올지 모름** | `hermes cron --monitor-script` |

정기 루틴만 쓸 거라면 **crontab 으로 충분합니다.** hermes 가 값을 하는 자리는 두 번째입니다.
`가격도달-감시.py` 는 알림을 보내지 않고 **상태 한 줄만** 찍습니다.
hermes 가 직전 출력과 견줘 **바뀌었을 때만** 깨웁니다. 같으면 조용합니다.

```
routines/README.md 의 「정해진 시각에 돌리기」 대로 아침 브리핑을 예약해 줘.

1) hermes 가 없으면 설치해 줘. 로그인은 무료 Nous Portal 이야.
2) hermes/scripts/morning-brief.py 를 ~/.hermes/scripts/ 로 복사하고
   REPO 를 이 저장소 절대경로로 고쳐 줘.
3) 평일 아침 8시에 --no-agent 로 예약해 줘. hermes 가 LLM 을 쓰지 않게 해.
4) 한 번 강제로 실행해서 폰에 오는지 보고, hermes cron list 로 보여 줘.
```

> hermes 설치가 막히면 crontab 한 줄로도 같습니다. **예약이 목적이지 hermes 가 목적이 아닙니다.**

## 여기서부터 여러분 것 — 세 단계

| | 무엇 | 예 |
|---|---|---|
| 01 | **그대로 가져와 씁니다** | `python routines/아침브리핑.py` |
| 02 | **살을 붙입니다** | 파일 위쪽 「지시사항」 몇 줄을 바꿉니다 |
| 03 | **없는 것을 붙입니다** | 재무(DART) · 검색량 · 공시 알림 |

03 이 3·4주차로 가는 다리입니다. 지금 우리 시스템에 **없는 것**은 이렇습니다.

- **재무제표** — 전자공시(DART). 키는 무료·즉시 발급입니다. 펀더멘탈 분석이 여기서 열립니다.
- **검색량 · 커뮤니티 반응 · 공시 알림** — 아직 없습니다.

없다는 것을 아는 게 먼저입니다. 붙이는 방법은 1주차 「찾기」에서 이미 배웠습니다.

### 내 루틴 만들기

`routines/` 에 파일 하나를 더하면 그게 내 루틴입니다.

```python
from _routine import 루틴, 정보수집

r = 루틴("내 루틴 이름", 정보수집)
r.칸("무엇을 볼까")
r.줄("여기에 내가 보고 싶은 것")
r.보내기()
```
