# 2부 · 나만의 AI 투자 에이전트 (2회차)

## 이 파트의 목표
**검증 가능한 일 하나를 에이전트에게 맡기고, 안전선을 긋는다.**

그 일이 리밸런싱입니다. 왜 하필 이것이냐 — **내가 답을 채점할 수 있는 거의 유일한 과제**이기
때문입니다. 목표 20%인데 현재 36.9%면 팔아야 한다, 이건 직접 계산해서 맞는지 확인됩니다.
3·4회차의 "언제 살까"는 몇 주 지나야 맞았는지 압니다.

**채점할 수 없는 일부터 맡기면 신뢰를 배울 수 없습니다.** 그래서 여기가 먼저입니다.

## 끝나면 할 수 있는 것
- 말로 한 원칙이 표 → 에이전트 점검으로 이어진다.
- **AI가 채운 표를 그대로 믿지 않고 검토·반박**할 수 있다. 기계가 잡는 실수와
  사람만 잡는 실수가 다르다는 걸 안다.
- 미리보기 → 가드레일 차단 → 연습 계좌 체결을 눈으로 본다.
- 체결 결과를 AI가 해석하고, 3~4회차용 판단 메모 4줄 초안이 생긴다.
- 텔레그램으로 같은 보고를 받는다. **hermes** 로 말로 예약한다 (막히면 crontab).

## 직접 하는 것
- 예제 그대로 실행 → **스펙 인터뷰**로 내 표 채우기 → 가드레일 한 번 걸어보기
- `--execute` 후 비중이 움직이는지 확인 → **리뷰어** 프롬프트
- hermes 로 예약 (막히면 텔레그램 + crontab)

## 준비/주의
- 기본은 **미리보기**. `--execute` 일 때만 연습 계좌가 움직인다.
- 실전은 졸업 스위치(수업 밖). 3~4회차는 액티브로 확장하는 시간이다.
- 토요일은 증권사 서버가 안 됩니다. **연습 계좌가 수업의 본편**입니다.
