# 2주차 · 모의투자로 배우는 안전한 자동화 구조

## 오늘 도착할 곳

가설 검토는 시스템을 만들 때 **처음 한 번** 합니다. 오늘은 검토할 예제가 이미
고정되어 있으며, 학생이 매 주문마다 다시 채택하지 않습니다. 그 뒤 텔레그램의
**내 투자 에이전트**에서는 아래 순서로 진행합니다.

```text
처음 한 번: 유저 스토리 → 후보 선정 가설의 근거·약점 확인 → 고정 예제
재료 찾기: /ts_tools [순위·가격·수급·실적·계좌·주문]
필요할 때: /ts_analyze → 기술적·펀더멘탈·둘 다 중 선택
핵심 흐름: /ts_status → /ts_analyze [대상] → /ts_order_plan → 승인 또는 보류
자동 실행: 아침·마감 브리핑과 주간 점검은 예약한 시각에 시작
규칙 재검토: 전제가 달라졌을 때만 /ts_rule
설정 변경: /ts_config → 계좌 종류·기술적 분석 지표
```

결과는 **지수와 비교한 기술적 분석**, **공식 자료를 우선한 펀더멘탈 분석**, **모바일 분석
보고서**, **연습 계좌 체결 한 번**, **자동 활동 기록과 선택한 투자 원칙**입니다. 실제 돈은 움직이지 않습니다. 예약은 같은
프로그램을 정해진 시각에 시작해 결과를 텔레그램으로 보냅니다.

## 오늘의 학습용 예제

오늘은 KIS에서 조회할 수 있는 **시가총액 순위와 일별 시세**로 간단한 후보 선정
규칙을 만듭니다. 이 규칙은 정답이나 추천이 아니며, 자료 조회·계산·AI 설명·사람 승인을
나눠 연결하는 방법을 익히기 위한 예제입니다.

기본 분석 규칙은 다음 한 문장입니다.

> **KIS 시가총액 상위 30개 가운데 현재가가 20일선 위이고 20일선이 60일선 위인 종목을
> 먼저 고르면, 사람이 이유를 설명할 수 있는 검토 후보를 세 개까지 줄일 수 있을까?**

KIS의 순위·가격·수급·실적 재료로 후보가 같은 입력에서 다시 나오는지 확인합니다. 이것은
**후보 선정 절차의 재현**이지 지수 초과수익 검증이 아닙니다. 지수를 이겼다고 말하려면
기간·비용·생존편향을 갖춘 별도 백테스트가 필요합니다. AI는 공식 자료의 위험과 다음 질문을
읽고, 주문의 종목·수량·가격은 사람이 이미 채택한 목표를 규칙 코드가 계산합니다.

지수는 비교 기준입니다. 후보 세 개가 나와도 자동 주문으로 이어지지 않습니다.

## 학습 목표

수업이 끝나면 다섯 가지를 설명하고 직접 보여 줄 수 있습니다.

1. 1주차 숙제의 생각을 **가드레일 · AI 참고 · 후보 재료**로 나눕니다.
2. KIS 166개 도구를 가격·순위·수급·실적·계좌·주문 재료로 구분합니다.
3. AI · 규칙 코드 · 사람 · 텔레그램 · 예약의 역할을 구분합니다.
4. 처음 한 번의 규칙 채택과 매번 필요한 주문 승인을 구분합니다.
5. 장이 닫혀 있어도 텔레그램에서 기술적·펀더멘탈·시장 분석을 읽습니다.

## 시스템은 역할별로 나눕니다

| 층 | 오늘 쓰는 것 | 하는 일 | 하지 않는 일 |
|---|---|---|---|
| 재료 | KIS 166개 조회 · 외부 시세 · 공식 공시 · 내 숙제 | 읽고 계산할 근거를 줌 | 주문 결정 |
| 오케스트레이션 | Hermes | 가능한 작업자로 라우팅, 실패 시 폴백 | 주문 승인 |
| AI 작업자 | Claude · Codex · Nous 무료 모델 | 약점 · 반대 근거 · 다음 질문 | 수량 계산 · 주문 |
| 규칙 코드 | `agent/` | 비중·수량 계산, 가드레일 차단 | 가드레일 임의 변경 |
| 사람 | 학생 | 예제의 한계 확인, 정확한 주문 승인 | 승인 뒤 내용 바꾸기 |
| 인터페이스 | 텔레그램 | 수동 호출, 결과 표시, 승인 버튼 | 투자 판단 |
| 자동 실행 | Hermes | 같은 점검을 정해진 시각에 시작 | 자동 승인 |

AI에서 주문으로 바로 가는 화살표는 없습니다. **주문은 언제나 규칙 코드가 만들고,
사람이 정확한 계획을 승인해야 연습 계좌로 갑니다.**

Claude/Codex가 설치되지 않았거나 로그인·사용 한도·응답 시간 문제로 호출되지 않으면
Hermes가 다음 작업자나 Nous Portal 무료 모델로 넘깁니다. 판단 경로가 모두 실패하면 그
상태를 화면에 표시하고, 저장된 규칙 보기·계산·가드레일·주문 미리보기·사람 승인·기록만
코드로 계속합니다. 이것은 완전한 무중단 보장이 아니라 **한 곳이 막혀도 안전한 범위에서
계속되는 구조**입니다.
