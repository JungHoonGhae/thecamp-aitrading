# 2부 · 나만의 AI 투자 에이전트 (2회차)

## 이 파트의 목표
**내 원칙을 마크다운으로 선언하면, 스스로 점검·리밸런싱하고 보고하는 나만의 에이전트**를
만든다. 1부에서 만든 연결 위에서, "매일 정해진 시각에 내 계좌를 내 스펙과 비교"까지 간다.

## 끝나면 할 수 있는 것
- 내 투자 원칙(종목·비중·주기)과 **가드레일(한도)** 을 마크다운 스펙으로 선언한다.
- 에이전트가 현재 계좌와 비교해 **무엇을 얼마나 사고팔지** 계산하게 한다.
- **미리보기 → 가드레일 → 모의 주문**의 신뢰 게이트로 실제 리밸런싱을 해본다.
- **정해진 시각에 자동 실행 + 디스코드 보고**까지 붙인다(자는 동안 AI가 지켜본다).

## 직접 하는 것 (실습)
받아서 실행 → **내 스펙으로 고침** → 다시 실행 → 공유. "본인이 원칙을 바꾸는" 게 핵심.
- 예제 그대로 실행(신호가 섞여 나옴) → `spec/portfolio.md` 비중을 **내가 수정**
- 일부러 한도를 넘겨 **경고를 체험** → 되돌리기 → `--execute` 로 모의 주문
- hermes에 자연어로 "매주 예약" → 디스코드로 보고 받기

## 준비/주의
- 실행 기본은 **미리보기**(주문 없음). 실제 모의주문은 `--execute` 일 때만, 가드레일 통과분만.
- 이 저장소는 **모의투자**까지 — 실계좌(실전) 매매는 범위 밖(3~4회차, 문상록 강사).
- 토요일 휴장 시 모의주문 거부 가능 → mock 시뮬레이션으로 흐름 익히고 평일에 실행.
