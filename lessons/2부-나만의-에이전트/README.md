# 2부 · 나만의 AI 투자 에이전트 (2주차)

## 이 파트의 목표
**이미 있는 기본 스펙으로 투자 사이클 한 바퀴를 돈다.** 산다 · 판다 · 안 움직여도 기록한다.

가져가는 한 줄: 스펙은 이미 채워져 있습니다. `/config` 로 보고, 칸을 고칠 때만 `/update_config` 입니다.

긴장 한 박: 미리보기에 산다·판다가 나와도, 사람이 누르기 전에는 주문이 나가지 않습니다. 한국에 같은 규칙을 쓰면 수업 본편으로 쓰지 않습니다.

숨 한 박: 연습은 미국 연습 계좌입니다. `--reset-mock` 으로 되돌립니다. 승인을 안 누르면 계좌는 그대로입니다.

수업에서 미국 대형주를 볼 때는 **직전 한 달을 빼고 1년 성적이 상위인 종목**을 다음 한 달 같은 금액으로 담습니다. 지수를 이겼는지 숫자로 확인한 뒤에야 본편으로 씁니다. 한국은 같은 규칙이어도 **버립니다.**

확인 명령은 두 줄입니다. `python agent/committee.py` 그리고 `python agent/committee.py --market KR`.
나중 구간 벤치마크 차이: 미국 **+137.3%p**, 한국 **+62.2%p**. 그래서 본편은 미국만입니다. 세부는 [1-예제-실행](1-예제-실행.md).

AI는 약점과 반대 근거만 말합니다. 주문은 코드가 냅니다. 사람이 `/rebalance` 로 눌러야 모의가 나갑니다.

## 끝나면 할 수 있는 것
- 기본 스펙이 이미 있다는 걸 `/config` 로 본다.
- 미국 대형주 후보를 지수와 견준 결과를 읽고, 한국 후보는 본편에서 뺀다.
- 한 종목 최대 비중을 낮추면 주문이 차단되는 것을 본다.
- 미리보기 → 승인 → 미국 연습 계좌 체결을 눈으로 본다.
- 산 이유 · 판 이유 · 안 움직인 이유를 `/journal` 에 남긴다.
- 텔레그램으로 같은 보고를 받고, 폰에서 **저장된 주문 계획**을 승인한다.
- 정해진 시각에 혼자 돌게 만든다 (hermes · 20분이 넘으면 crontab · 화면).

## 직접 하는 것
- 기본 스펙으로 한 바퀴 (점검 미리보기 → 승인 → 기록)
- **한 종목 최대 비중**만 바꿔 가드레일을 한 번 걸어 보기
- 취향이 있으면 `/update_config` 로 칸 하나
- hermes 로 예약 (20분이 넘으면 화면과 crontab)

## 준비/주의
- 기본은 **미리보기**. `--execute` 일 때만 연습 계좌가 움직인다.
- 수업 본편은 **미국 연습 계좌**다. 실전은 졸업 스위치(수업 밖).
- 토요일은 미국장이 닫힙니다. 키와 장 시간이 없어도 돌아갑니다.
- 미국 대형주 예제는 고정 바스켓이라 생존편향이 있습니다. 시장 전체 성과로 일반화하지 않습니다.
