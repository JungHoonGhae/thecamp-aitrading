# 9 · 마무리

여기까지 왔다면, 당신은 이미:
- AI를 **국내 주식시장(KIS 모의투자)** 에 연결했고,
- 내 원칙을 스펙으로 선언해 **점검·리밸런싱·자동 보고**하는 에이전트를 만들었습니다.

## 여기까지가 반쪽이 아닙니다

3·4주차가 남았다고 해서 지금 손에 있는 게 미완성인 건 아닙니다. **이대로 계속 쓰셔도 됩니다.**

지금 돌아가는 것:

| 이미 되는 것 | 어디서 |
|---|---|
| 내가 적은 비율과 지금 계좌를 비교 | `내-투자-스펙.md` → `agent/agent.py` |
| 한도를 넘거나 금지어에 걸리면 **주문 차단** | 가드레일 |
| 미리보기 → 확인 → 체결 | 신뢰 게이트 |
| 정해진 시각에 알아서, 텔레그램으로 | hermes / crontab |
| 평일엔 증권사 모의투자, 나중엔 실전 | `.env` 한 줄 + 졸업 스위치 |

이게 **판단 없이 굴러가는 시스템의 최소 완전체**입니다. 지수를 따라가는 대부분의 상품이
하는 일이 정확히 이것이고, 남에게 수수료 내고 맡기던 걸 직접 돌리는 겁니다.

2주차는 기본 스펙으로 로컬 모의 한 바퀴를 돈 것입니다. 3·4주차는 여기에
**내 판단**을 얹을 수 있습니다. 없으면 안 도는 나머지 절반이 아니라, **돌아가는 것 위에
올리는 확장**입니다. 채점할 수 있는 것부터 맡겨야 믿을 근거가 쌓입니다.

## 신뢰 게이트
스펙 몇 줄로 안전이 완성되지는 않습니다. 권한은 **한 단계씩** 엽니다.

**AI 판단 제안 → 스펙 채택 → 주문 미리보기 → 정확한 주문 승인 → 모의 자동 → 실전**

- 핵심 안전장치는 코드로 단단히 고정하는 **하이브리드**가 현실적입니다(스펙 선언만으론
  예외를 다 못 막습니다).
- AI 검토는 주문하지 않습니다. 제안을 스펙으로 채택하는 확인과, 코드가 계산한
  정확한 주문을 승인하는 확인은 서로 다른 단계입니다.
- 수업은 **모의투자**까지입니다. 실전은 아래 "졸업 스위치"로만 열립니다.
- **강사도 겁납니다** — 그래서 천천히 엽니다.

## 졸업 스위치 — 실전으로 전환하려면 (수업 범위 밖)

수업이 끝나고, 모의로 충분히 오래 돌려 신뢰가 쌓였다면 — 같은 코드가 그대로
실전으로 전환됩니다. 코드를 고치는 게 아니라 **환경변수 스위치 2개**입니다.

```
KIS_ENV=real                    # 실전 서버로
KIS_REAL_ACK=REAL-MONEY-OK      # "실제 돈이 움직인다"는 이중 확인 (정확히 이 문구)
```

- `.env` 의 키·계좌번호도 **실전 계좌** 것으로 바꿔야 합니다.
- 이중 확인이 없으면 에이전트가 실행을 거부합니다 — 실수로 켜지지 않습니다.
- 가드레일은 실전에서도 똑같이 작동합니다. 전환 직후에는 **소액 + 보수적 가드레일**
  (한도 낮추고, 현금 높이고)로 시작하세요.
- 미국 주식도 같은 원칙입니다. 수업의 KIS Trading MCP 절차는 `env_dv=demo`에서
  멈춥니다. 실전 해외주식 주문은 졸업 스위치 뒤에 거래소·통화·지정가를 다시 확인합니다.
- AI에게: `"실전 전환을 도와줘. lessons/9-마무리 의 졸업 스위치 절차대로,
  바꾸기 전에 내 가드레일이 충분히 보수적인지 먼저 점검해줘."`

> 이 스위치는 "언젠가 스스로 열 수 있게" 만들어 둔 것이지, 서두르라는 뜻이 아닙니다.
> 패시브 리밸런싱은 원래 느린 전략입니다 — 신뢰도 느리게 쌓는 게 맞습니다.

## 다음 — 3~4주차 배턴

실전 자동매매·심화는 **3~4주차(문상록 강사님, PRISM-INSIGHT 기반)** 로 이어집니다.
실습 저장소가 따로 있습니다: [lecture-prism](https://github.com/dragon1086/lecture-prism)

여기(1~2주차)가 **패시브의 미니멀 완전체**(목표 비중·정기 리밸런싱)였다면,
3~4주차는 **액티브 매매**(진입·청산·시그널)로 확장합니다.

**들고 갈 것은 딱 네 문장입니다.** lecture-prism 의 `MY_STRATEGY.md` 는 이렇게 시작합니다.

> 나는 ______ 한 종목을 사고,
> ______ 하면 팔고,
> ______ 만큼만 위험을 지고 싶다.
> (선택) 그리고 AI가 종목을 볼 때 ______ 관점으로 판단했으면 좋겠다.

2부 3단계 **리뷰어 프롬프트**가 이 빈칸을 채운 초안을 만들어 줍니다. 그걸 그대로 가져가세요.

우리가 한 것과 이렇게 이어집니다.

| 우리 (1·2주차) | 3~4주차 |
|---|---|
| ① 담을 종목 — **무엇을** 담을지 정했다 | **언제** 담을지로 넓어진다 (진입) |
| ③ 허용 오차 — 언제 손댈지의 기준 | 청산 조건이 된다 |
| ④ 하지 마 · 한 종목 최대 비중 · 현금 최소 | 리스크 관리로 그대로 간다 |
| (없음 — 우리는 판단을 안 했다) | 분석 관점 (AI가 종목을 보는 눈) |

**비중 표 전체를 복사하는 과제가 아닙니다.** 네 문장이면 됩니다 —
`MY_STRATEGY.md` 도 "완벽하게 쓸 필요 없다, 두루뭉술해도 에이전트가 되묻는다"고 적혀 있습니다.
