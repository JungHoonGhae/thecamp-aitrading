# 9 · 마무리 — 신뢰는 한 단계씩

여기까지 왔다면, 당신은 이미:
- AI를 **국내 주식시장(KIS 모의투자)** 에 연결했고,
- 내 원칙을 스펙으로 선언해 **점검·리밸런싱·자동 보고**하는 에이전트를 만들었습니다.

## 신뢰 게이트
스펙 몇 줄로 안전이 완성되지는 않습니다. 권한은 **한 단계씩** 엽니다.

**읽기 전용 → 미리보기·확인 → 모의 자동 → 실전**

- 핵심 안전장치는 코드로 단단히 고정하는 **하이브리드**가 현실적입니다(스펙 선언만으론
  예외를 다 못 막습니다).
- 수업은 **모의투자**까지입니다. 실전은 아래 "졸업 스위치"로만 열립니다.
- **강사도 겁납니다** — 그래서 천천히 엽니다.

## 졸업 스위치 — 실전으로 전환하려면 (수업 범위 밖)

수업이 끝나고, 모의로 충분히 오래 돌려 신뢰가 쌓였다면 — 같은 코드가 그대로
실전으로 전환됩니다. 코드를 고치는 게 아니라 **환경변수 스위치 2개**입니다.

```
KIS_ENV=real                    # 실전 서버로
KIS_REAL_ACK=REAL-MONEY-OK      # "실제 돈이 움직인다"는 이중 확인 (정확히 이 문구)
```

- `.env` 의 키·계좌번호도 **실전 계좌** 것으로 바꿔야 합니다.
- 이중 확인이 없으면 에이전트가 실행을 거부합니다 — 실수로 켜지지 않습니다.
- 가드레일은 실전에서도 똑같이 작동합니다. 전환 직후에는 **소액 + 보수적 가드레일**
  (한도 낮추고, 현금 높이고)로 시작하세요.
- AI에게: `"실전 전환을 도와줘. lessons/9-마무리 의 졸업 스위치 절차대로,
  바꾸기 전에 내 가드레일이 충분히 보수적인지 먼저 점검해줘."`

> 이 스위치는 "언젠가 스스로 열 수 있게" 만들어 둔 것이지, 서두르라는 뜻이 아닙니다.
> 패시브 리밸런싱은 원래 느린 전략입니다 — 신뢰도 느리게 쌓는 게 맞습니다.
