# KIS 모의투자 Open API 신청 가이드

**1주차 수업 중에 다 같이 신청합니다.** 미리 받아 오시면 그 시간을 아낄 수 있습니다.

키가 필요한 시점은 이렇습니다.

| 언제 | 키가 필요한가 | `.env` |
| -- | -- | -- |
| 1주차 (토·휴장) | 없어도 됩니다. 연습 계좌 | `KIS_MODE=mock` |
| **1주차 숙제 (평일 장중)** | **필요합니다.** 모의투자 서버 + 공식 트레이딩 MCP(Docker) | `KIS_MODE=live` + 키 세 개 |
| 2주차 수업 (토) | 키는 놔두고 모드만 되돌립니다 | 다시 `KIS_MODE=mock` |

MCP(kis-lecture-lab)는 바꾸지 않습니다. 공식 트레이딩 MCP·Docker는 **1주차 평일 숙제**에 있습니다. 2주차 토요일 수업에는 없습니다.

돈은 가짜입니다. 모의투자라 손실 위험이 없습니다.

## 순서
1. **한국투자증권 계좌 개설** (앱/영업점). 이미 있으면 생략.
2. **모의투자 신청** — KIS 홈페이지 로그인 → 모의투자 → 참가 신청.
3. **KIS Developers 에서 Open API 신청** — 모의투자용 앱키(App Key)·시크릿(App Secret) 발급.
4. 발급받은 **앱키 · 시크릿 · 모의계좌번호(앞 8자리)** 를 메모.

> 모의투자 쪽은 승인이 대체로 바로 납니다. 당일 시간을 아끼려면 미리 받아두세요.

## 이 프로젝트에 넣기
1. `.env.example` 을 복사해 `.env` 로 만든다.
2. 값을 채운다:
   ```
   KIS_MODE=live
   KIS_APP_KEY=발급받은_앱키
   KIS_APP_SECRET=발급받은_시크릿
   KIS_ACCOUNT=모의계좌_앞8자리
   ```
3. 값은 `.env` 에만 둔다. 같은 kis-lecture-lab 이 다음 조회부터 모의투자 서버를 본다.
   `agent/agent.py` 는 2주차 본편이다.

## 주의
- `.env` 는 절대 공유·업로드하지 않는다 (`.gitignore` 에 이미 제외됨).
- **토요일 등 휴장일**엔 실시간 시세·주문이 제한된다. 이럴 땐 mock 모드로 실습.
