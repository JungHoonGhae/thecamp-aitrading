📦 이 방

숙제와 수업 자료 맞춤만 이야기하는 방입니다.
본편 숙제에 공식 손(둘러보기+모의주문)을 넣습니다. 여기에 찾는 숙제를 더합니다.

한투 공식 MCP는 둘입니다. 코딩도우미는 문서 334개(주문 없음). 트레이딩 MCP는 호출 166개(모의주문). 코딩도우미로 사면 주문이 안 나갑니다. 트레이딩 MCP는 Docker가 필요합니다.

한 칸이 끝나면 화면에 🧃 한입 상자가 나와야 합니다. 「다음」이라고 한 뒤에만 넘어가세요.
한 덩어리가 끝나면 🪞 회고 상자입니다.

✅ 본편 숙제 (평일 장중 9시~15시 반)

실습 폴더를 연 다음 순서대로. 한 줄씩.

1)
.agents/skills/kis-trading-mcp/SKILL.md 대로 공식 손을 붙여 줘. 코딩도우미로 조회와 액션을 한번 둘러보고, 트레이딩 MCP로만 호출해. 나한테 쓸 조회 셋과 액션 하나를 고르자. 코딩도우미로는 주문하지 마.

Docker Desktop 설치 창이 뜨면 클릭하세요. Windows는 Use WSL 2 를 켭니다.

2)
.agents/skills/investment-habit-rules/SKILL.md 대로 내 투자 습관을 하나씩 물어봐 줘. 말한 것만 규칙으로 적고, 방금 고른 조회·액션과 그 규칙으로 첫 모의투자까지 가자. 주문은 kis-trade-mcp 만. 코딩도우미로는 주문하지 마.

3)
.agents/skills/investment-habit-rules/references/retro.md 대로 방금 모의투자를 회고해 줘. 말한 것만 내-투자-판단.md 회고 칸에 채워. 끝나면 🪞 회고 상자로 보여 줘.

키가 있으면 .env 의 KIS_MODE=live. Docker가 막히면 막힌 지점만 남기면 됩니다.
2주차 오기 전: .env 의 KIS_MODE 를 mock 으로 되돌려줘. 키는 지우지 마세요. kis-lecture-lab 은 지우지 마세요.

자세한 글: lessons/1부-연결/3-1주차-숙제.md

🔎 더하는 숙제 — AI가 찾고, 학생이 확인

브라우저에서 skills.sh 나 GitHub 를 열지 마세요.
공식 한투 MCP 둘은 본편에서 이미 붙입니다. 더 찾기는 다른 손입니다.

스킬과 MCP 가 뭐가 다른지 가르쳐 줘. 끝나면 내가 말한 일에 맞는 스킬 하나와 MCP 하나를 AI가 찾아 줘. 나는 웹페이지를 직접 열지 않을게. 수업 스킬과 kis-lecture-lab 은 그대로 둬. 공식 KIS 코딩도우미·트레이딩 MCP와 실전 주문은 빼. 고른 이유와 네가 본 길을 한 줄로 말해 줘.

일이 있으면 앞에 한 줄만 덧붙입니다. 예: 공시를 보고 싶어.

📘 상자 → 한 질문씩 → 🧃 한입에서 「다음」→ AI가 🔎 표 → 한 번 쓰기 → 🪞 회고.

자세한 글: lessons/1부-연결/3-1주차-숙제-찾기.md
(자료 맞춘 뒤에 열리면 됩니다)
