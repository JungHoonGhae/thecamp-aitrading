# 새 숙제방 — 첫 글 세 개 (그대로 붙여넣기)

카톡은 마크다운이 거의 안 된다. 이모지도 쓰지 않는다. **세 글로 나눠 올린다.**

**2번은 학생이 통째로 복사해 클로드에 넘기는 글이다.** 그래서 제목도 설명도 없다.
안내는 1번 글 끝에 있다 — "다음 글을 처음부터 끝까지 전부 복사하세요".

> **왜 2번이 폴더 정리부터 하는가.** 학생 대부분은 폴더를 만들고 그 안에서 clone 했다.
> 그래서 클로드가 저장소보다 한 칸 위에서 열려 `.claude/skills` 를 못 읽는다.
> 「스킬이 설치되지 않았다」의 진짜 원인이다. 저장소를 위로 올려 고친다 —
> 폴더 경로가 유지돼야 대화 세션도 남는다. 자세한 건
> `.agents/skills/environment/SKILL.md` 의 「가장 흔한 함정」.

학생 문서: `lessons/1부-연결/3-1주차-숙제.md` · `3-1주차-숙제-찾기.md`

## 글 1 — 방 소개

```
[1/3]

1주차 수업을 진행한 계정훈입니다.

이 방은 편하게 쓰시라고 만들었습니다.
숙제 이야기만 하는 방이 아닙니다.

AI로 뭔가 하다가 막히셨나요. 여기 올려 주세요.
수업 때 놓친 부분도 괜찮습니다.
빨간 글씨가 뜨면 그대로 복사해서 붙여 주세요. 화면을 찍어 올리셔도 됩니다.


수업이 끝난 뒤에 자료를 조금 손봤습니다.
먼저 최신으로 맞춰 주세요. 1분이면 됩니다.

수업 때 쓰시던 클로드를 그대로 켜세요.
수업에서 대화하던 그 창에서 하시면 됩니다.
폴더는 이미 잡혀 있어서 따로 찾지 않으셔도 됩니다.

다음 글이 하나 더 올라갑니다.
그 글을 처음부터 끝까지 전부 복사해서 클로드에 붙여넣으세요.
그다음은 클로드가 알아서 합니다.

화면에 「실습 환경이 준비되었습니다」가 뜨면 끝난 겁니다.

창을 닫으셨거나 잘 안 되면 화면을 찍어 여기 올려 주세요. 같이 보겠습니다.
```

## 글 2 — 클로드에 붙여넣을 글 (이 코드블록 안만 복사)

```
수업 자료를 최신으로 맞춰줘. 아래 순서대로 해줘.

1. 지금 열린 폴더에 verify.py 파일이 바로 보이는지 봐줘. 보이면 3번으로 가.

2. 안 보이면 지금 폴더 아래에 폴더가 하나 더 있을 거야. 그 안에 verify.py 가 있어.
   그 폴더 안의 내용을 전부 지금 폴더로 꺼내줘. 숨김 파일과 .git 도 빠뜨리지 마.
   다 꺼냈으면 빈 폴더는 지워줘. 폴더를 새로 만들거나 다른 데로 옮기지는 마.
   이렇게 하는 이유는, 클로드가 열린 폴더를 기준으로 도우미를 읽기 때문이야.

3. 내가 고친 파일 세 개를 먼저 안전한 곳에 복사해둬.
   내-투자-스펙.md, 내-투자-판단.md, .env 야. 이건 잃으면 안 돼.

4. git pull 로 최신으로 맞춰줘.
   내 수정 때문에 막히면, 3번 복사본을 믿고 깨끗하게 되돌린 뒤 pull 하고,
   세 파일을 원래 자리에 되돌려놔줘.

5. VERSION 을 읽고 verify.py 를 실행해줘. 윈도우면 python, 맥이면 python3 야.

6. 마지막에 두 가지만 알려줘.
   버전 숫자와, verify 화면에 뭐가 됐는지.
   2번을 실제로 했으면 클로드를 껐다 켜야 도우미가 붙는다는 것도 알려줘.
   폴더는 그대로니까 대화는 이어진다고 말해줘.
   중간 과정은 설명 안 해도 돼. 문제가 생기면 그때만 자세히 알려줘.
```

## 글 3 — 숙제

```
[3/3] 1주차 숙제

평일에 한 번만 하시면 됩니다. 주식 시장이 열린 날이어야 합니다.
오전 9시부터 오후 3시 반 사이입니다.

자료를 맞추셨으면, 같은 창에 아래 네 줄을 하나씩 보내세요.
한 줄씩 보내고, 끝나면 다음 줄을 보내시면 됩니다.


숙제 환경 준비됐는지 확인해 줘

.agents/skills/kis-trading-mcp/SKILL.md 대로 공식 도구를 붙여 줘. 조회와 액션을 둘러보고, 나한테 쓸 조회 셋과 액션 하나를 고르자.

.agents/skills/investment-habit-rules/SKILL.md 대로 내 투자 습관을 하나씩 물어봐 줘. 말한 것만 규칙으로 적고, 첫 모의투자까지 가자.

.agents/skills/investment-habit-rules/references/retro.md 대로 방금 모의투자를 회고해 줘.

점 부터 시작하는 줄은 길어 보여도 그대로 복사해 붙이시면 됩니다.


하다 보면 도커라는 프로그램을 하나 깔게 됩니다.
설치와 연결은 클로드가 합니다.
직접 하실 일은 두 번뿐입니다. 설치 창을 한 번 누르고, 깔린 프로그램을 한 번 켜는 것입니다.

안 되어도 괜찮습니다.
수업에서 쓰던 것으로도 모의주문과 잔고 조회, 수익률 확인까지 다 됩니다.
10분 넘게 막히시면 그만하시고 여기 올려 주세요.

에러가 나면 이 한 줄만 보내시면 됩니다.

.agents/skills/troubleshooting/SKILL.md 대로 고쳐줘


2주차에 오시기 전에 이 한 줄만 보내 주세요.

.env 의 KIS_MODE 를 mock 으로 되돌려줘


숙제가 끝나면 내-투자-판단.md 파일 하나가 남습니다.
2주차는 그 내용으로 시작합니다.

잘 안 된 것도 그대로 적어 오세요. 오히려 그쪽이 이야기할 게 많습니다.
```
