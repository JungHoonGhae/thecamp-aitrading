🔎 더하는 숙제 — AI가 찾고, 학생이 확인

브라우저에서 skills.sh 나 GitHub 를 열지 마세요.
실습 폴더를 연 다음 이 한 줄이면 구분부터 찾기까지 갑니다.

스킬과 MCP 가 뭐가 다른지 가르쳐 줘. 끝나면 내가 말한 일에 맞는 스킬 하나와 MCP 하나를 AI가 찾아 줘. 나는 웹페이지를 직접 열지 않을게. 수업 스킬과 kis-lecture-lab 은 그대로 둬. 공식 KIS 트레이딩 MCP와 실전 주문은 빼. 고른 이유와 네가 본 길을 한 줄로 말해 줘.

일이 있으면 앞에 한 줄만 덧붙입니다. 예: 공시를 보고 싶어.

📘 상자 → 한 질문씩 → 🧃 한입에서 「다음」→ AI가 🔎 표 → 한 번 쓰기 → 🪞 회고.

자세한 글: lessons/1부-연결/3-1주차-숙제-찾기.md
(자료 맞춘 뒤에 열리면 됩니다)
