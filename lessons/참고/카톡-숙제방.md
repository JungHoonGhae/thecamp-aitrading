[2/3] 아래를 통째로 복사해서 클로드에 붙여넣으세요


수업 자료를 최신으로 맞추고, 도우미(스킬)가 제대로 붙게 정리해줘. 순서는 이렇게 해줘.

1. 지금 열린 폴더에 verify.py 가 바로 보이는지 확인해줘.
   보이면 3번으로 가.

2. 안 보이면, 지금 폴더 바로 아래에 저장소 폴더가 하나 더 있을 거야.
   그 안에 verify.py 와 .claude 폴더가 있어. 그러면 아래처럼 정리해줘.

   - 그 폴더 안의 내용을 전부 지금 폴더로 올려줘. 숨김 파일과 .git 폴더도 빠뜨리면 안 돼.
   - 다 옮겼으면 빈 껍데기 폴더는 지워줘.
   - 옮긴 뒤 git status 가 정상인지, 내 파일이 그대로 있는지 확인해줘.
   - 폴더를 새로 만들거나 다른 곳으로 옮기지는 마. 지금 이 폴더가 기준이야.

   왜 이렇게 하냐면, 클로드는 열린 폴더를 기준으로 도우미를 읽어.
   저장소가 한 칸 아래에 있으면 도우미가 안 붙어서 짧은 말이 안 먹혀.

3. 내가 고친 파일을 먼저 안전한 곳에 복사해둬.
   내-투자-스펙.md, 내-투자-판단.md, .env 세 개야. 이건 절대 잃으면 안 돼.

4. git pull 로 최신으로 맞춰줘.
   내 수정 때문에 pull 이 거부되면, 3번 복사본을 믿고 저장소를 깨끗하게 되돌린 뒤
   pull 하고, 세 파일을 원래 자리에 되돌려놔줘.

5. VERSION 을 읽고 verify.py 를 실행해줘. 윈도우면 python, 맥이면 python3 야.

6. 마지막에 이렇게만 알려줘.
   - 버전 숫자와 몇 개 통과했는지
   - 2번을 실제로 했으면, 클로드를 껐다 켜야 도우미가 붙는다는 것.
     폴더는 그대로니까 이어서 대화하면 된다는 것도 알려줘.
   중간 과정은 설명 안 해도 돼. 문제가 생기면 그때만 자세히 알려줘.
