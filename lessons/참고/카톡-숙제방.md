# 카톡 숙제방 — 붙여넣을 글

카톡은 마크다운이 거의 안 된다. 이모지도 쓰지 않는다.
**사람이 읽는 글과 AI에 넘기는 글을 나눈다.** 학생이 어디까지 복사할지 헷갈리지 않게.

| 글 | 언제 | 누가 읽나 |
| -- | -- | -- |
| 1 · 학생용 | 방 열 때 | 사람 |
| 2 · AI에 붙여넣기 | 1 바로 다음 | 클로드 |
| 3 · 숙제 리마인드 | 며칠 뒤 | 사람 |

> **왜 2번이 폴더 정리부터 하는가.** 학생 대부분은 폴더를 만들고 그 안에서 clone 했다.
> 그래서 클로드가 저장소보다 한 칸 위에서 열려 `.claude/skills` 를 못 읽는다.
> 「스킬이 설치되지 않았다」의 진짜 원인이다. 저장소를 위로 올려 고친다 —
> 폴더 경로가 유지돼야 대화 세션도 남는다.
> 자세한 건 `.agents/skills/environment/SKILL.md` 의 「가장 흔한 함정」.

> **카톡에서는 슬래시 명령을 쓴다.** 학생이 긴 경로를 치게 하지 않는다.
> 저장소 문서(`3-1주차-숙제.md`)는 AI 가 읽으므로 경로 그대로 둔다 — 그쪽이 정확하다.

학생 문서: `lessons/1부-연결/3-1주차-숙제.md` · `3-1주차-숙제-찾기.md`

## 1 · 학생용

```
1주차 수업 진행한 계정훈입니다.

이 방은 편하게 쓰시라고 만들었습니다.
AI로 뭔가 하다 막히셨거나, 수업 때 놓친 게 있으면 여기 올려 주세요.
화면을 찍어 올리셔도 되고, 빨간 글씨를 그대로 붙이셔도 됩니다.


1주차 때 환경 세팅에 생각보다 시간이 많이 걸렸습니다.
컴퓨터마다 상태가 달라서 어떤 분은 금방 되고 어떤 분은 한참 걸렸습니다.

그래서 도커라는 걸 쓰기로 했습니다.
컴퓨터가 달라도 그 안은 모두 똑같아서, 세팅 때문에 시간 버리는 일이 줄어듭니다.

깔고 설정하는 건 클로드가 다 합니다. 직접 하실 건 없습니다.
설치 창이 뜨면 한 번 누르고, 깔린 프로그램을 한 번 켜 주시면 그걸로 끝입니다.


수업 뒤에 자료를 조금 손봤습니다. 먼저 맞춰 주세요.

수업 때 쓰시던 클로드를 그대로 켜세요.
수업에서 대화하던 그 창에서 하시면 됩니다.

다음 글을 전부 복사해서 그 창에 붙여넣으세요.
그다음은 클로드가 알아서 합니다. 기다리시기만 하면 됩니다.

화면에 「실습 환경이 준비되었습니다」가 뜨면 끝입니다.
잘 안 되면 화면 찍어 올려 주세요. 같이 보겠습니다.


맞추고 나면 숙제는 이 세 줄입니다. 평일 장중에 하시면 됩니다.

숙제 환경 준비됐는지 확인해 줘
/kis-trading-mcp
/investment-habit-rules

막히면 /troubleshooting 이라고 보내세요.
그래도 안 되면 그만하시고 여기 올려 주세요. 붙잡고 계실 필요 없습니다.


여기까지 하시면 투자 원칙을 적고, 모의주문을 넣고, 회고까지 남습니다.

여유 되시면 하나 더 해보세요.

/skill-vs-mcp

스킬과 MCP가 뭐가 다른지 클로드가 알려 줍니다.
그다음 내 투자에 쓸 만한 걸로 스킬 하나, MCP 하나를 클로드가 찾아 줍니다.
사이트를 직접 뒤지실 필요는 없습니다. 찾아온 걸 보고 왜 그걸 골랐는지 한번 물어보세요.
```

## 2 · AI에 붙여넣기 (이 블록만 복사)

```
수업 자료를 최신으로 맞춰줘. 아래 순서대로 해줘.

1. 지금 열린 폴더에 verify.py 파일이 바로 보이는지 봐줘. 보이면 3번으로 가.

2. 안 보이면 지금 폴더 아래에 폴더가 하나 더 있을 거야. 그 안에 verify.py 가 있어.
   그 폴더 안의 내용을 전부 지금 폴더로 꺼내줘. 숨김 파일과 .git 도 빠뜨리지 마.
   다 꺼냈으면 빈 폴더는 지워줘. 폴더를 새로 만들거나 다른 데로 옮기지는 마.
   이렇게 하는 이유는, 클로드가 열린 폴더를 기준으로 도우미를 읽기 때문이야.

3. 내가 고친 파일 세 개를 먼저 안전한 곳에 복사해둬.
   내-투자-스펙.md, 내-투자-판단.md, .env 야. 이건 잃으면 안 돼.

4. git pull 로 최신으로 맞춰줘.
   내 수정 때문에 막히면, 3번 복사본을 믿고 깨끗하게 되돌린 뒤 pull 하고,
   세 파일을 원래 자리에 되돌려놔줘.

5. VERSION 을 읽고 verify.py 를 실행해줘. 윈도우면 python, 맥이면 python3 야.

6. 마지막에 두 가지만 알려줘.
   버전 숫자와, verify 화면에 뭐가 됐는지.
   2번을 실제로 했으면 클로드를 껐다 켜야 도우미가 붙는다는 것도 알려줘.
   폴더는 그대로니까 대화는 이어진다고 말해줘.
   중간 과정은 설명 안 해도 돼. 문제가 생기면 그때만 자세히 알려줘.
```

## 3 · 숙제 리마인드 (며칠 뒤)

2주차 도입에서 물어볼 것을 그대로 앞에 둔다. 그게 곧 할 일이 된다.
`3-1주차-숙제-찾기.md` 의 「2주차에 가져올 것 — 다섯 줄」과 같은 내용이다.

```
숙제 리마인드입니다. 평일 장중에 한 번이면 됩니다.

2주차 시작할 때 아래를 여쭤볼 겁니다.
그래서 숙제가 끝나면 이 답들이 손에 있어야 합니다.


[본편]

1. 내 투자 원칙을 글로 적었는가
   무엇을 살지, 무엇은 하지 않을지. 내-투자-판단.md 파일에 남습니다.

2. 모의주문을 한 번 넣어 봤는가
   실제 돈은 안 움직입니다. 안 됐으면 왜 안 됐는지가 답입니다.

3. 해 보니 어땠는가
   회고 한 줄. 이것도 파일에 남습니다.

숙제 환경 준비됐는지 확인해 줘
/kis-trading-mcp
/investment-habit-rules


[더 하시는 분]

4. 어떤 스킬을 찾았는가 — 이름과 어디서 찾았는지
5. 어떤 MCP를 붙였는가 — 이름과 붙였는지 여부
6. 왜 그걸 골랐는가 — 내 투자에 어떻게 도움이 될 거라고 봤는지
7. 정말 도움이 됐는가 — 써 보니 어땠는지

/skill-vs-mcp

7번이 제일 중요합니다.
골라만 놓고 안 써 보면 그 판단이 맞았는지 알 수가 없습니다.
「생각보다 별로였다」가 좋은 답입니다. 그게 다음 선택을 낫게 만듭니다.

남의 것을 붙이는 거라 하나만 조심해 주세요.
증권사 앱키를 넣으라고 하면 붙이지 마세요. 다른 걸 고르시면 됩니다.


다 못 하셔도 괜찮습니다.
막힌 지점 한 줄만 있어도 2주차에 이야기할 게 생깁니다.
클로드가 다 해주니 붙잡고 계실 필요 없습니다.
```
