# 1주차 — AI를 국내 주식시장(KIS)에 연결

> 수업 당일은 토요일입니다. 연습 데이터(mock)와 `kis-lecture-lab` 다섯 개로 조회·주문까지 합니다.
> 평일 숙제는 공식 손입니다. 코딩도우미(334, 보기) + 트레이딩 MCP(166, Docker, 호출·주문).
> 코딩도우미로 사면 주문이 안 나갑니다. `kis-lecture-lab` 은 지우지 않습니다.

## 1-1. kis-lecture-lab 붙이기

```
이 저장소의 agent/mcp_server.py 를 MCP 서버로 등록해줘.
Claude Code면  claude mcp add kis-lecture-lab -- python3 <이 저장소 절대경로>/agent/mcp_server.py
Codex면        codex  mcp add kis-lecture-lab -- python3 <이 저장소 절대경로>/agent/mcp_server.py
Windows면 python3 자리에 python 을 넣어줘 (Windows 에는 python3 명령이 없습니다).
등록되면 어떤 도구가 연결됐는지 목록으로 보여줘.
```

등록한 뒤 앱을 한 번 껐다 켭니다.

```

## 1-3. 연습 주문 (숙제의 「주문해」와 같은 도구)

공식 트레이딩 MCP가 아닙니다. 수업에서 붙인 kis-lecture-lab입니다.

```
kis-lecture-lab으로 삼성전자 1주를 시장가로 사는 주문을 미리보기만 해줘. 아직 사지 마.

내가 「주문해」라고 하면 그때 연습 계좌에 넣어줘.
들어가면 접수됐는지, 잔고가 어떻게 바뀌었는지 다시 알려줘.
```

되돌리기:

```
python agent/agent.py --reset-mock
```

## 1주차 숙제 (수업 뒤 · 평일 장중)

호출·주문은 **트레이딩 MCP**입니다. Docker가 필요합니다. 코딩도우미는 둘러보기만.
키가 있으면 평일 장중에 `.env` 의 `KIS_MODE=live`. Docker가 막히면 막힌 지점만 남깁니다.
2주차 오기 전 `KIS_MODE=mock` 으로 되돌립니다. 키는 지우지 않습니다.

```

# 2주차 — 나만의 AI 투자 에이전트

## 2-1. 예제 에이전트 그대로 실행

```
agent/agent.py 를 그대로 실행해줘. 결과에서 '현재 비중'과 '목표 비중'이
무슨 뜻인지, 왜 어떤 종목은 사고 어떤 종목은 팔라고 나오는지 초보자도 알게 설명해줘.
```

## 2-2. 내 원칙을 스펙으로 (선언)

```
내-투자-스펙.md 표를 내 상황에 맞게 채워줘.
내-투자-판단.md 가 있으면 그걸 먼저 읽고, 거기 적힌 원하는 방식·하지 말 것을 이 표의 근거로 써줘.
나는 (예: 월급 일부로 장기 적립, 반도체 쏠림이 걱정, 종목은 3개면 충분) 이야.

규칙:
- 국내 종목만, 비중 합 100.
- 한 종목 40% 넘지 말 것. 몰빵·레버리지는 넣지 말 것.
- 내가 이름을 아는 회사를 최소 한 곳은 넣어줘.
- 다 채우면 python sync_spec.py 하고 python verify.py 로 「실습 환경이 준비되었습니다」를 확인해줘.
- 에이전트 주문은 다음 단계.
```

## 2-3. 가드레일 체험 (일부러 위반)

```
가드레일을 시험해보고 싶어. 내-투자-스펙.md 에서 한 종목 비중을 일부러 45%로 올려서
경고가 뜨는지 확인하고, 왜 막히는지 설명해줘. 그다음 python sync_spec.py 하고
다시 안전한 값으로 되돌려줘.
```

## 2-4. 리밸런싱 — 미리보기 → 가드레일 → 모의 주문

먼저 미리보기(주문 안 나감):
```
지금 내 스펙 기준으로 리밸런싱하면 무엇을 얼마나 사고팔아야 하는지
'미리보기'만 보여줘. 아직 실제 주문은 넣지 마.
```

가드레일 통과분만 실제 모의 주문:
```
방금 미리보기에서 가드레일을 통과한 주문만, 모의투자로 실제 실행해줘.
실행 전에 한 번 더 확인 질문을 하고, 실행 후 체결/거부 결과를 알려줘.
```

> ⚠️ 토요일(휴장)엔 실제 모의주문이 거부될 수 있습니다. 그럴 땐 미리보기까지만 하고,
> 평일에 같은 프롬프트로 실행해보세요.
