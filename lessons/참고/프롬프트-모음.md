# 1주차 — AI를 국내 주식시장(KIS)에 연결

> 수업 당일은 토요일입니다. 연습 데이터(mock)와 `kis-lecture-lab` 다섯 개로 조회·주문까지 합니다.
> 평일 숙제는 공식 도구입니다. 코딩도우미(334, 보기) + 트레이딩 MCP(166, Docker, 호출·주문).
> 코딩도우미로 사면 주문이 안 나갑니다. `kis-lecture-lab` 은 지우지 않습니다.

## 1-1. kis-lecture-lab 붙이기

```
이 저장소의 agent/mcp_server.py 를 MCP 서버로 등록해줘.
Claude Code면  claude mcp add kis-lecture-lab -- python <이 저장소 절대경로>/agent/mcp_server.py
Codex면        codex  mcp add kis-lecture-lab -- python <이 저장소 절대경로>/agent/mcp_server.py
맥에서 python 이 없다고 나오면 python 자리에 `python3` 을 넣어줘.
등록되면 어떤 도구가 연결됐는지 목록으로 보여줘.
```

등록한 뒤 앱을 한 번 껐다 켭니다.

## 1-3. 연습 주문 (숙제의 「주문해」와 같은 도구)

공식 트레이딩 MCP가 아닙니다. 수업에서 붙인 kis-lecture-lab입니다.

```
kis-lecture-lab으로 삼성전자 1주를 시장가로 사는 주문을 미리보기만 해줘. 아직 사지 마.

내가 「주문해」라고 하면 그때 연습 계좌에 넣어줘.
들어가면 접수됐는지, 잔고가 어떻게 바뀌었는지 다시 알려줘.
```

되돌리기:

```
python agent/agent.py --reset-mock
```

## 1주차 숙제 (수업 뒤 · 평일 장중)

호출·주문은 **트레이딩 MCP**입니다. Docker가 필요합니다. 코딩도우미는 둘러보기만.
키가 있으면 평일 장중에 `.env` 의 `KIS_MODE=live`. Docker가 막히면 막힌 지점만 남깁니다.
2주차 오기 전 `KIS_MODE=mock` 으로 되돌립니다. 키는 지우지 않습니다.

두 줄을 순서대로 보냅니다. 앞에 붙은 `/environment` · `/homework` 가 스킬 이름입니다.

```
/environment 수업 자료 업데이트 해 줘
```

```
/homework 이번 주 숙제 절차를 안내하고, 내가 하는 걸 도와줘
```

한 칸만 다시 할 때만 아래를 씁니다.

```
.agents/skills/kis-trading-mcp/SKILL.md 대로 공식 도구를 붙여 줘. 코딩도우미로 조회와 액션을 한번 둘러보고, 트레이딩 MCP로만 호출해. 나한테 쓸 조회 셋과 액션 하나를 고르자. 코딩도우미로는 주문하지 마.
```

```
.agents/skills/investment-habit-rules/SKILL.md 대로 내 투자 습관을 하나씩 물어봐 줘. 말한 것만 규칙으로 적고, 방금 고른 조회·액션과 그 규칙으로 첫 모의투자까지 가자. 주문 다음 회고도 이어서. 주문은 kis-trade-mcp 만. 코딩도우미로는 주문하지 마.
```

회고는 `/homework` 가 이어서 합니다. 따로 보내지 않습니다.

## 1주차 숙제 · 더 찾기 (스킬 하나, MCP 하나)

사이트를 직접 열지 않습니다. 일의 이름만 말하면 AI가 찾습니다.
한 칸이 끝나면 🧃 한입. 덩어리가 끝나면 🪞 회고.

```
스킬과 MCP 가 뭐가 다른지 가르쳐 줘. 끝나면 내가 말한 일에 맞는 스킬 하나와 MCP 하나를 AI가 찾아 줘. 나는 웹페이지를 직접 열지 않을게. 수업 스킬과 kis-lecture-lab 은 그대로 둬. 공식 KIS 코딩도우미·트레이딩 MCP와 실전 주문은 빼. 고른 이유와 네가 본 길을 한 줄로 말해 줘.
```

일이 있으면 앞에 한 줄. 예: 공시를 보고 싶어.

```
방금 뭐 배웠는지 🧃 한입으로 보여 줘. 맞으면 다음만 말해 줘.
```

# 2주차 — 나만의 AI 투자 에이전트

## 2-1. 후보를 지수와 견주기

```
python agent/committee.py 를 실행해 줘.
약점, 반대 근거, 다음 질문과 제안 번호까지만 확인하고,
스펙 채택이나 주문은 하지 마.
```

한국 바스켓을 보려면 같은 명령에 `--market KR` 을 붙입니다. 본편은 미국입니다.

## 2-2. 판단 제안을 스펙으로 채택

`(제안 번호)`에는 앞 화면 맨 아래 `제안 번호:` 줄을 붙입니다.

```
방금 참조 실험의 약점과 반대 근거를 다시 짧게 보여 줘.
내가 채택한다고 답한 뒤에만 아래 미리보기를 실행해 줘.

python agent/us_agent.py --adopt (제안 번호)

주문 계획은 보여 주되 실행하지 마.
```

가드레일만 만져 보려면 `--max-weight 15` 를 붙입니다. 세 줄이 모두 `차단:` 이면 통과입니다.

## 2-3. 정확한 주문 승인

```
방금 주문 미리보기의 종목·방향·수량·지정가를 다시 보여 줘.
내가 정확한 주문 계획 번호를 승인한 뒤에만 미국 연습 계좌에서 실행해 줘.

python agent/us_agent.py --adopt (제안 번호) \
  --approve (주문 계획 번호) --execute

주문 계획이 바뀌었거나 가드레일에 걸리면 실행하지 말고 다시 보여 줘.
```

제안 번호와 주문 계획 번호는 다릅니다. 승인은 주문 계획 번호로만 합니다.

## 2-4. 자동화 — hermes 로 예약 (본편)

```
lessons/2부-나만의-에이전트/4-자동화-hermes-예약.md 대로
hermes setup --portal 하고, portfolio-check.py 를 복사한 뒤
매주 월요일 아침 점검 예약을 걸어줘. 수업 모델은 Nous Portal 이야.
Claude Code 를 hermes 에 다시 붙이지 마.
```

## 2-5. 폴백 — hermes 가 막히면 텔레그램 + crontab

```
hermes 설치가 막혔어. lessons/참고/telegram-봇-가이드.md 대로 봇을 만들고
python agent/agent.py 한 번에 텔레그램이 오게 한 다음,
crontab(또는 작업 스케줄러)에 같은 명령을 매주 월요일 아침으로 걸어줘.
```

## 2-6. 숙제 — 기본 스펙으로 한 바퀴

```
lessons/2부-나만의-에이전트/5-넓히기-루틴과-데이터.md 대로
기본 스펙으로 점검 미리보기 한 번과 기록 한 줄만 남겨 줘.
```
