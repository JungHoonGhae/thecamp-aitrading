# 1회차 — AI를 국내 주식시장(KIS 모의투자)에 연결

## 1-1. KIS Trading MCP 붙이기 (내 도구에 등록)

> 강사가 배포한 미리 빌드된 MCP 이미지를 사용합니다(직접 빌드하지 않아도 됩니다).

```
강사가 준 KIS Trading MCP 컨테이너 이미지를 내 컴퓨터에서 실행하고,
지금 쓰는 이 AI 도구(Claude Code / Codex)에 그 MCP 서버를 등록하는 걸 도와줘.
등록이 끝나면 어떤 도구들이 연결됐는지 목록으로 보여줘.
```

## 1-2. AI가 실제 모의계좌 조회

```
모의투자로 삼성전자(005930) 현재가를 조회해줘.
그리고 이 숫자가 실제로 어디서 온 건지, mock이 아니라 진짜 KIS 서버 응답인지
한 줄로 설명해줘.
```

여러 종목도:
```
모의투자로 삼성전자, SK하이닉스, 현대차 현재가를 표로 비교해서 보여줘.
```

## 1-3. (안 될 때) mock 폴백

> Docker가 안 뜨거나 등록이 막히면, 실습을 멈추지 말고 mock으로 동일하게 진행하세요.

```
Docker/MCP 연결이 지금 안 돼. 대신 이 저장소의 mock 모드로 삼성전자 현재가를
확인하고, 나중에 MCP로 다시 붙일 수 있게 뭐가 막혔는지도 같이 알려줘.
```

## 1-4. (심화) AI가 도구를 진단·수리

```
방금 MCP를 붙이는 과정에서 어떤 문제가 생길 수 있는지,
그리고 .agents/skills/troubleshooting 의 진단 가이드를 참고해서 흔한 오류(라이브러리 버전 변경 등)를
어떻게 스스로 고치는지 예를 들어 설명해줘.
```

# 2회차 — 나만의 AI 투자 에이전트

## 2-1. 예제 에이전트 그대로 실행

```
agent/agent.py 를 그대로 실행해줘. 결과에서 '현재 비중'과 '목표 비중'이
무슨 뜻인지, 왜 어떤 종목은 사고 어떤 종목은 팔라고 나오는지 초보자도 알게 설명해줘.
```

## 2-2. 내 원칙을 스펙으로 (선언)

```
spec/portfolio.md 를 열어서, 내 투자 원칙대로 종목과 목표 비중을 바꿔줘.
(예: 삼성전자 30, SK하이닉스 20, 현대차 20, 나머지 현금)
바꾼 뒤 다시 실행해서 이전과 뭐가 달라졌는지 비교해줘.
```

## 2-3. 가드레일 체험 (일부러 위반)

```
가드레일을 시험해보고 싶어. spec 에서 한 종목 비중을 일부러 45%로 올려서
경고가 뜨는지 확인하고, 왜 막히는지 설명해줘. 그다음 다시 안전한 값으로 되돌려줘.
```

## 2-4. 리밸런싱 — 미리보기 → 가드레일 → 모의 주문

먼저 미리보기(주문 안 나감):
```
지금 내 스펙 기준으로 리밸런싱하면 무엇을 얼마나 사고팔아야 하는지
'미리보기'만 보여줘. 아직 실제 주문은 넣지 마.
```

가드레일 통과분만 실제 모의 주문:
```
방금 미리보기에서 가드레일을 통과한 주문만, 모의투자로 실제 실행해줘.
실행 전에 한 번 더 확인 질문을 하고, 실행 후 체결/거부 결과를 알려줘.
```

> ⚠️ 토요일(휴장)엔 실제 모의주문이 거부될 수 있습니다. 그럴 땐 미리보기까지만 하고,
> 평일에 같은 프롬프트로 실행해보세요.

## 2-5. 자동화 — hermes에 말로 예약

준비(한 번):
```
hermes/scripts/portfolio-check.py 를 내 ~/.hermes/scripts/ 로 복사하고,
그 안의 저장소 경로를 내 실제 경로로 바꾸는 걸 도와줘.
```

예약(hermes 채팅에서 자연어로):
```
portfolio-check.py 를 매주 월요일 아침 8시에 no-agent 모드로 실행해서
디스코드로 결과를 보내줘.
```
