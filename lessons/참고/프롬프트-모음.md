# 1주차 — AI를 국내 주식시장(KIS)에 연결

> 수업 당일은 토요일입니다. 연습 데이터(mock)와 `kis-lecture-lab` 다섯 개로 조회·주문까지 합니다.
> 평일 숙제는 공식 도구입니다. 코딩도우미(334, 보기) + 트레이딩 MCP(166, Docker, 호출·주문).
> 코딩도우미로 사면 주문이 안 나갑니다. `kis-lecture-lab` 은 지우지 않습니다.

## 1-1. kis-lecture-lab 붙이기

```
이 저장소의 agent/mcp_server.py 를 MCP 서버로 등록해줘.
Claude Code면  claude mcp add kis-lecture-lab -- python <이 저장소 절대경로>/agent/mcp_server.py
Codex면        codex  mcp add kis-lecture-lab -- python <이 저장소 절대경로>/agent/mcp_server.py
맥에서 python 이 없다고 나오면 python 자리에 `python3` 을 넣어줘.
등록되면 어떤 도구가 연결됐는지 목록으로 보여줘.
```

등록한 뒤 앱을 한 번 껐다 켭니다.

## 1-3. 연습 주문 (숙제의 「주문해」와 같은 도구)

공식 트레이딩 MCP가 아닙니다. 수업에서 붙인 kis-lecture-lab입니다.

```

내가 「주문해」라고 하면 그때 연습 계좌에 넣어줘.
들어가면 접수됐는지, 잔고가 어떻게 바뀌었는지 다시 알려줘.
```

되돌리기:

```

```

## 1주차 숙제 (수업 뒤 · 평일 장중)

호출·주문은 **트레이딩 MCP**입니다. Docker가 필요합니다. 코딩도우미는 둘러보기만.
키가 있으면 평일 장중에 `.env` 의 `KIS_MODE=live`. Docker가 막히면 막힌 지점만 남깁니다.
2주차 오기 전 `KIS_MODE=mock` 으로 되돌립니다. 키는 지우지 않습니다.

두 줄을 순서대로 보냅니다. 앞에 붙은 `/environment` · `/homework` 가 스킬 이름입니다.

```
/environment 수업 자료 업데이트 해 줘
```

```
/homework 이번 주 숙제 절차를 안내하고, 내가 하는 걸 도와줘
```

한 칸만 다시 할 때만 아래를 씁니다.

```
.agents/skills/kis-trading-mcp/SKILL.md 대로 공식 도구를 붙여 줘. 코딩도우미로 조회와 액션을 한번 둘러보고, 트레이딩 MCP로만 호출해. 나한테 쓸 조회 셋과 액션 하나를 고르자. 코딩도우미로는 주문하지 마.
```

```
.agents/skills/investment-habit-rules/SKILL.md 대로 내 투자 습관을 하나씩 물어봐 줘. 말한 것만 규칙으로 적고, 방금 고른 조회·액션과 그 규칙으로 첫 모의투자까지 가자. 주문 다음 회고도 이어서. 주문은 kis-trade-mcp 만. 코딩도우미로는 주문하지 마.
```

회고는 `/homework` 가 이어서 합니다. 따로 보내지 않습니다.

# 2주차 — 모의투자로 배우는 안전한 자동화 구조

## 2-0. Hermes와 텔레그램 연결

```text
lessons/참고/telegram-봇-가이드.md 대로 내 투자 에이전트를 연결해 줘.
토큰은 이거야: (BotFather가 준 토큰)

.env에 내 방 번호를 넣고 python hermes/setup_course.py --from-project-env 를 실행한 뒤
Hermes gateway를 다시 시작해 줘. 토큰은 화면에 다시 출력하지 마.
```

연결되면 폰에서 `/ts_help`를 보냅니다. Hermes 기본 명령은 수업 명령 아래 그대로 남습니다.

## 2-1. 장과 상관없이 분석하기

```text
/ts_analyze AAPL
```

버튼에서 `기술적 분석`을 고르면 외부 과거 시세를 코드로 계산하므로 AI가 없어도 됩니다.
`펀더멘탈 분석`을 고르면 Hermes가 가능한 AI를 연결해 공식 공시·회사 자료를 우선 찾습니다.
`둘 다 분석`을 고르면 두 결과를 차례로 보여 줍니다.
둘 다 주문과 분리됩니다.

## 2-2. 분석 규칙부터 승인까지 확인하기

폰에서 한 줄씩 보냅니다.

```text
/ts_status
/ts_rule
/ts_order_plan
/ts_log 오늘 본 것과 다음에 확인할 이유 한 줄
```

`/ts_status`에서는 잔고·보유 주식·대기 주문이 한 번에 나옵니다. `/ts_rule`는 이미 저장된
현재 규칙을 읽을 때 사용하며, 가설을 주문마다 새로 만들지 않습니다. `/ts_order_plan`에서 종목·방향·
수량·지정가를 읽고 2분 안에 `이 계획 승인` 또는 `보류` 버튼을 누릅니다. 내부 번호를 복사할
필요가 없습니다. 승인 뒤에만 수업용 계좌가 한 번 바뀝니다.

규칙의 전제가 달라졌을 때만 `/ts_rule 걱정 한 줄`에서 `가설 근거와 약점`을 다시 봅니다.
AI는 약점을 설명할 뿐 주문값을 바꾸지 않습니다.

## 2-3. 계좌 종류 확인

```text
/ts_config
```

`수업용 계좌`는 KIS 키 없이 토요일에도 동작하는 로컬 연습 계좌입니다. `KIS 모의투자 계좌`는
KIS 국내주식 모의 서버이며 별도 키가 있어야 전환됩니다. 실계좌 선택지는 없습니다.

## 2-4. 자동화 — 아침 브리핑 실행과 예약

```
Telegram에서 "아침 브리핑 지금 실행해 줘"를 먼저 실행해 결과를 확인해 줘.
정상 결과가 오면 "평일 오전 8시에 아침 브리핑 보내 줘"로 예약하고,
예약 이름·시각·스크립트·no-agent 여부를 보여 줘. 주문은 만들거나 실행하지 마.
```

## 2-5. Hermes 폴백과 AI 상태 확인

```
Hermes 설치나 로그인이 10분 안에 안 되면 crontab 또는 작업 스케줄러로
python agent/agent.py 점검만 등록해 줘. --execute 는 붙이지 마.
Claude나 Codex의 AI 검토도 안 되면 원인과 계속 가능한 코드 단계를 따로 알려 줘.
```

## 2-6. 숙제 — 기본 스펙으로 직접 실행

```

기본 스펙으로 점검 미리보기 한 번과 기록 한 줄만 남겨 줘.

python sync_spec.py 와 python verify.py 까지 실행해 줘.
```
