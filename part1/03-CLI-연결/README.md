# Part 1 · 03 — 가벼운 래퍼(CLI)로 연결하기

## 이 단계 목표
필요한 기능만 명령으로 감싼 작은 CLI를 써본다. MCP처럼 상시 떠 있지 않고,
쓸 때만 부르니 가볍다. AI 에이전트가 이런 CLI를 명령으로 불러 쓴다.

## 📋 복사용 프롬프트
```
part1/03-CLI-연결/code/kisctl.py 로 삼성전자(005930)와 SK하이닉스(000660)
현재가를 한 번에 조회하고, 내 계좌 잔고도 보여줘.
```

## 직접 실행하고 싶다면
```
python part1/03-CLI-연결/code/kisctl.py price 005930 000660
python part1/03-CLI-연결/code/kisctl.py balance
```

## 기대 결과
```
005930: 307,500원
000660: 2,319,000원
현금: 1,960,500원 / 보유 4종목
  - 삼성전자(005930): 12주 · 3,690,000원
  - ...
```

## MCP vs CLI — 언제 무엇이 나은가
- **MCP**: 표준·자동 참조. 편하지만 도구 정의가 늘 컨텍스트를 차지.
- **CLI**: 가볍고 쓸 때만 호출. 대신 AI에게 사용법을 알려줘야 함.
- 정답은 상황마다 다르다. 여기서는 두 방식을 나란히 놓고 감을 잡는다.
