# Part 2 · 03 — 내 스펙으로 다시 실행 & 결과 확인

## 이 단계 목표
내가 고친 스펙대로 에이전트가 점검·보고하는지 다시 돌려 확인한다.
(선택) 디스코드로 보고가 오게 연결한다.

## 📋 복사용 프롬프트
```
part2/agent.py 를 다시 실행해서, 내가 바꾼 원칙대로 점검 결과가
달라졌는지 이전과 비교해서 설명해줘.
```

## 직접 실행하고 싶다면
```
python part2/agent.py
```

## (선택) 디스코드로 보고 받기
디스코드 채널의 웹훅 URL을 환경변수로 넣으면 화면 대신 디스코드로 갑니다.
```
DISCORD_WEBHOOK="https://discord.com/api/webhooks/..." python part2/agent.py
```
웹훅 만드는 법은 강의 중에 함께 진행합니다.

## (선택) 정해진 시각에 자동 실행
hermes-agent 의 예약(cron) 기능으로 "매주 월요일 아침" 같은 주기에 이
점검을 자동 실행하고 디스코드로 받게 할 수 있습니다. (강의 중 시연)
