# 읽기 전용 루틴

루틴은 정해진 시각이나 사건에 맞춰 자료를 조회하고 보고합니다. 주문안을 만들거나 주문을
실행하지 않습니다. 모의주문안은 Telegram의 `/ts_order_plan`에서 별도로 만듭니다.

## 현재 루틴

| 파일 | 실행 시점 | 결과 |
|---|---|---|
| `아침브리핑.py` | 장 시작 전 | 시장·계좌·보유 종목 점검 |
| `마감브리핑.py` | 장 마감 후 | 시장 마감과 보유 종목 변화 |
| `가격도달-알림.py` | 값이 바뀌었을 때 | 설정한 가격 조건 알림 |
| `저점고점-판독.py` | 수동 또는 예약 | 가격 위치 점검 |
| `참조전략-실험.py` | 수동 | 학습용 비교 결과 |

## 수업 자동화

2주차에는 아침 브리핑 하나만 사용합니다.

```text
아침 브리핑 지금 실행해 줘.
평일 오전 8시에 아침 브리핑 보내 줘. 예약 이름과 시각도 보여 줘.
```

첫 문장으로 결과를 확인한 뒤 두 번째 문장으로 예약합니다. 정상 결과에는 `주문 없음`이
표시됩니다.

## 안전 기준

- 모든 루틴은 조회와 보고만 합니다.
- AI가 실패하면 실패 이유를 표시하고 끝냅니다.
- 계좌 반영과 주문은 루틴에서 실행하지 않습니다.
- 노트북이 꺼져 있으면 정기 루틴은 실행되지 않습니다.
