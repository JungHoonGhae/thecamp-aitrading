# 루틴

**루틴**은 정해진 주기에 혼자 도는 작은 일입니다. 결과는 **루틴 알림**으로 옵니다.

일일이 열어 보던 것을 한 번에 받습니다. 코드를 새로 짜는 게 아니라,
이미 만든 것을 정해진 시각에 시작하는 것뿐입니다.

```
python routines/아침브리핑.py        ← 지금 한 번 돌려 보기
```

## 카테고리

이름만 봐도 위험을 알 수 있게 나눠 두었습니다. **주문이 나가는 것은 리밸런싱 하나뿐입니다.**

| 카테고리 | 무엇 | 주문 |
|---|---|---|
| 정보수집 | 읽을 거리를 모아 정리합니다 | 안 나감 |
| 스크리닝 | 조건에 맞는 종목을 찾습니다 | 안 나감 |
| 매매제안 | 제안까지 합니다. 넣는 건 사람이 합니다 | 안 나감 |
| 리밸런싱 | 목표 비중으로 되돌립니다 | **나감 · 승인 필요** |

새 루틴을 만들 때 어디인지 먼저 정합니다. 애매하면 정보수집입니다.

## 지금 있는 루틴

### 아침 브리핑 · 정보수집
장 열기 전에 알아야 할 것만 한 장으로 — 시장 분위기, 내 계좌, 종목 뉴스, 오늘이 점검일인지.

```
python routines/아침브리핑.py
```

```
코스피 6,893.40 (+1.25%)

— AI가 짚은 것 —
삼성바이오로직스 0.0% / 목표 20% — 보유가 없는데 목표만 잡혀 있다.
```

### 참조전략 실험 · 정보수집
미국 대형주: 직전 한 달을 빼고 1년 성적이 상위인 종목을 다음 한 달 같은 금액으로 담은 결과입니다.
한국에 같은 규칙을 쓰면 수업 본편으로 쓰지 않습니다. 주문이 나가지 않습니다.

```
python routines/참조전략-실험.py --no-send
python routines/참조전략-실험.py --compare --no-send
```

<details><summary>알림 예시</summary>

```
[정보수집] 참조전략 실험

— 한 가지 규칙 —
미국 대형주: 직전 한 달을 빼고 1년 성적이 상위인 종목을 다음 한 달 같은 금액으로 담습니다.

— 미국 고정 바스켓 · 2021~2025 —
비용 후 누적 +232.7% · 벤치마크 차이 +137.3%p
```
</details>

> 숫자가 커 보여도 고정 바스켓·생존편향이 있습니다. 시장 전체 성과로 읽지 마세요.
> `--compare` 는 선택입니다. 숙제의 본편이 아닙니다.

### 저점·고점 판독 · 매매제안
지금 이 가격이 어디쯤인지 — 1년 최저·최고 사이 위치, 평균선 대비, 흔들림을 한 줄로 판독합니다.

```
python routines/저점고점-판독.py
```

<details><summary>알림 예시</summary>

```
[매매제안] 저점·고점 판독 · 08/27 15:17

삼성전자 ▆ 67% · 가운데
   지금 264,500 (최저 67,600 / 최고 362,500) · 60일선 -7.2% · 흔들림 3.47%

— AI가 짚은 것 —
위치%는 1년 최고·최저 두 점만으로 나오는 숫자다. 그 두 점이 언제 찍혔는지는 표에 없다.
```
</details>

### 마감 브리핑 · 정보수집
장 끝난 뒤 오늘을 정리 — 시장이 어떻게 끝났는지, 내 계좌가 목표와 얼마나 벌어졌는지.

```
python routines/마감브리핑.py
```

> 아침은 「오늘 무엇을 볼까」, 마감은 「오늘 무슨 일이 있었나」입니다. 묻는 것이 다릅니다.

### 가격 도달 알림 · 정보수집
정해 둔 가격에 닿은 순간에만 옵니다. 그대로면 조용합니다.

```
python routines/가격도달-알림.py
```

> 직전 상태를 스스로 기억합니다. 같은 알림이 반복되지 않습니다.
> `가격도달-감시.py` 는 짝입니다 — hermes 가 견주게 할 때 씁니다.

### 정기 리밸런싱 · 리밸런싱 · **주문 나감**
목표 비중으로 되돌립니다. 기본은 미리보기이고, 승인해야 주문이 나갑니다.

```
python agent/agent.py             ← 미리보기 (주문 없음)
python agent/agent.py --execute   ← 승인한 셈. 가드레일 통과분만 모의 주문
```

## 두 층으로 되어 있습니다

```
규칙(코드)   계산하고, 견주고, 차단한다.  늘 같은 답. 공짜.
   ↓ 재료
판단(AI)     「무슨 뜻인가」, 「내가 놓친 게 있나」.  매번 조금 다르다.
   ↓ 루틴 알림
전달(텔레그램)
```

**주문은 언제나 규칙이 냅니다. AI는 읽고 말할 뿐입니다.** 이 선을 넘기지 마세요.
판단 층은 `claude` → `codex` → `hermes` 순으로 찾아 씁니다. 하나도 없으면 조용히 건너뛰고,
규칙 결과만 옵니다. 각 루틴 위쪽 `AI판단 = True` 를 `False` 로 두면 끕니다.

## 정해진 시각에 돌리기

hermes 채팅에 말로 겁니다.

```
아침브리핑.py 를 평일 오전 8시에 no-agent 로 실행해줘.
```

하루를 이렇게 채웁니다.

| 언제 | 무엇 | 스크립트 |
|---|---|---|
| 평일 08:00 | 아침 브리핑 | `morning-brief.py` |
| 값이 닿을 때만 | 가격 도달 (그대로면 조용) | `price-alert.py` |
| 평일 16:00 | 마감 브리핑 | `closing-brief.py` |

hermes 가 막히면 `crontab` 한 줄로도 같습니다. 자세한 건
[`lessons/2부-나만의-에이전트/4-자동화-hermes-예약.md`](../lessons/2부-나만의-에이전트/4-자동화-hermes-예약.md).

## 내 루틴 만들기

`routines/` 에 파일 하나를 더하면 그게 내 루틴입니다.

```python
from _routine import 루틴, 정보수집

r = 루틴("내 루틴 이름", 정보수집)
r.칸("무엇을 볼까")
r.줄("여기에 내가 보고 싶은 것")
r.보내기()
```

가져다 쓸 재료는 이렇습니다.

| 어디서 | 무엇 | 공식? |
|---|---|---|
| `common.kis` | 현재가 · 잔고 · 뉴스 제목 · 시총 상위 · 주문 | **공식** (한국투자증권) |
| `common.market` | 과거 시세 · 코스피 · 환율 · 공포지수 · 섹터 | 비공식 (야후) |
| `common.crypto` | 코인 시세 · 일봉 | **공식** (업비트) |
| `common.judge` | AI 판단 한 마디 | 내 코딩 앱 |

비공식 소스는 예고 없이 막힐 수 있습니다. 공부에는 쓰고, 돈이 걸린 판단의 근거로는 쓰지 마세요.
