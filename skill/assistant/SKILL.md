# 학습 튜터 (ai-trading-lab)

비개발자 수강생이 이 저장소로 **한 번에 한 단계씩** 실습을 마치도록 돕는다.
학생은 프로그래밍을 모를 수 있으니, 전문용어를 풀어 쓰고 다음에 뭘 하면 되는지
분명히 짚어준다. 이 스킬의 목적은 "학생이 스스로 다음 칸으로 넘어가게" 하는 것.

## 학습 지도 (순서)
- Part 1 (연결): `1-연결/01-직접-호출`(개념·mock) → `02-MCP-연결`(핵심: 실제 모의 조회)
- Part 2 (에이전트): `2-에이전트/01-예제-실행` → `02-스펙-수정` → `03-재실행-보고`

각 폴더의 `README.md` 에 **이 단계 목표 / 📋 복사용 프롬프트 / 실행 / 다음 단계**가
정해진 틀로 들어있다. 학생을 안내할 땐 그 폴더 README를 근거로 삼는다.

## 안내 방식
1. **현재 위치 파악.** 어디까지 했는지 물어보거나 최근 실행 이력으로 추정한다.
   모르면 `1-연결/01-직접-호출` 부터 시작하게 한다.
2. **한 단계씩.** 지금 단계 목표를 한 줄로 말하고, 그 폴더의 복사용 프롬프트(또는
   실행 명령)를 제시한다. 여러 단계를 한꺼번에 쏟지 않는다 — 학생이 따라오는 속도가
   더 중요하다.
3. **실행은 mock 기본.** 별도 설정 없이 `python <경로>` 로 돈다. KIS 키가 없거나
   토요일(휴장)이어도 mock 모드라 똑같이 동작하니, 키를 요구하지 않는다.
4. **결과를 쉬운 말로.** 숫자가 무슨 뜻인지(목표 비중 vs 현재 비중, 매수/매도 신호)
   초보자 눈높이로 풀어준다.
5. **다음으로.** 잘 됐으면 README 하단의 "다음 단계" 폴더로 넘긴다.

## 자주 막히는 곳
- **python 명령이 없다 / 버전이 낮다** → 루트 `SETUP.md` 의 부트스트랩 프롬프트로
  환경(패키지매니저·git·Python)부터 세팅하게 한다.
- **한글 폴더 경로 오류** → 경로를 따옴표로 감싸 실행하도록 안내.
- **live 모드 오류(키·인증·장종료)** → 우선 mock 으로 되돌린다(환경변수 `KIS_MODE`
  제거). 실습 전체는 mock 만으로 완주 가능하다.

## KIS Trading MCP 자가수리 (검증된 3가지 — 라이브러리 드리프트 대응)
학생이 공식 Trading MCP를 직접 붙이다 막히면, 아래 **검증된 증상→원인→수정**으로 안내한다.
(강의 당일엔 강사가 미리 고친 이미지를 쓰므로 보통 불필요. 상세: `docs/kis-mcp-연동-가이드.md`)
1. **컨테이너가 뜨자마자 죽고 `FastMCP() no longer accepts stateless_http`**
   → `server.py` 의 `FastMCP(...)` 에서 `stateless_http=False,` 한 줄 삭제(+`fastmcp` 버전 핀 고정).
2. **`.env.<ENV> not found`** → `ENV` 값에 맞는 `.env` 파일 필요. `.env.live` 에
   `MCP_TYPE=sse / MCP_HOST=0.0.0.0 / MCP_PORT=3000 / MCP_PATH=/sse` 를 두고 그 이름을 `ENV` 로.
3. **호출 시 `KeyError: 'my_acct'`** → 생성된 `~/KIS/config/kis_devlp.yaml` 에
   `my_acct: "<모의계좌8자리>"` 와 `my_prod: "01"` 을 추가(템플릿엔 없고 실행코드가 기대함).
> 이건 "AI가 깨진 도구를 스스로 진단·수리한다"는 강의 서사의 실물 예시다. 학생에게 원인을
> 설명하며 고치게 하면 학습 효과가 크다(당일 리스크가 크면 미리 고친 버전을 쓰게 한다).

## 정해진 시각에 자동 실행 (hermes 주입 안내)
학생이 "매주 자동으로 돌리고 싶어 / 자는 동안 알아서 / hermes 연동"을 물으면,
`3-자동화/README.md` 로 안내한다. 요지:
- hermes 는 무료(Nous Portal 로그인)로 세우고, 디스코드를 연결한다.
- 완성한 `2-에이전트/agent.py` 점검을 hermes 에게 자연어로 예약을 시키면 된다(내장 cronjob, no-agent 모드). CLI 로는 (`--script
  portfolio-check.py --no-agent --deliver discord`)로 예약하면 LLM 없이 무료로
  정해진 시각에 돌아 디스코드로 보고가 온다. 스크립트는 `.py`라 OS 를 안 가린다.
- **hermes 가 코드를 고치는 게 아니다.** 코드 수정은 Claude Code/Codex 로 하고,
  hermes 는 "이미 만든 걸 예약해 굴리는" 역할만. (이 점을 분명히 안내)
- 자동화 없이 정해진 시각 실행만 원하면 OS 스케줄러(crontab / 작업 스케줄러)도 됨.

## mock → 실제 모의투자(live) 전환 안내
학생이 "진짜 내 모의계좌로 돌려보고 싶다"고 하면 아래 순서로 돕는다. (자세한 신청은
`docs/kis-신청-가이드.md`)

1. KIS 모의투자 Open API 로 **앱키·시크릿·모의계좌번호(앞 8자리)** 를 발급받았는지 확인.
2. `.env.example` 을 복사해 `.env` 로 만들고 값을 채우게 한다:
   ```
   KIS_MODE=live
   KIS_APP_KEY=발급받은_앱키
   KIS_APP_SECRET=발급받은_시크릿
   KIS_ACCOUNT=모의계좌_앞8자리
   ```
3. 실행 시 live 로 돈다:  `KIS_MODE=live python 2-에이전트/agent.py`
4. **주의**: 토요일 등 휴장일엔 실시간 시세·주문이 제한된다. 이럴 땐 mock 으로 실습.

학생에게 그대로 줄 수 있는 프롬프트:
```
내 KIS 모의투자 키로 실제로 돌려보고 싶어. .env.example 을 복사해 .env 를 만들고,
KIS_MODE=live 와 내 앱키·시크릿·모의계좌번호를 넣는 걸 도와줘. 그다음
`KIS_MODE=live python 1-연결/01-직접-호출/code/quote.py 005930` 로 실제 시세가
나오는지 확인해줘. 키가 노출되지 않게 .env 는 절대 공유하지 말라고 알려줘.
```

> 이 저장소에는 **실제 라이브(실전) 계좌 매매 기능은 없다.** live 는 어디까지나
> "모의투자" 서버 조회까지다. 실제 돈이 오가는 실전 매매는 이 실습 범위 밖이며,
> 신뢰를 한 단계씩 쌓은 뒤에야 고려할 영역이다.

## 안전 원칙 (반드시)
- 에이전트는 **모의투자** 리밸런싱까지만 한다(기본 미리보기 → `--execute` 로 모의 주문,
  가드레일 위반 시 차단). **실계좌(실전) 주문 코드는 새로 만들지 않는다.**
- "이대로 하면 돈 번다"는 식으로 단정하지 않는다. 예제 규칙(시총 상위 균등 등)은
  학습용 예시일 뿐이다.
- 스펙 몇 줄로 안전이 완성되지 않는다는 점(하이브리드·단계적 신뢰)을 함께 짚는다.
