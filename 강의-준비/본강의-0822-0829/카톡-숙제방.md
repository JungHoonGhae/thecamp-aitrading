# 카톡 숙제방 — 붙여넣을 글

카톡은 마크다운이 거의 안 된다. 이모지도 쓰지 않는다.
**사람이 읽는 글과 AI에 넘기는 글을 나눈다.** 학생이 어디까지 복사할지 헷갈리지 않게.

| 글 | 언제 | 누가 읽나 |
| -- | -- | -- |
| 1 · 학생용 | 방 열 때 | 사람 |
| 2 · AI에 붙여넣기 | 1 바로 다음 | 클로드 |
| 3 · 숙제 리마인드 | 며칠 뒤 | 사람 |

## 쓸 때 지킬 것

- **핵심만.** 배경 설명은 소음이다. 학생이 할 일은 세 가지뿐이다 —
  자료 맞추기 · 숙제 세 줄 · 막히면 올리기. 도커를 쓰는 이유 같은 건 안 적는다.
- **말하듯 쓴다.** 종결어미가 전부 `~니다` 면 안내문처럼 읽힌다. `~어요` · `~죠` 를 섞는다.
- `「」` 대신 큰따옴표. 카톡에서 「」는 안 쓴다.
- **슬래시 명령을 쓴다.** 긴 경로를 학생이 치게 하지 않는다.
  저장소 문서(`3-1주차-숙제.md`)는 AI 가 읽으므로 경로 그대로 둔다 — 그쪽이 정확하다.
- **`skill-vs-mcp` 는 카톡에서 언급하지 않는다.** 2주차 수업에서 강사가 직접 소개한다.
  스킬과 문서(`3-1주차-숙제-찾기.md`)는 저장소에 그대로 둔다.

> **왜 2번이 폴더 정리부터 하는가.** 학생 대부분은 폴더를 만들고 그 안에서 clone 했다.
> 그래서 클로드가 저장소보다 한 칸 위에서 열려 `.claude/skills` 를 못 읽는다.
> 「스킬이 설치되지 않았다」의 진짜 원인이다. 저장소를 위로 올려 고친다 —
> 폴더 경로가 유지돼야 대화 세션도 남는다.
> 자세한 건 `.agents/skills/environment/SKILL.md` 의 「가장 흔한 함정」.

## 1 · 학생용

```
지난 주 수업 진행했던 계정훈입니다.

이 방은 편하게 쓰시면 돼요.
막히거나 궁금한 거 있으면 그냥 올려주세요. 화면 캡처만 올리셔도 됩니다.

수업 끝나고 자료를 좀 손봤어요. 먼저 맞춰주세요.

수업 때 쓰시던 클로드 그대로 켜시고, 다음 글 전체를 복사해서 붙여넣으세요.
"실습 환경이 준비되었습니다" 뜨면 끝입니다.

숙제는 평일 장 열렸을 때 이 세 줄이면 됩니다.

숙제 환경 준비됐는지 확인해 줘
/kis-trading-mcp
/investment-habit-rules

중간에 도커라는 걸 깔게 되는데, 클로드가 알아서 합니다.
설치 창 뜨면 한 번 누르고, 깔리면 한 번 켜주시면 돼요.

막히면 /troubleshooting 보내시고, 그래도 안 되면 여기 올려주세요.
```

## 2 · AI에 붙여넣기 (이 블록만 복사)

```
수업 자료를 최신으로 맞춰줘. 아래 순서대로 해줘.

1. 지금 열린 폴더에 verify.py 파일이 바로 보이는지 봐줘. 보이면 3번으로 가.

2. 안 보이면 지금 폴더 아래에 폴더가 하나 더 있을 거야. 그 안에 verify.py 가 있어.
   그 폴더 안의 내용을 전부 지금 폴더로 꺼내줘. 숨김 파일과 .git 도 빠뜨리지 마.
   다 꺼냈으면 빈 폴더는 지워줘. 폴더를 새로 만들거나 다른 데로 옮기지는 마.
   이렇게 하는 이유는, 클로드가 열린 폴더를 기준으로 도우미를 읽기 때문이야.

3. 내가 고친 파일 세 개를 먼저 안전한 곳에 복사해둬.
   내-투자-스펙.md, 내-투자-판단.md, .env 야. 이건 잃으면 안 돼.

4. git pull 로 최신으로 맞춰줘.
   내 수정 때문에 막히면, 3번 복사본을 믿고 깨끗하게 되돌린 뒤 pull 하고,
   세 파일을 원래 자리에 되돌려놔줘.

5. VERSION 을 읽고 verify.py 를 실행해줘. 윈도우면 python, 맥이면 python3 야.

6. 마지막에 두 가지만 알려줘.
   버전 숫자와, verify 화면에 뭐가 됐는지.
   2번을 실제로 했으면 클로드를 껐다 켜야 도우미가 붙는다는 것도 알려줘.
   폴더는 그대로니까 대화는 이어진다고 말해줘.
   중간 과정은 설명 안 해도 돼. 문제가 생기면 그때만 자세히 알려줘.
```
