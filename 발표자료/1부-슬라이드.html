▶ 시연 · 강사가 보여드립니다

공식 API가 없던 토스를 AI가 다루게

토스증권은 공식 API가 없었습니다. WTS를 재사용해 AI가 조회·거래까지 다루게 만든 게 tossinvest-cli. 핵심은 하나 — 어떤 데이터를 어떻게 주느냐(input)가 경쟁력입니다.

※ 이 화면은 강사 시연입니다. 수강생 계정은 필요 없습니다.

전환

여러분은 공식 API가 있는 KIS로

토스는 공식 창구가 없어 우회했지만, 우리는 한국투자증권(KIS)의 공식 모의투자 API로 — 더 안전하게, 같은 원리로 갑니다. 실제 돈이 아닌 모의투자라 손실 위험도 없습니다.

발표를 토씨까지 외우면 오히려 막힙니다. 잘하는 사람은 핵심 키워드만 쥐고, 나머지는 그 자리에서 추론해 연결합니다. AI 모델도 그렇습니다.

비유 · 생각의 흐름

“스타필드 안 A 레스토랑으로 와”

모든 골목을 안 읊어도 친구는 찾아옵니다. 낯선 곳에서 이렇게 생각하죠 — 그리고 AI가 “내 잔고 얼마야?”를 처리하는 방식과 똑같습니다.

친구 · 스타필드

① 지도앱으로 큰 길을 잡고
② 키오스크에서 “A 레스토랑” 검색
③ 몇 층인지 확인하고 찾아감

AI · MCP 도구 3개

① “KIS 도구로 되겠네” (패턴)
② 검색으로 잔고 API 찾기
③ 상세보기 → 호출로 실제 조회

문제

API 문서 330개를 통째로 던지면?

  • 1
    토큰 폭발 — 매번 수십만 토큰, 남는 공간이 없다
  • 2
    정확도 하락 — 중요한 게 묻혀 엉뚱한 값을 지어냄
  • 3
    문서 ≠ 실행 — 인증·계좌 처리는 문서만으론 안 됨
  • 4
    금방 낡음 — 복붙한 순간부터 원본과 어긋남

해법

MCP — 필요할 때 필요한 것만 (catalog)

평소엔 도구 3개만. 모델이 “잔고가 필요하네” 하면 그 스펙만 그때 꺼냅니다.

1검색무엇이 필요한지 찾기
2상세보기파라미터·필요조건 확인
3호출실제 실행

위계

무엇이 위에 있는 정보인가

인증·계정▸ 계좌▸ 종목▸ 상세 파라미터

상위 정보를 먼저, 세부는 필요할 때. 많이 주는 게 아니라 위계와 구조로 주는 것 — 이게 실력입니다.

▶ 시연 · 강사가 보여드립니다

재사용

서버 하나, 어디서든

같은 MCP를 Claude Code에도, hermes에도 붙입니다. 소스마다·도구마다 따로 잇던 걸, 서버 하나로 모두가 재사용 — N×M 을 N+M 으로.

CLI vs MCP

정해진 반복은 CLI, 그때그때 판단은 MCP

CLI = 자판기

정확한 버튼을 누르면 정해진 게 딱. 매번 똑같은 일엔 빠르고 확실 — 버튼에 없는 건 안 됨

MCP = 점원

“이런 게 필요해요” 하면 알아서 처리. 뭐가 필요할지 모를 때·여러 앱 재사용에 유리

CLI는 강력한 만큼 위험(잘못 치면 파일이 지워질 수도)해서, 오늘은 “이런 것도 있다”만.
